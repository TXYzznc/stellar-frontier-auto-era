# B43 资源权威与入库结算

## Context

仓库与资源点已有表现资产，但没有统一资源缓存、预留和入库权威。若先各自实现采集或运输，容易在并发、取消与存读档时产生重复资源，且会与b07物理货物唯一归属冲突。

原始任务：P4-001、P4-010、P4-012、P4-013。用户在2026-10-08确认全量详细规划及“复用现有架构、必要时局部重构”，随后确认本批方向并授权实施；UI运行验收仅1920×1080，但Prefab结构仍考虑适配。

## Goals / Non-Goals

**Goals:**

- 建立资源缓存、可用/预留数量、统一转移与实际提交结果。
- 建立机器货舱、来源缓存和仓库的原子交接；复用b07所有权边界，不引入第二套货物拥有者。
- 通用资源入库转换全局余额，实体物品保留仓库身份与容量，事件记录责任与实际数量。

**Non-Goals:** 不实现传送带运动/出料队列/建造，不实现商品购买、升级或完整农业规则；缓存基础可扩展但本批不宣称四类资源点均完成。

实现边界见proposal.md的路径清单。新增产品类型只能进入AutoEra目录并使用AutoEra.*命名空间；本批不修改ScriptsBuiltin、asmdef、HybridCLR/FSR设置或用户任务表。场景/Prefab共享文件在实施前核对占用和精确清单，不按目录通配批量改写。

## Decisions

### 路线与取舍

| 候选 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 复用既有服务并局部修正边界 | 保留既有规则与验证投入，可独立回归 | 需处理旧入口兼容 | 采用，符合用户A |
| 统一底座后重写接入 | 全局模式整齐 | 回归面与前期投入更大 | 不采用 |
| 只补调用，不调整责任 | 局部代码少 | 生命周期/状态风险可能残留 | 不作为本批方案 |

### D1 领域数据

采用资源类型ID、容器/货物永久ID、整数权威数量、容量及预留记录。可用量=持有量−有效预留量；资源单位/容量计量继承正式表。MachineCargo作为机器容器接入相同转移边界，不维护平行库存。全局余额由世界会话拥有，仓库实体库存由仓库拥有。

### D2 预留与提交

Reserve读取来源可用量和目标容量，返回带事务ID/来源任务/实际可承诺量的令牌；Commit在单个世界安全边界重验来源、目标、代次与数量后同时扣源加目标。重复Commit返回同一结果，Cancel只释放尚未提交部分；目标失效不能吞掉已提交货物。避免在异步表现回调里分两次扣加。

实施语义：拥有者版本只在归属改变时递增；部分交付拆出新的永久子批次，来源剩余批次保持原身份/版本，使其他合法预留仍可提交。整批交接保留批次ID并递增版本。仓库转换将物理批次耗尽，结果保留原事务/任务身份与实际量。事务完成序号作为幂等键；未知过期序号仅返回等待原因，不产生新数量事实。已提交结果在通知前存入权威，两个机器的货舱投影及占用先一起更新，再通知观察者。目标代次变化取消未提交预留并保留已交付数量。只在提交和通知之外提供脱离运行时的只读资源快照。

### D3 唯一货物权威

优先接b07的唯一归属与原子转移接口；若b07实现尚未出现，仅允许完成领域接口/契约测试并标明生产接入待依赖，不临时创建竞争所有权账本。物理代理数量、散落位置、动画完成不能反推资源结算。

2026-10-08实施补充授权：用户在范围选项中明确选择“补齐最小前置核心”。本批负责补齐b07的唯一权威核心：批次永久ID、拥有者及其版本、预留、幂等原子交接；所有容器/货舱/入库都适配该同一权威。此核心是b07合同的实际交付，不能另设兼容竞争账本。不包含传送带状态机、下游拉取调度、物理代理或视觉表现，b07其他任务保持未交付。

### D4 入库分类

金币按既有规则直接余额；木材/矿石/水/生物质在缓存/运输中保持实体数量，进入仓库时原子转全局余额且不占实体库存容量，不提供反向提取。种子/农产品等物品按所属仓库占容量；封装组件按正式容量规格进入组件库，未部署载体进入机器库且不能装入普通货舱。入库对象只选一个分类去向，未知类型拒绝并保留来源。

### D5 日志与持久化准备

每次提交只发布一条带事务ID、任务/行为ID、来源/目标与实际数量的结果。完整提交后允许取快照；预留和已提交标记成为B48快照字段，不要求持久化Unity对象或视觉代理。

## Risks / Trade-offs

- **与b07形成双权威** → 由生产接入测试断言每个货物只有一个拥有者；接口未交付时不能用临时全局字典绕过。
- **部分搬运与取消丢货** → 区分承诺、实际提交和未提交量，逐整数提交边界验证守恒。
- **本次尚无新运行证据** → 本文件定义将来的验证门；历史测试保留时间/版本，不当作本次复跑。
