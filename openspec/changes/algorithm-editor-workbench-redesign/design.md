## Context

当前 `AlgorithmEditorForm` 是一个功能集中但层级扁平的页面：节点库、画布、检视器、问题区和操作按钮在同一个 Form 预制体中，画布节点与连线还由同一个双模式模板承担。算法编辑器属于游戏内高频操作界面，需要让玩家在不阅读说明的情况下知道当前模式、选中的对象、可用操作和验证结果。

项目 UI 规范要求动态列表使用默认 inactive 的 Item 模板，并由 Form 管理实例生命周期；本次新增的节点和连线 Item 必须位于 `Assets/Game/Prefabs/UI/Item`，Form 只保存 prefab 引用。Unity 版本为 2022.3.62f3，继续使用 UGUI、TMP 和 GF UI 生命周期。

## Goals / Non-Goals

**Goals:**

- 建立三栏工作台：节点库、画布、检视器；问题与上下文工具条提供全局反馈。
- 保持深色信息工具风格，并加入游戏化分类色、状态徽标、选中高亮和短时交互反馈。
- 支持滚轮缩放、中键平移、节点拖拽、端口拖线和画布聚焦。
- 将节点和连线解耦为两个独立 UIItem，Form 通过 prefab 引用动态生成。
- 保留现有算法读模型和命令语义，确保添加、连接、删除、验证、应用和诊断功能继续可用。
- 为节点 Item 和连线 Item 提供稳定的运行时绑定入口，避免按场景中具名对象查找。

**Non-Goals:**

- 本变更不新增算法节点种类、算法执行语义或数据模型。
- 不把端口行、节点库行、检视器行和问题行抽成全局 UIItem；它们继续使用所属页面的动态模板。
- 不引入新的 UI 框架、第三方图编辑器或运行时资源包。
- 不重做 FieldHudForm 或其他页面的整体视觉。

## Decisions

### 1. 节点和连线分别使用独立 Item

新增 `AlgorithmNodeItem.prefab` 和 `AlgorithmEdgeItem.prefab`。节点 Item 自己持有标题、状态、端口列表和节点选择/拖拽行为；连线 Item 自己持有线段表现和连线选择行为。Form 只负责把快照数据绑定到 Item，并把命令回调交给读模型。

选择独立 prefab 是因为节点和连线的几何、输入命中区域、刷新频率和交互状态不同。继续使用双模式模板会让节点与连线互相携带无关层级，容易出现遮挡、状态残留和绑定路径错误。端口行留在节点 Item 内部，因为它只对节点成立，且端口列表尺寸依赖节点布局。

### 2. 画布采用中心坐标系和显式视图状态

`Content_AlgorithmGraph` 保持可滚动的大画布，节点和连线实例使用中心锚点；画布控制器维护缩放值、平移偏移和当前聚焦对象。模型 `LayoutX/LayoutY` 仍是持久化坐标，视图状态只影响显示，不写回模型；拖拽结束时才调用 `MoveNode`。

滚轮缩放以指针位置为中心，中键拖动改变平移，节点拖拽只在节点命中区域内移动。初次打开或点击“定位”时，画布把选中节点或图边界带入可见区域。

### 3. 三栏布局和上下文工具条

页面内容区使用固定比例的三栏：左栏约 20% 用于节点库和搜索，中栏约 56% 用于画布，右栏约 24% 用于检视器；问题条位于画布下方，顶部显示算法名称、运行状态、节点/连线计数和编辑/诊断模式。底部操作条根据当前选择显示“添加节点、连接提示、修改参数、删除、验证、应用”等操作。

按钮不再把所有命令同时铺开。不可用命令隐藏或明确显示原因；编辑/诊断模式用标题徽标和操作条颜色区分；节点类别用稳定的少量语义色区分，错误、警告、已连接和待连接状态使用统一状态色。

### 4. Form 与 Item 的绑定边界

Form 新增两个 prefab 引用字段，渲染时实例化节点和连线 Item，并在刷新前回收旧实例。Item 只暴露绑定所需的方法或轻量事件，不直接访问算法服务。端口按钮回调通过节点 Id 和端口 key 回传 Form，Form 再调用读模型。

节点库、检视器和问题列表仍由 Form 持有默认 inactive 模板，避免为页面专用短行增加独立资产和跨页面契约。后续若这些行在两个以上页面复用，再单独提取。

## Risks / Trade-offs

- [画布坐标与缩放引入输入换算错误] → 所有指针坐标统一通过 `RectTransformUtility.ScreenPointToLocalPointInRectangle` 转换，并用 PlayMode 测试覆盖拖拽、缩放和定位。
- [节点数量增加导致频繁 Instantiate/Destroy] → 先保留 Form 级实例缓存，刷新时回收并复用同类 Item；只有结构变化时才重建端口行。
- [视觉层级变复杂后状态难辨] → 用固定状态色、模式徽标和选中描边，所有状态同时提供文字说明；不依赖颜色单独传达错误。
- [旧路径绑定失效] → 更新 Form 字段、Prefab 合同和 PlayMode 测试；编译后运行节点添加、连线、删除和诊断流程。
- [低分辨率空间不足] → 保持三栏最小宽度，允许左/右栏收起，画布优先保留；第一版继续以 1920×1080 为设计分辨率。
