## Context

继承已验收 ArtResource 环境：七地貌、种子确定性流式生成、密集随机草、共享风场、积雪覆盖和雪/沙/泥/液体响应，默认地貌倍率 0.25、正交大小 14。正式场景已有 80×80 区域、七个对象、导航平面和语义输入。

## Goals / Non-Goals

目标：正式世界入口真实加载环境，镜头移动与旋转不露出未生成地面，机器实际接触产生响应，退出/重进正确释放和重建。
非目标：改写权威建设范围、机器导航、存档域或输入设备读取；导入样机 UI/测试代理；移交 Git 提交。

## Decisions

1. 仅导入资产依赖闭包和运行时核心，按类型放入正式 Environment 子目录。新文件保留源 GUID，同 GUID 既有文件核对内容，不覆盖其它窗口成果。源项目不变；引用完整性由 Unity 原生加载再验证。
2. 地形原点下降 12m，建设区域固定高度 0，边界外 12m 平滑过渡。材质气候分类仍读取原始地貌场；建设区对象周边预留装饰空间。替换原平面的可见 Renderer，保留导航 MeshFilter/Collider。相较移动全部正式对象，该方法保留现有业务坐标合同。
3. 区域镜头显式绑定环境控制器，继续消费现有语义输入/设置。流式世界提交正交镜头，范围 10～20，支持 25～80 度俯仰及水平旋转；请求视野覆盖含旋转、地形和装饰高度包络。正式环境关闭自动原点搬移，避免外部机器与权威坐标失步。
4. 区域初始化启动环境，异步入口在初始地面就绪后报告世界就绪；释放对称取消任务、动态网格、纹理和全局 Shader 状态。机器绑定时显式注册接触来源，未来敌人可复用相同注册入口。
   光照继承验收样机的三色环境光和暖色柔和主光；进入世界时克隆当前 URP 质量资产，将阴影距离提高到至少 250m，支持距离 160m 的正交相机，退出恢复原质量资产和全局光照。正式资产不保存运行时质量修改。
5. 快速执行候选检查：本单元包含生命周期、坐标和镜头边界专业判断，并与当前独占 Unity 场景现场不可分离，由当前负责人实施复核，不创建子 agent。

## Risks / Trade-offs

- 地形偏移影响液面/覆盖层 → 统一物理高度与 Terrain 局部归一化高度，Shader 加地形基准高度。
- 旋转扩大显示包络 → 使用保守四角旋转包络及显示缓存上限，准备完成前保持原镜头。
- 原点搬移关闭 → 正式当前小建设区安全；远距离继续采用已验证 ±1,000,000m 请求上限，不声称无限精度。
- 共享仓库脏文件 → 小范围增量修改，安装器只编辑环境组件/引用/地面 Renderer，不重建区域。

## Migration Plan

记录依赖清单与摘要；导入新资产；添加适配和安装器；保存 InitialRegion 后恢复 Launch；原生编译和相关测试；实际世界流程及可视验证；项目围栏审计。回退删除本变更新增环境组件和资源并恢复安装前场景备份，不触碰其它改动。
