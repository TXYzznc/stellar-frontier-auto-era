# algorithm-editor-canvas

## ADDED Requirements

### Requirement: 画布创建节点

算法编辑器画布 SHALL 通过读模型 CreateNode 命令在选中实例草稿中创建节点，布局坐标按网格步进避开既有节点。

#### Scenario: 从节点库行创建

- **WHEN** 用户在选中机器实例时点击节点库中种类 K 的行
- **THEN** 草稿新增一个种类 K 的节点（带目录默认字段）、画布位置按网格步进偏移、草稿修订加一

#### Scenario: 经工具条按钮创建

- **WHEN** 用户在选中机器实例且已选定库种类时点击「添加或连接节点」按钮
- **THEN** 草稿新增一个所选种类节点，行为与行点击一致

#### Scenario: 域未就绪

- **WHEN** 未选中机器实例或域状态非 Ready
- **THEN** 不发生草稿变更

### Requirement: 两步端口连线

画布 SHALL 以两步端口选择建立连线：先点输出端口记录待连源，再点输入端口对该组合发起 Connect。

#### Scenario: 兼容端口连接

- **WHEN** 用户先点节点 A 的输出端口 O、再点节点 B 的输入端口 I，且组合兼容
- **THEN** 草稿新增边 A/O → B/I、待连源清除、修订加一

#### Scenario: 不兼容或已占用

- **WHEN** 第二次点击的端口不兼容或目标输入已被占用
- **THEN** 不新增边、待连源保持、问题栏呈现失败原因（端口缺失／类型／单位／能力不兼容／输入已占用）

#### Scenario: 取消或换源

- **WHEN** 用户再次点击同一输出端口或点击另一输出端口
- **THEN** 待连源被取消或替换，且不发生草稿变更

### Requirement: 连线选择与删除

画布 SHALL 为每条草稿边渲染一个可选中的元素（位置取两端节点布局坐标中点）；「删除选中」MUST 经 Disconnect 命令仅删除选中的边。

#### Scenario: 删除选中边

- **WHEN** 选中一条边并点击「删除选中」
- **THEN** 仅该边从草稿移除、修订加一、其他边保持不变

### Requirement: 节点选择与删除

画布 SHALL 经节点按钮选中画布节点供检视器展示；「删除选中」MUST 经服务 DeleteNode 命令删除选中节点，并级联移除所有引用该节点的边。

#### Scenario: 删除选中节点

- **WHEN** 选中一个画布节点并点击「删除选中」
- **THEN** 该节点与所有 From 或 To 指向它的边在同一次草稿变更中移除

#### Scenario: 修订保护

- **WHEN** 草稿修订与界面快照不一致时请求删除
- **THEN** 删除被拒绝，界面按新快照重渲染而不变更草稿

### Requirement: 草稿工具条可用性

窗体 SHALL 呈现 Grp_AlgorithmDraftTools 工具条（撤销／重做／删除选中）；撤销与重做 MUST 可见但禁用直至存在命令历史；删除选中 MUST 恰在存在节点或连线选择且域 Ready 时可用。

#### Scenario: 无选择

- **WHEN** 未选中节点或边
- **THEN** 「删除选中」禁用

#### Scenario: 撤销重做占位

- **WHEN** 任意时刻查看工具条
- **THEN** 撤销与重做按钮可见且 interactable=false

### Requirement: 预制体字段绑定完整

AlgorithmEditorForm 预制体 MUST 为生成分部声明的每个字段携带序列化引用，含此前缺失的应用按钮、节点搜索输入、画布内容与画布元素模板，以及新增的添加按钮与草稿工具按钮；任一绑定为 null 时窗体 MUST 对该控件保持惰性而不抛异常。

#### Scenario: 绑定补全

- **WHEN** 检查预制体 Form 组件的序列化字段
- **THEN** 应用按钮、搜索框、画布内容、画布模板、添加、撤销、重做、删除选中引用均非空且指向正确节点
