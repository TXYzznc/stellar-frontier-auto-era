## Why

上一版美术目录只有 16 份扁平摘要，无法像参考项目那样直接交给美术或生图 AI：共用素材没有按批次自包含，状态没有逐项编号，页面缺少真实布局数值、元素表和专属素材清单，世界资产缺少逐对象生产稿。用户要求完全按 `Everlight-Tales/Docs/GameDesign/11-美术规范 - 副本` 的结构和内容深度重写。

## What Changes

- 重建 `Docs/GameDesign/11-美术规范/` 的目录结构：总规范、美术风格和规范、界面设计文档、世界资产设计文档、manifest 和验收。
- UI 共用素材拆为 9 个自包含批次，每个批次包含固定视觉模块、技术硬约束、逐状态编号/文件名/提示词、出图批次建议和验收。
- 18 个 UI 页面族各自建立完整文档，包含实际 Form/Prefab/contract 来源、布局节点骨架、元素/数据槽位、中英文效果图提示词、页面专属素材、交互状态、共用引用和返工条件。
- 世界资产拆为共用 3D 模块、机器/组件、建筑/施工、资源点/环境、VFX/动画/音频和 7 个世界效果图文档。
- 继续遵守全量重做：旧图片、模型、贴图、材质、VFX、动画、音频和旧效果图不得作为生产内容；用户负责实际生图，本变更只交付文档与提示词。

## Scope

包含第一版实际 UI、机器、建筑、资源点、环境、VFX、动画、字体和音频设计；排除人物、动物、战斗、实际探索、棋盘、角色语音和移动端 UI。

## Acceptance

目录与参考结构对应；每个生产文档可单独交接；每个状态有唯一记录；manifest 无悬空引用；当前 Form/contract 可追溯；OpenSpec strict validation 通过。
