## ADDED Requirements

### Requirement: 提交机器任务节点
系统 SHALL 提供「提交机器任务」节点，在第一个世界行为发生前显式创建机器任务；可选设置任务名称与优先级，后续同事件链行为共享该任务上下文。

#### Scenario: 显式提交任务
- **WHEN** 一个提交任务节点被触发且任务队列未满
- **THEN** 创建一个新机器任务，其 ID 回传算法供后续行为继承

#### Scenario: 队列满时拒绝
- **WHEN** 任务队列已满
- **THEN** 提交返回拒绝并产生 `rejected` 结果事件，不覆盖旧任务

### Requirement: 查询本机任务节点
系统 SHALL 提供「查询本机符合条件的任务」节点，输出匹配任务引用与其状态，供算法做显式防重判断。

#### Scenario: 查询到未结束任务
- **WHEN** 本机存在符合查询条件的未结束任务
- **THEN** 节点输出该任务引用与进行中状态

#### Scenario: 查询无匹配任务
- **WHEN** 本机不存在符合查询条件的任务
- **THEN** 节点输出空引用（无效），不伪造任务
