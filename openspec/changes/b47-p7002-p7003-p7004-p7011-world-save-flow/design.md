# B47 安全快照与存读档入口

## Context

三槽文件服务已有校验、备份与恢复，但实际新建/继续/保存退出尚未接入世界状态。机器运行时被销毁再重建为空闲不能满足保存行为责任、算法计时及待应用请求的要求。

原始任务：P7-002、P7-003、P7-004、P7-011。用户在2026-10-08确认全量详细规划及“复用现有架构、必要时局部重构”，随后确认本批方向；UI运行验收仅1920×1080，但Prefab结构仍考虑适配。当前仅规划，未实施。

## Goals / Non-Goals

**Goals:**

- 用领域DTO保存世界、对象、机器、任务/行为和算法状态，不序列化运行服务与Unity对象。
- 建立安全快照、单槽串行异步写入、60秒与关键事件保存请求合并。
- 新建/继续/恢复/保存退出连接真实世界，采用先验证候选再切换会话的恢复方式。

**Non-Goals:** 不新增云存档、任意手动回档或跨设备同步；不把尚无领域实现的生产/经济/成长伪造为已保存；B48/B49未完成前不得将整套存档离线标为G7通过。

实现边界见proposal.md的路径清单。新增产品类型只能进入AutoEra目录并使用AutoEra.*命名空间；本批不修改ScriptsBuiltin、asmdef、HybridCLR/FSR设置或用户任务表。场景/Prefab共享文件在实施前核对占用和精确清单，不按目录通配批量改写。

## Decisions

### 路线与取舍

| 候选 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 复用既有服务并局部修正边界 | 保留既有规则与验证投入，可独立回归 | 需处理旧入口兼容 | 采用，符合用户A |
| 统一底座后重写接入 | 全局模式整齐 | 回归面与前期投入更大 | 不采用 |
| 只补调用，不调整责任 | 局部代码少 | 生命周期/状态风险可能残留 | 不作为本批方案 |

### D1 文件与世界格式分离

继续使用SaveSlotService的外层槽位元数据/校验/备份；在ContentJson内引入显式worldSchemaVersion与领域段目录。复用现有MachineRosterSnapshot/AlgorithmMemorySnapshot并补缺失领域字段。外层版本只有外层格式变化才升级；旧空内容/测试内容不是有效世界快照，明确提示不可加载而不删除。

### D2 安全快照协调

应用上下文拥有保存协调器和当前槽；世界会话提供安全边界。60秒周期和部署/硬件/算法成功应用等关键事件只置脏并请求保存。算法批次和整数转移完成后在主线程生成不可变DTO，再后台序列化/写临时文件/校验/轮转/替换。每槽只允许一个写入，快照后新变化保留新dirtyRevision，旧写入完成不能清掉新脏标记。

### D3 恢复顺序

先在隔离候选内校验槽位、世界版本、时间、ID唯一性和所需领域段；先创建领域实例及注册永久ID，再解析引用，最后重建运行服务、传感/效应器和实体表现。缺目标保留失效引用不按名寻找；未知领域版本或缺必需段失败不得用默认世界顶替。所有验证通过才提交ActiveWorldSession，失败清理候选且保留可恢复文件。

### D4 运行状态与新旧合同

运行服务对象仍不直接进存档，但重建后必须从领域快照恢复任务阶段、货舱责任、事件序号、算法状态/延迟/历史和待应用请求，不能沿用旧部署接线中的“重建回空闲”作为正式读档规则。这是B47对早期无持久化阶段限制的明确替代，不改真实任务规则。首次新建与恢复走不同入口，恢复不发Startup。

### D5 退出与入口

正常菜单选择有效槽/创建新槽；初始内容来源于已确认开局配置，不发明免费机器。保存退出先封锁新操作，推进到安全边界取快照，再停止模拟等写入；失败提供重试/返回游戏/明确强制退出。主文件损坏显示有效备份时间与损失范围，用户确认后提升。离线待结算槽转B49入口，未就绪时明确不可进入世界，不跳过离线。

## Risks / Trade-offs

- **新脏状态被旧写入清掉** → 以快照修订与完成修订比较，延迟IO测试覆盖连续保存请求。
- **部分恢复污染当前世界** → 隔离构建/提交两阶段，失败释放候选；引用断链保持可诊断而非重新生成身份。
- **初始配置或后续领域未就绪** → 允许验证子集，不启用假正常继续；正式综合流程完成项必须等待全部必要领域。
- **本次尚无新运行证据** → 本文件定义将来的验证门；历史测试保留时间/版本，不当作本次复跑。
