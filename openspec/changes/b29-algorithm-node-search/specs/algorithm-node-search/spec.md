## ADDED Requirements

### Requirement: 图节点搜索过滤

算法工作台节点栏 SHALL 支持按输入过滤图节点。

#### Scenario: 输入过滤词

- **WHEN** 玩家在「搜索节点」输入框输入文字
- **THEN** 节点栏只显示名称或状态包含该文字（忽略大小写）的节点

#### Scenario: 清空过滤词

- **WHEN** 玩家清空搜索框
- **THEN** 节点栏恢复显示全部图节点

#### Scenario: 命中计数回显

- **WHEN** 过滤后显示的节点少于全部节点
- **THEN** 节点栏说明回显「搜索命中 N 个」

#### Scenario: 点选过滤后的行

- **WHEN** 玩家点选过滤后的一行节点
- **THEN** 按该行节点的稳定 Id 选中（不受过滤重排影响）
