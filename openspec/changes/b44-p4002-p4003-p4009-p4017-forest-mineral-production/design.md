# B44 林木与矿脉真实作业

## Context

两类资源点已有场景对象和外观，但尚无驱动真实产出与耗尽的生产权威。用动画或静态公开数值验证算法会掩盖资源生产链未接通。

原始任务：P4-002、P4-003、P4-009、P4-017。用户在2026-10-08确认全量详细规划及“复用现有架构、必要时局部重构”，随后确认本批方向；UI运行验收仅1920×1080，但Prefab结构仍考虑适配。本批已按追加授权实施，实际证据见evidence/implementation-20261008.md。

## Goals / Non-Goals

**Goals:**

- 实现人工林逐树状态、矿脉独立储量与换日清场，接B43缓存。
- 切割/钻探使用已确认行为结算、安全中断和能源规则，向B41暴露真实读取。
- 录入本批资源/行为数值并校验单位，表现从实际状态和整数提交事件派生。

**Non-Goals:** 不实现农田批次、灌溉、水泵或全量P4-017；不生成替代正式美术，不恢复被推翻的固定每秒产速。缺失参数仅使用2026-10-08用户明确批准的可调试玩初值，不扩大到其他平衡数值。

实现边界见proposal.md的路径清单。新增产品类型只能进入AutoEra目录并使用AutoEra.*命名空间；本批不修改ScriptsBuiltin、asmdef、HybridCLR/FSR设置或用户任务表。场景/Prefab共享文件在实施前核对占用和精确清单，不按目录通配批量改写。

## Decisions

### 路线与取舍

| 候选 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 复用既有服务并局部修正边界 | 保留既有规则与验证投入，可独立回归 | 需处理旧入口兼容 | 采用，符合用户A |
| 统一底座后重写接入 | 全局模式整齐 | 回归面与前期投入更大 | 不采用 |
| 只补调用，不调整责任 | 局部代码少 | 生命周期/状态风险可能残留 | 不作为本批方案 |

### D1 林木权威

人工林逐树使用稳定对象ID，生长/成熟/采集状态与可采资源对应，继承最新排列与数量合同DEC-203；表现对象可重建但不能另分配权威树ID。切割对象由实际目标确定，目标失效不能按名字自动换树。

### D2 矿脉权威

矿脉总储量与视觉矿石分离，使用已确认小/中/大100/250/500与满显示6/8/10资料；表现映射按DEC-203，不因碰撞体销毁多扣资源。耗尽/换日清场只处理该资源点占用，保留遗留货物和无关玩家设施。

### D3 作业阶段

行为上下文保存目标、任务、阶段、有效贡献、已提交/剩余单位与下一安全边界。实际消耗与产出遵守DEC-183/184/187/192及最新结算文档；停电/取消在安全边界停止，恢复从未完成部分继续，表现完成不直接扣库存。

### D4 缓存与溢出差异

共用B43容器和提交事务，但资源点阻塞/溢出策略按类别配置。矿脉地面堆显示封顶不等于停止开采；需明确保留权威数量/拥有者，复用b07代理和溢出合同。不能用一个通用容量规则覆盖不同对象特例。

### D5 数据与可观察性

工具型号、等级、资产、功率端点和既有资源类别读取已加载GameData。生成数据表没有本批新增数值列；D6批准的试玩初值由ForestMineralProductionConfig配置资产承载，加载后复制并验证为不可变ProductionRules，不手改生成C#或把配置资产用作运行时数据库。公开状态提供者返回真实储量/阶段与允许字段，记录动作等待原因；最佳农业参数不在本批出现。

### D6 缺失数值追加授权（2026-10-08）

复用此前三轮目标、架构和验收澄清，只询问配置缺口。用户明确批准[evidence/proposed-numerics-20261008.md](evidence/proposed-numerics-20261008.md)中的可调试玩初值：树数、间隔、高度/生长曲线、恢复期、木材换算、锯盘伤害及钻探阻力/伤害端点。功率端点仍读取现有组件定义，矿量/显示档位仍继承DEC-203。初值录入不等于平衡或完整阶段验收。

## Risks / Trade-offs

- **旧数据与最新决策不一致** → 以DEC和统一数值表建立字段对照，遇实际冲突只暂停相关字段，不能自行猜测数值。
- **外部资源或动作锚点不足** → 记录资产依赖，先验证纯逻辑；正式场景/视觉通过必须有批准资源。
- **增量与完整阶段门不同** → 本次运行证据见evidence，完整阶段前置和正式美术门仍独立保留。
