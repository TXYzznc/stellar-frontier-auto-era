## Decisions

### D1 两条验收线
结构线：b51 用户通过 → 全量结构分批推广 → 全量结构验收。
美术线：明确正式视觉系统/资源生产范围 → 代表效果图与用户验收 → 素材拆分和装配/动效 → 代表实机效果验收 → 全量美术推广。
用户已明确恢复并验收 b51；b52 结构现已解锁。正式美术不是当前结构实施的一部分。

### D2 家族差异
按覆盖矩阵逐页设计，不批量机械套同一外壳。保留统一控件尺寸层级、状态语义、导航规则；允许不同面框尺寸、导航方向、卡片密度、展示区和阅读节奏。平铺卡片与紧凑列表按任务选择，不要求统一网格。

### D3 脚本与组件
继续使用现有读模型、UIItem 池和事务接口。按需要增加物件卡、指标摘要、槽位、时间记录等预制阅读组件；只在真实多处复用时提取，避免为了规范新增框架层。图表必须有真实采样；无数据时隐藏或说明。列表选择、分页、滚动和返回焦点保留。

### D4 美术生产
工程科幻、温暖工程设施与精密显示区；状态颜色继承正式美术基线。按现有字体规范使用 SIMHEI SDF，字体更换属于另行决定。明确面板/读数/按钮/物件层次。占位资源不算正式交付。
效果图从已确认布局尺寸生成；图内动态文字不烘焙进最终图片；切片记录九宫格边界、透明度、尺寸和资源键。ArtResource 为美术源，主项目只接收交付资源。

### D5 动效与反馈
按因果触发选中、面板展开、槽位变更、真实成果和异常；高频操作不等待长动画。未来动效集中控制/可中断，关闭释放 Tween 与事件，隐藏页停止动画；布局容器和动效容器分离。动画强度、音效和时长在代表美术阶段确认，禁止伪造实时曲线/执行路径或离线补播历史动作。

### D6 验收与回退
每批先保存原合同及目标子树摘要，再定向生成、验证和截图。1920×1080 覆盖正常、空、不可用、长文本、滚动和模态返回；隐藏状态不必同时呈现。节点数只用于候选排序，不当作性能结论。Player 性能结果与 B50 共享真实证据，不用 Editor 截图冒充整体验收。

## Risks / Trade-offs
- [前置领域缺失] → 明确结构通过和运行未接入的区别，保持禁用原因。
- [复用导致同质化] → 控件复用、构图按家族独立。
- [正式资源制作晚于原型] → 资源槽位和比例写进合同，不能先做临时美术造成二次标准。
- [全量改动过大] → 按下列批次串行、每批验证后再继续，保留截图版本和意见记录。

## Migration Plan
次序：基础阅读/流程组件 → 系统/启动 → 目录/选择 → 生产/现场 → 算法 → 中枢/任务/报告 → 全量复核。各 Form 对应 tasks 和矩阵，正式美术再走一次同样的覆盖清单。只恢复本批备份，不覆盖他人改动，不自动 Git 提交。
