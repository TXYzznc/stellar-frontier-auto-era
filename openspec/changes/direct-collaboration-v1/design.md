# 设计

## 角色边界
派发制作人启动任务并维护全局索引；协作验收制作人处理协作、决策和验收；专业窗口负责执行和自恢复。

## 数据
全局日志目录按角色保存 `角色-日志.ndjson`，只追加。角色队列保存轻量任务索引，完整任务正文单独文件，领取时读取。

## 通信
消息直接发送目标窗口，同时写入发送日志；目标收到后写入接收日志并回执。未送达由目标启动扫描日志补收，不依赖轮询调度器。

## 打断策略
消息带 priority 与 interruptPolicy。normal/deferred 只入队；decision-required/conflict/blocking 才在安全点处理；critical 才允许显式抢占。

## 迁移
先冻结新调度器入队与定时唤醒，再迁移未完成任务到角色队列，保留旧日志只读，验证双制作人和全部角色直连后停用旧窗口。
