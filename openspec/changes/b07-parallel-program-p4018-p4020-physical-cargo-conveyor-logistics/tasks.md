## 3. P4-019 三段传送带与出料队列

- [ ] 3.1 定义接料短滚筒、主带、出料短滚筒、接料范围、轨迹、间距、速度和状态合同

- [ ] 3.3 实现不依赖带面摩擦的受控工业运输约束、三段交接、顺序保持和安全恢复
