## ADDED Requirements

### Requirement: 五套系统模板在世界创建时录入
算法模板库 SHALL 在世界创建时录入五套系统模板：基础灌溉、农田基础作业、生长资源采集、储量资源开采、固定路线运输，每套都是结构有效的系统模板（不绑定任何对象或组件）。

#### Scenario: 世界创建后五套系统模板存在
- **WHEN** 一个世界会话被创建
- **THEN** 模板库的系统模板列表包含五个不同名称的系统模板，且全部 IsSystem 为 true

### Requirement: 系统模板可实例化为独立文档
系统模板 SHALL 能通过模板库实例化为独立的玩家文档（新文档 ID + 全部节点 ID 重新分配），实例化失败时返回失败而非静默成功。

#### Scenario: 实例化系统模板得到独立文档
- **WHEN** 对某个系统模板调用实例化
- **THEN** 返回文档的 DocumentId 与源模板不同，且所有节点 ID 均被重新分配

#### Scenario: 未绑定的模板保持无绑定
- **WHEN** 读取某套系统模板的文档
- **THEN** 其 Bindings 为空（不预置任何组件/对象绑定）
