# B42 算法工作台可用性与闭环

## Context

算法工作台已能编辑图，但现有截图显示端口标签拥挤及信息层级问题，已有UI测试主要证明图操作。需要在B40/B41的真实运行链上验收应用、历史与诊断，并遵循用户仅1920×1080验收、节点布局仍适配的要求。

原始任务：P3-010、P3-011、P3-013、P3-014。用户在2026-10-08确认全量详细规划及“复用现有架构、必要时局部重构”，随后确认本批方向；UI运行验收仅1920×1080，但Prefab结构仍考虑适配。当前仅规划，未实施。

## Goals / Non-Goals

**Goals:**

- 修正节点端口排版、选中/连线/验证反馈及诊断定位；保留强类型和版本检查。
- 按视图、编辑命令和诊断读模型局部拆分，运行时生命周期归B40。
- 建立1920×1080视觉/交互验收与RectTransform结构适配检查，形成G3真实执行证据。

**Non-Goals:** 不重写图框架，不增加移动端/其他分辨率验收，不默认实现撤销重做历史，不复制模板规则或升级美术风格。UI资产允许清单仅算法编辑器及其现有节点/连线项和直接契约，不覆盖整个UI目录。

实现边界见proposal.md的路径清单。新增产品类型只能进入AutoEra目录并使用AutoEra.*命名空间；本批不修改ScriptsBuiltin、asmdef、HybridCLR/FSR设置或用户任务表。场景/Prefab共享文件在实施前核对占用和精确清单，不按目录通配批量改写。

## Decisions

### 路线与取舍

| 候选 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 复用既有服务并局部修正边界 | 保留既有规则与验证投入，可独立回归 | 需处理旧入口兼容 | 采用，符合用户A |
| 统一底座后重写接入 | 全局模式整齐 | 回归面与前期投入更大 | 不采用 |
| 只补调用，不调整责任 | 局部代码少 | 生命周期/状态风险可能残留 | 不作为本批方案 |

### D1 既有契约演进

保留UIViews标识、页面导航与节点/边ID。先修改AlgorithmEditor契约/迁移工具，再生成字段与预制体，禁止手改.Fields.cs造成双源；沿用独立AlgorithmNodeItem/AlgorithmEdgeItem，不把每个端口都拆独立资源。

### D2 节点布局

端口列以内容布局和LayoutElement管理最小/首选尺寸，标题与端口分区，长标签换行/省略与可访问说明按语义选择；线端点来自端口RectTransform，移动/缩放后仍对齐。禁止布局组和脚本同时控制同一轴。

### D3 屏幕与适配分开验收

只在1920×1080执行截图和交互验收。Form根全屏Stretch、零offset；缩放由GF根Canvas及AppSettings.DesignResolution管理，Form根不新增CanvasScaler。HUD按边缘语义锚定、模态居中、列表视口随容器拉伸，结构检查保证适配意图；不新增其他分辨率运行检查。

### D4 编辑与运行隔离

选中/移动/连线只改草稿；应用使用B40命令入口与修订门禁。失败定位具体节点/绑定，保留旧已应用实例；禁用未实现按钮并说明，不让开发类型名替代玩家错误原因。

### D5 诊断与证据

运行历史携带当次修订、节点路径、输入快照与任务结果；用选定记录定位当时节点，不拿新图猜旧路径。自动截图隐藏可控调试浮层但不篡改业务状态，另存原生测试XML；截图不能证明运行成功，必须同时断言真实任务结果。

## Risks / Trade-offs

- **图布局修复误改模型坐标或绑定** → 保留节点永久ID与现有布局数据，视图回退不回写模型；连线/缩放/拖动回归。
- **过早宣称G3已通过** → 区分测试场景输入准备与正常玩家入口；G3记录附全部前置及真实结果，综合正常入口复验不足时明确保留待验项。
- **本次尚无新运行证据** → 本文件定义将来的验证门；历史测试保留时间/版本，不当作本次复跑。
