## 5. 过程中踩到的两件事（留痕）

- **一个 PlayMode 类只能放一条用例。** 我原本把整备页的验证作为第二条 `[UnityTest]` 放进
  `MachineLibraryDeployEntryPlayModeTests`，结果第二条一开始就报
  `MissingReferenceException: The object of type 'UIComponent' has been destroyed`
  （栈在 `GFBuiltin.Start` / `LaunchProcedure.OnEnter`）：第二条用例会重新引导框架，
  而上一轮留下的世界对象已经被销毁。仓库里既有的 PlayMode 类**都只有一条用例**，
  现在这条约定有了明确的失败证据与原因。
- **一次断言写错的教训（不是代码问题）。** 我断言出售资格文案含「撤回」，而实际文案是
  「必须先撤**收**回库」——期望子串与实际用词不同。测试失败时先核对期望串本身，
  比先怀疑实现更快定位。
