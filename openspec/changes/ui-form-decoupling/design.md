# 设计
1. 保留内嵌所有页：改动小，但继续一次加载全部节点，不采用。
2. 仅拆成 MonoBehaviour/Prefab：可整理文件，但缺独立 GF 生命周期，不作为完整页面方案。
3. 独立 GF UIForm 按需加载（采用）：保持原路由入口，子页按稳定身份/显式请求取得数据；父窗拥有子窗并对称关闭。

算法公开参数：主窗拥有读模型，子窗借用同一编辑上下文（独立打开时自行创建并释放）。防重复打开，关闭父窗时先关闭/取消子窗再释放模型。编辑与诊断共享画布，不拆成两个重复图编辑器。

共享框架：OpenSubUIForm 需追踪加载中的 ID，CloseSubUIForm 同时支持取消加载。禁止框架引用 AutoEra 类型。

快速执行候选检查：当前工作单元包含路由/生命周期判断，并依赖正在使用的 Unity 编译及 Prefab 现场，不能原子交接，本窗口直接实施。
