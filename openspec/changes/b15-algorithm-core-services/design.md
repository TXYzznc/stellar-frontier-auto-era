**Goals:** S1强类型图和计划、S2事件/调度/导航/诊断、S3隔离应用与模板/内存恢复，及真实联合测试。

## Decisions

- 使用专用可序列化DTO与深拷贝，不用运行SO节点或外部图框架。固定注册表描述端口/运算；编辑坐标不影响执行顺序，未知版本拒绝运行。
- 编译验证后保持私有不可变副本；基础布尔/数值/引用/位置/枚举家族及已确认只读结构类型有明确单位/能力。未实现端点显式不可用。
- 根事件锁定快照；预计算纯计划及成本，整批取得算力后提交状态写集与命令；队列拒绝进入后续事件，普通世界结果不变红。
- 复用ComputePool/Tasks/Navigation/Sensors，不重复收导航或采样算力。算法结果只在后续批次传播；绑定代次与应用修订门禁。
- 草稿、已应用图、运行状态及模板分离；版本比较拒绝过期申请。结构安全点发布重置修改实例，参数保留状态。关闭观察层不取消申请。
- DEC-097/024：结构应用的整机重启期间其它实例暂停并保留状态，结束后恢复；不是始终运行，也不清空其它实例。
- 单实例事件等待32、历史运行50；测试需区分假驱动和真实NavMesh，保留原生报告后再运行。

## Risks / Trade-offs

- 旧模板与新格网成本冲突 → 本批不交五生产模板，拒绝未知动作，不隐藏领域运算。
- 同步Compute.Started回调重入 → 服务泵与回调分离、先建工作项再提交，统一释放。
- 旧图历史路径失配 → 历史保留修订及输入/路径，不在新图猜旧数据。
- 安全点不足 → 不伪造完成；仅等待明确服务状态，退出必须取消/排空租约。

## Migration Plan

新增服务不自动启用任何开局算法，不改正式场景/配置。通过测试显式组合；回退仅解除新服务订阅，不重写既有机器数据。
