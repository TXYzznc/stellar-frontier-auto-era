# B40 算法正式运行驱动

## Context

正式场景已创建算法实例服务，却未持续驱动实例服务与命令适配器；UI激活会先挂接适配器，再尝试提交实例，失败时存在半挂接风险。已有集成测试自行Pump，不能证明产品入口形成运行闭环。

原始任务：P3-003、P3-005、P3-007、P3-008。用户在2026-10-08确认全量详细规划及“复用现有架构、必要时局部重构”，随后确认本批方向；UI运行验收仅1920×1080，但Prefab结构仍考虑适配。当前仅规划，未实施。

## Goals / Non-Goals

**Goals:**

- 给机器运行时提供稳定排序的推进入口，实例服务与适配器每业务步只推进一次。
- 把首次激活和应用请求交给机器级操作入口，读模型委托调用，生命周期不依赖Form。
- 明确首次启动、恢复、参数应用、结构应用、安全点及失败回滚；补正式宿主集成测试。

**Non-Goals:** 不新增节点语言、五套模板规则、算法市场或新调度框架；硬件提供者由B41建立；磁盘恢复由B47接入；不把现有单适配器限制升级为新的玩法规则。

实现边界见proposal.md的路径清单。新增产品类型只能进入AutoEra目录并使用AutoEra.*命名空间；本批不修改ScriptsBuiltin、asmdef、HybridCLR/FSR设置或用户任务表。场景/Prefab共享文件在实施前核对占用和精确清单，不按目录通配批量改写。

## Decisions

### 路线与取舍

| 候选 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 复用既有服务并局部修正边界 | 保留既有规则与验证投入，可独立回归 | 需处理旧入口兼容 | 采用，符合用户A |
| 统一底座后重写接入 | 全局模式整齐 | 回归面与前期投入更大 | 不采用 |
| 只补调用，不调整责任 | 局部代码少 | 生命周期/状态风险可能残留 | 不作为本批方案 |

### D1 唯一推进入口

InitialRegionScene保留组合根，新增机器注册表AdvanceWorldStep(worldMilliseconds, navigationSeconds)一类窄接口（名称可在实现时等价调整）。按机器永久ID稳定迭代，在迭代结束后处理部署/撤收变更，避免回调改变集合。导航仍只由RegionNavigation推进，禁止双Tick。

### D2 业务步与回调

先落本步能源/环境事实，再采样传感器，再处理已入队算法事件与应用安全点，再把接受的命令送往任务/行为权威；本步产生的结果事件排到后续可控批次，避免递归重入。导航完成回调只记录结果，不在回调中直接递归执行算法。保留既有队列容量、事件顺序和公平规则。

### D3 原子激活

将ActivateDraft的创建/挂接/逻辑容量占用封装到机器级服务：检查草稿/硬件/绑定修订→验证编译→准备运行时→提交实例与适配器→发布变化。任一步失败均释放临时对象与租约并恢复可重试状态，不能留下HasRuntime=true但实例未接收的状态。

### D4 触发与应用语义

首次激活只入队一次Startup；无效申请不影响旧实例。参数变更保持运行状态；结构应用按现有整机安全点合同暂停其他实例、替换目标并恢复，结果归属原请求ID。恢复读档只恢复未处理事件，不补发Startup；用户暂停/断电暂停/应用暂停原因相互独立。

### D5 多实例与释放

沿用AlgorithmInstanceService的实例集合与共享算力池。先复核正式多实例合同；适配器若需局部改造，采用实例ID隔离订阅/命令归属，复用任务与导航仲裁，不克隆机器状态。删除实例、撤收、退出区域均取消归属请求、退订并释放；实例生命周期调整不得顺手扩大执行并行规则。

## Risks / Trade-offs

- **回调重入或双重推进** → 以时序测试、同一时刻推进计数和结束后队列交换证明每个入口只运行一次。
- **当前代码限制与既有多实例合同不一致** → 作为局部差异补齐并回归共享算力/导航仲裁；若需改变已确认玩法则停止该差异实现，不静默降级为单实例。
- **本次尚无新运行证据** → 本文件定义将来的验证门；历史测试保留时间/版本，不当作本次复跑。

1. 取得实施授权、核对原始任务和依赖证据；读取conventions，记录实际修改文件及共享工具占用。
2. 先补能暴露问题的测试和基准，再按tasks.md实施领域/接入/表现单元；结构与序列化变更停止Play Mode，使用普通Unity编译。
3. 按规格逐场景验证，保存原生XML、日志和必要1920×1080截图/Player基准；UI截图不代替业务结果断言。
4. 回滚策略：按小提交单元保留原服务API适配，回退新宿主接线与UI委托调用；不自动删除机器或草稿。出现半激活状态须先释放临时运行时再恢复旧已应用实例。
5. 更新本变更evidence索引与未覆盖项；仅当实际完成后勾选任务。阶段验收与用户任务表状态另行处理，不自动Git提交或归档既有变更。
