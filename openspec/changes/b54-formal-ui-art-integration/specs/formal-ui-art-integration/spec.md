## ADDED Requirements

### Requirement: 保留源图的正式导入
系统 SHALL 配置全部正式 UI PNG 的 Sprite、透明、mipmap、过滤与适用切片，保留源字节及 GUID，独立图标不使用面板切片。

#### Scenario: 带透明留白的按钮
- **WHEN** 源图实际范围与标注尺寸不同
- **THEN** 导入基于实际像素边界和 Sprite 范围，源 PNG 不变且角部不随中心拉伸

### Requirement: 文档驱动的逐页接入
系统 SHALL 按 01→18 页面族对现有 UI Prefab 与已有分页进行布局及正式资源接入，保留已有行为和绑定；结构及资源身份以正式界面文档为准，构图以效果图为准。

#### Scenario: 效果图与素材语义路由不同
- **WHEN** 效果图包建议交换资源身份
- **THEN** 实施仍沿用正式设计文档资源身份，并记录冲突

### Requirement: 可复验视觉与结构
交付 SHALL 包含 1920×1080 渲染、导入及引用审计、编译与已有 UI 回归证据，并列出未实现页面、无法验证的真实状态及素材问题。

#### Scenario: 领域前置未完成
- **WHEN** 页面真实业务数据依赖尚未交付
- **THEN** 区分静态视觉验证和业务验证，不伪造数据证明业务完成
