## Goals / Non-Goals

**Goals:** 正式素材完整导入，保持角部与图标比例；现有页面区域与效果图一致，动态文字、数值与进度继续由程序驱动。

**Non-Goals:** 补建业务或缺失页面、改动源 PNG、应用待批准的语义路由、修改 ScriptsBuiltin、提交 Git。

## Decisions

1. 图像源不变，通过 Sprite rect 和实际像素 border 处理留白；独立插画和图标保留比例，条带按对应合同处理，不能全量套同一 border。
2. 先审计再应用；Unity API 原位编辑 Prefab，保留原节点身份、脚本引用和绑定，不重建整个 Form。
3. 效果图决定区域构图，设计文档决定节点职责与资源身份；布局调整回写工程合同。
4. 按家族顺序进行，每个独立页面保留可复验截图和映射；未实现领域不作为视觉接入完成的业务证据。
5. 快速执行候选检查：实际 PNG 几何与合同不一致，需逐族专业判断；Unity 现场和回归不可安全分离，本窗口直接执行。

## Risks / Trade-offs

- 源像素及文件名不一致 → 扫描实际像素与 alpha 范围，报告冲突，配置不覆盖原图。
- 切片边界和超小控件相撞 → 调整 pixelsPerUnitMultiplier/控件布局并检查边界和。
- 效果图没有动态文字 → 保留 TMP 与可读性，不将整页效果图当运行时背景。
- 工具服务未监听 → 优先恢复已有编辑器工具连接；仍不可用则保留可执行工具与真实未验证状态。
