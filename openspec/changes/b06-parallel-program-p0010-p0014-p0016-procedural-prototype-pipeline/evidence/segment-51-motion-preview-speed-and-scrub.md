# 第51段：动作预览速度与进度拖动

日期：2026-09-04

## 实现

- `AutoEra > Motion > 动作预览`新增0.1×至4.0×播放速度滑条、当前倍率显示和“一键恢复1.0×”。
- “预览进度”滑条改为即时采样：拖动时先恢复绑定姿态，再以所选动作图的指定进度直接应用，因此暂停状态也可逐帧检查动作姿态。
- 播放时速度倍率同时作用于进度和连续旋转的经过时间；重新选择动作从0开始播放。
- 时间映射提取为纯 `MotionPreviewTimelineCore`，由编辑器窗口调用并由EditMode测试覆盖；它不读取玩法任务或记录运行时结果。
