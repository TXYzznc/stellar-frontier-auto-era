# 第42段：三类效应器作业表现阶段

日期：2026-09-03

## 实现

- 新增`EffectorWorkPresentation`，作为不接触玩法结算的表现阶段状态机。
- 水枪按瞄准、喷射、关阀、终止表现；中断或断电只先关阀。
- 旋转锯盘按瞄准、升降、升速、进给、接触切割、退刀、停盘、终止表现；中断或断电从接触／进给状态先退刀。
- 旋转钻头按瞄准、升速、压入、钻探、收钻、粉尘、停转、终止表现；中断或断电从作业状态先收钻。
- 该状态机不保存效应器队列、不读取算法图，也不决定灌溉、伤害、矿产、任务或存档结果。
