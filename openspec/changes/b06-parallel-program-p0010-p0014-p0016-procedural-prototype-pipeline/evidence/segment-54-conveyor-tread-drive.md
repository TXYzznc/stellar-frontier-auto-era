# Segment 54：传送带履带驱动与物料传送可视化

## 用户反馈修正

- 不以静态闭合网格、上下两个平面或仅转动滚筒冒充传送带。
- 验收场必须可见一圈连续的履带节，履带节沿上行带面、端部回绕和下行回程构成的同一闭环推进。
- 两端滚筒与四个支承滚筒按履带线速度和滚筒半径同步旋转。
- 演示货物只位于上行工作带面，从入料端移动到出料端；抵达后回到入料端开始下一循环，以表现传送而非让货物倒挂回程。

## 实现边界

- `ConveyorLoopPresentation`为纯几何／运动映射：闭环路径、履带速度、滚筒转角和上行货物位置可由编辑器Builder与验收场Director共用。
- Builder生成36节基础几何履带与5个演示货物；Director仅驱动这些表现节点和滚筒，不结算物流、货物归属或出料口逻辑。
- 停止验收场时恢复所有履带节与货物的绑定姿态。
