## ADDED Requirements

### Requirement: 同一永久机器身份

区域 SHALL 绑定当前世界名册已有机器的同一 ID；世界注册表 MUST 继续解析原 MachineInstance，不分配新 ID 或注册第二实例。

#### Scenario: 首次及重复绑定
- **WHEN** 合法机器以合法占地部署，并重复相同请求
- **THEN** 名册和区域 ID 一致，注册表数量及分配高水位不变，重复请求返回同一表示。

#### Scenario: 非法绑定及跨区域重复
- **WHEN** ID 无效、数值非有限、占地冲突、机器销毁、其它区域已绑定或重复参数改变
- **THEN** 请求失败，原部署标志、占地和绑定不变，不能借部署接口移动固定载体。

### Requirement: 所有权与生命周期

区域 SHALL 只拥有机器表示；合法回收、区域删除、区域卸载和世界卸载 MUST 对称释放表示及事件，不误删除名册身份。

#### Scenario: 回收及失败回收
- **WHEN** 已绑定机器通过原名册回收门或因损伤／未停机被拒绝
- **THEN** 成功移除表示但保留名册身份；拒绝不移除表示或改变部署状态。

#### Scenario: 区域卸载和再次绑定
- **WHEN** 区域被释放或机器表示被移除
- **THEN** 名册和部署事实保留，区域 token 解除，可在新区域重新绑定；重复清理无副作用。

#### Scenario: 世界先于区域卸载
- **WHEN** 世界先释放名册，而区域和作业队列尚存
- **THEN** 区域被关闭并释放表示、队列和订阅，后续重复清理安全。

#### Scenario: 名称及通知一致性
- **WHEN** 名册重命名或部署通知被订阅者读取
- **THEN** 区域名称保持一致，观察者不会看到第二 ID 或缺失的已发布绑定。
