## ADDED Requirements

### Requirement: 同身份预约与只读查询

已绑定机器 SHALL 用同一 ID 申请现有 RegionWorkQueue；查询 MUST 不修改排队，Granted 仅表示预约权而不表示已抵达。

#### Scenario: 优先级和 FIFO
- **WHEN** 多台已绑定机器申请通道且后续请求优先级更高
- **THEN** 当前占用不被抢占，释放后优先级高者先接替，同优先级按申请顺序；重复申请不重复入队。

#### Scenario: 查询与取消等待
- **WHEN** 查询未申请、占用或等待的机器，然后取消等待并重复释放
- **THEN** 查询返回对应状态且不入队，取消仅移除该等待项，重复释放无副作用。

### Requirement: 清理预约

机器回收、表示移除、目标删除和区域/世界卸载 SHALL 清理对应占用及等待项，保留其它有效机器的正常接替。

#### Scenario: 机器与目标失效
- **WHEN** 当前机器合法回收或作业目标被移除
- **THEN** 前者释放并移交下一个有效等待者，后者清空通道并返回 InvalidTarget，永久机器身份不受目标删除影响。

#### Scenario: 卸载与非法申请
- **WHEN** 世界或区域关闭，或名册机器尚未绑定区域就申请
- **THEN** 关闭目标不可申请且无残留，未绑定机器返回 InvalidRequester，不隐式部署或移动。
