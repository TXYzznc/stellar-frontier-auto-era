## ADDED Requirements

### Requirement: 运行时节点值快照

算法运行时 SHALL 在执行时记录值节点的「当时值」快照。

#### Scenario: 记录值节点

- **WHEN** 一批求值计算了某值节点的主输出端口
- **THEN** 该节点的主输出值被记录进运行记录的节点值快照

#### Scenario: 快照可复制

- **WHEN** 读取运行记录的节点值快照
- **THEN** 返回深拷贝（修改返回结果不影响记录本身）

### Requirement: 诊断按值细节

机器域算法读模型 SHALL 在选中节点时暴露其「当时值」。

#### Scenario: 有当时值

- **WHEN** 选中一个在最近运行里执行过的值节点
- **THEN** 节点详情含「当时值」行（格式化自节点值快照）

#### Scenario: 无当时值

- **WHEN** 选中一个最近运行未执行过的节点
- **THEN** 节点详情不含「当时值」行
