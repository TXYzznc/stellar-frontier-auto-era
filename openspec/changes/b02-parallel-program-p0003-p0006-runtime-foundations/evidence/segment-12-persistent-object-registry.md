# 第 12 段：永久对象注册表

## 实施范围

- 增加世界内 `PersistentObjectRegistry`，以 `PersistentId` 为唯一键保存对象类别与受控对象引用。
- 注册、查询和注销返回可区分的无效 ID、无效类别、空引用、重复、缺失、类别不匹配与实例不匹配结果；不会覆盖既有条目。
- 注册恢复 ID 时推进共享分配器高水位；注册表 `Clear` 丢弃当前世界的全部对象引用。
- 分配器在耗尽后仍可接受不影响高水位的已恢复 ID，避免恢复顺序影响已保存条目；新分配持续明确失败，不发生回绕。

## 验证
