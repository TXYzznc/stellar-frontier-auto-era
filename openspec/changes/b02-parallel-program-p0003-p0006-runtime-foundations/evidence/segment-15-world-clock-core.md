# 第 15 段：整数世界时钟核心

## 实施范围

- 增加 `WorldClock`，以非负 `long` 整数毫秒作为唯一权威世界时间。
- 在线输入以秒传入并累计不足一毫秒的双精度余量，只提交完整毫秒；不同帧切分不会重复或遗漏整毫秒。
- 支持直接推进到目标时刻，拒绝负推进、向后跳转、NaN/Infinity 输入与溢出，不改变原时间。
