## Why

> 历史记录（2026-10-09）：用户要求“先别急着做，先写 OpenSpec”，因此当时先提交方案并暂停实施。随后用户明确恢复并授权本批执行；本提案现进入“技术实现完成、等待用户验收”阶段。

当前 UI 是结构原型，正式美术尚未制作；不同业务大量共用文字列表、等宽分栏与底部操作条，直接换皮会保留构图同质化。先用三个代表工作区验证对象展示、世界融合和管理概况，再推广其余页面，可降低全量返工。

## What Changes

- 保留工程科幻和全部功能、数据、权限规则，重组机器整备单页、HUD 常驻区与机器现场概况、中枢总览。
- 采用中性结构期资源；预留机器展示与动效容器，不生产正式图片、模型或动效。
- 更新布局文档、机器可读合同及真实 Prefab，保留同宿主其它分页和现有导航。
- 以 1920×1080 验收；节点锚点、布局驱动与可扩展区域仍须正确。使用真实数据或明确不可用态，不伪造经营数据。
- 用户通过代表原型后才允许 b52 推广结构；正式美术、效果图、动效另行验收。
