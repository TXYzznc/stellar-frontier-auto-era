# B49 离线领域推进与回归报告

## Context

离线调度器本身不能证明生产、机器行为、施工制造和任务结果正确。必须按第一版白名单接真实领域下一事件，并将结算身份、阻塞与报告持久化，避免重复领奖或离线穿过缺电/满载等限制。

原始任务：P7-008、P7-009、P7-010、P7-012。用户在2026-10-08确认全量详细规划及“复用现有架构、必要时局部重构”，随后确认本批方向；UI运行验收仅1920×1080，但Prefab结构仍考虑适配。当前仅规划，未实施。

## Goals / Non-Goals

**Goals:**

- 接资源生产/能源/机器任务行为和施工制造/任务成长的真实离线事件。
- 导航使用有效路径长度/速度计算抵达与中途进度，不逐帧模拟场景。
- 持久化一次性结算报告、阻塞聚合与离线进度；仅结算完成后开放世界操作。

**Non-Goals:** 不离线替玩家购买/出售、改装、选择配方、部署或领取普通可选择奖励；不新增实际探索/战斗/维修；不把待外部领域用简单乘法估算补齐。

实现边界见proposal.md的路径清单。新增产品类型只能进入AutoEra目录并使用AutoEra.*命名空间；本批不修改ScriptsBuiltin、asmdef、HybridCLR/FSR设置或用户任务表。场景/Prefab共享文件在实施前核对占用和精确清单，不按目录通配批量改写。

## Decisions

### 路线与取舍

| 候选 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 复用既有服务并局部修正边界 | 保留既有规则与验证投入，可独立回归 | 需处理旧入口兼容 | 采用，符合用户A |
| 统一底座后重写接入 | 全局模式整齐 | 回归面与前期投入更大 | 不采用 |
| 只补调用，不调整责任 | 局部代码少 | 生命周期/状态风险可能残留 | 不作为本批方案 |

### D1 领域接入接口

每个领域通过NextMeaningfulEvent和ApplyEvent一类窄接口暴露下一阈值及推进（最终命名可等价调整），复用在线提交规则。生产到成熟/耗尽/缓存边界，能源到日照/燃料/储能拐点，机器到任务/行为安全点；事件处理重新计算受影响下一事件，不把过去无效计划继续执行。

### D2 阻塞与精确单位

缺电、无资源、缓存/货舱满、目标失效、路径不可达和算法错误都会限制实际推进。允许合并循环只在状态、输入和结果严格等价时进行；以相同输入在线事件驱动参考轨迹为金标准，不用肉眼总收益近似。

### D3 导航与物理

离线仍查询权威导航路径；首次验证路径有效，再按长度与速度安排抵达事件。中断保存路径身份/段进度/剩余距离和目标代次，恢复到一致位置；路径失效重新按既有规则处理。货物归属与队列继续结算，但不逐帧运行RigidBody、动画或散落代理。

### D4 施工与奖励

施工/制造延续退出前已提交的配方与队列；缺料/缺电/输出满保持阻塞，不能替玩家换配方。任务达成和允许的自动结算按原事务规则处理，普通需领取或选择的奖励保留待领取，不由离线引擎强制发放。

### D5 报告身份

按settlementRunId持久化报告与已经应用的领域事务结果，继续结算可更新同一报告；完成标记与报告进入同一安全快照。报告显示实际离线时间、资源净变动、库存/消耗/溢出、任务与停机/未解决责任等，优先异常和阻塞，重复记录聚合。

### D6 进入流程

B47载入候选后先执行离线，进度条只读真实追赶时刻/工作量，完成后展示一次报告再交世界操作权；历史重看不调用结算。UI仅1920×1080验收，列表可滚动并采用结构适配；失败/中断保留检查点并提供恢复路径，不把失败显示为100%。

## Risks / Trade-offs

- **在线离线浮点累计差异** → 记录单位、积分边界与允许精度，资源整数/交易标记严格一致，长区间逐阈值对照。
- **报告重复显示引起再次结算** → 报告只读，所有收益绑定runId与领域提交标记；重入/崩溃点逐点故障注入。
- **路径/物理代理被误当运行权威** → 路径与货物身份存领域数据，重建表现不得重复生成资源。
- **本次尚无新运行证据** → 本文件定义将来的验证门；历史测试保留时间/版本，不当作本次复跑。

5. 更新本变更evidence索引与未覆盖项；仅当实际完成后勾选任务。阶段验收与用户任务表状态另行处理，不自动Git提交或归档既有变更。
