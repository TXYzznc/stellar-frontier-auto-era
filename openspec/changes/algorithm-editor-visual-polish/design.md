# 设计

## 视觉层级

画布必须是视觉焦点，节点和连线使用高亮色，面板只承担信息分组。左侧节点库负责发现能力，右侧检视器负责确认上下文，底部问题栏承载风险与验证结果。强调线与颜色只表达区域职责，不承载业务状态真值。

## 交互反馈

节点悬停提升青色轮廓，按下和选中使用颜色与描边反馈，不改变节点缩放，因此端口位置在交互期间保持稳定。输入端口固定在左侧、输出端口固定在右侧；端口名称保持短文本，Event、Boolean、Number、Enumeration、Object、Position 等类型使用不同颜色的 socket，连接后增强内圈与光晕。连线悬停加粗变亮，选中变为琥珀色。连线本身按贝塞尔曲线距离命中，矩形空白区不再拦截画布操作。画布空白区显示缩放／平移提示，首次显示图时适配到可读范围，玩家手动操作后不强制重置。

## 性能与耦合

网格使用单个 `MaskableGraphic` 批量生成低密度线段，射线关闭；连线使用独立 `AlgorithmGraphEdgeGraphic`，自身负责曲线采样、渲染和命中，`AlgorithmEdgeItem` 只保存身份、选择状态和几何宿主。视觉主题集中在独立组件，Form 只负责生命周期接入。节点拖拽只更新关联边，避免 Form 为无关边重复计算。
