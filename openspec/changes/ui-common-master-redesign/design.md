## Context

共用 UI 需要可复用的少量轮廓合同，同时让状态在灰度缩略图中可辨。页面专属素材仍由 18 个页面文档管理，但只引用母版 ID。

## Decisions

1. 保留四个 UI 母版：框架容器、交互控件、语义图标、反馈进度；职责相似的功能通过尺寸、glyph、状态装饰区分，不重复建立近似母版。
2. 每条状态资源是一个导入条目，表格同时包含 ID、文件名和存放路径；动态文字、数值、连线和进度不生成图片。
3. Logo 单独使用 `LOGO-REF-001` 合同，先生成三种分辨率，再在其它提示词中上传 PNG 作为参考。
4. 导入工具保持动态扫描，不硬编码文档；manifest 登记新 ID 和目标路径，删除旧 UI ID。
