## Why

现有 UI 共用素材按九个旧文档和多个批次拆分，近似母版重复、状态差异只写颜色，且 Logo 没有独立冻结合同。生成和导入时无法保证同一母版的状态一致，也无法保证页面使用同一个 Logo。

## What Changes

- 删除旧的 `界面设计文档/共用素材/01~09` 及其 `批次/` 文档。
- 重建 Logo 三分辨率文档和四个 UI 共用母版文档；每份需求数不超过 10 条。
- 为每个状态写明结构、几何、纹理、明度和语义差异；同母版状态放在同一生产文档。
- 更新 18 个页面文档的共用依赖和 Logo 引用规则，刷新 `assets-manifest.json` 与批次导入工具说明。

## Scope

仅重做第一版 UI 共用美术设计合同、页面引用和导入目录；不修改世界资产设计，不生成实际图片或 Unity Prefab。

## Acceptance

新共用文档可被导入工具扫描；每份最多 10 条，目标目录存在，manifest 无悬空文档；旧 UI 编号和旧批次路径不再出现在界面设计文档；Logo 文档包含 256×256、1024×256、1920×480 三个输出并明确禁止重新绘制。
