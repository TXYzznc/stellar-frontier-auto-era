# alert-form

## MODIFIED Requirements

### Requirement: 警报列表与详情渲染

AlertForm MUST 从会话的区域警报账本经读模型渲染警报列表（活跃在前、恢复在后，账本已排序）与选中警报的详情字段；无警报时显示空态，缺会话／不在世界／区域未就绪时显示不可用态并说明原因。

#### Scenario: 列表按账本顺序展示

- **WHEN** 区域账本有活跃与历史警报
- **THEN** 列表行按「先活跃后历史」渲染，行含标题（等级·种类·来源）与描述（状态·次数·时间）

#### Scenario: 点行展开详情

- **WHEN** 用户点一条警报
- **THEN** 详情栏展开该警报的完整字段（原因／影响／真实恢复条件／时间／次数／阅读状态）

### Requirement: 标记已读只改阅读状态

AlertForm 的「标记已读」MUST 只改选中警报的阅读状态，不改变警报本身（不解决问题）；未读数随之经读模型 Changed 事件刷新。

#### Scenario: 标记已读

- **WHEN** 用户选中一条未读警报并点「标记已读」
- **THEN** 该警报变已读、未读数减一，活跃状态与次数不变

### Requirement: 定位来源对象

AlertForm 的「定位」MUST 在选中警报有有效来源身份时选中该区域对象并回到现场；来源为区域口径（Invalid）或已移除时在详情栏说明，不伪造聚焦。

#### Scenario: 有效机器来源

- **WHEN** 选中警报的来源是区域内的一台机器
- **THEN** 区域选中该机器（现场高亮）并关闭警报页回到现场

#### Scenario: 区域口径来源

- **WHEN** 选中警报的来源是 Invalid（多储能合计口径）
- **THEN** 详情栏说明「区域级警报，无单一对象可定位」，不关闭页面
