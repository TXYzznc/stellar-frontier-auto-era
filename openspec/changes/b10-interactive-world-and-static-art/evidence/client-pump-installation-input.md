## 推荐参考岸段（全部待用户决定，不写入配置）

沿用主美P值，不另造第二套坐标：以岸上部署根为原点，Y向上、+Z朝水、-Z交接。该局部坐标随建筑根变换，不是固定世界坐标。

| 项目 | P参考值/含义 |
|---|---|
| 岸上主体 | X[-1.5,1.5]、Y[0,1.10]、Z[-1,1]，地面Y=0 |
| 参考岸线/水面 | 局部直岸Z=1.10；水侧Z>1.10；静态水面Y=-0.12 |
| 管口 | 中心(0,-0.25,1.45)，管径0.18；管后缘Z1.36，比岸线多0.26m |
| 完整模型包络 | X[-1.5,1.5]、Y[-0.34,1.10]、Z[-1,1.70]；不能仅报主体高1.10 |
| 接近/等待参考点 | (0.65,0,-2.5) / (-2.6,0,-2.5)，不增加强制建筑间距 |

算术核对：底座至岸线0.10m；管口中心入水0.13m；按半径保守计入的管口上缘Y=-0.16，比水面低0.04m，下界-0.34比水面低0.22m。只能说明该参考剖面相容，不能证明整段弯管不穿岸或不触底。若参考检测球半径0.12，其上界为-0.13；该球与可见管径不同，也不能将球相交等同实体管完整浸没。

建议第一版先支持这种局部平直、岸上可站立的预设岸段，提供可安装区，而非承诺任意斜岸/凹岸/悬崖。这是待确认方案，不是新增拒绝阈值。现有位置吸附可能使上述精确偏移无法由任意世界岸线自然获得；将来应验证场地锚点与吸附一致，不能偷偷扩大允许距离。
