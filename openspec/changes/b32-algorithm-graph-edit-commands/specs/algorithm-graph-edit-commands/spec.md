## ADDED Requirements

### Requirement: 创建草稿节点

算法实例服务 SHALL 为选中的草稿实例创建带稳定身份的新节点。

#### Scenario: 创建节点

- **WHEN** 调用方以匹配的草稿修订请求创建一个已支持的节点种类
- **THEN** 服务分配非零节点 Id、将节点加入草稿、草稿修订加一并发布变更

#### Scenario: 过期或应用中

- **WHEN** 修订不匹配或实例正在应用
- **THEN** 服务拒绝创建且草稿保持不变

### Requirement: 强类型连接

算法实例服务 SHALL 仅创建强类型兼容的端口连接。

#### Scenario: 兼容端口

- **WHEN** 源输出端口与目标输入端口存在、兼容且目标输入未连接
- **THEN** 服务新增一条精确边、草稿修订加一并发布变更

#### Scenario: 不兼容或已占用输入

- **WHEN** 端口不存在、节点已删除、类型/单位/能力不兼容，或目标输入已连接
- **THEN** 服务拒绝连接且草稿保持不变

### Requirement: 断开精确边

算法实例服务 SHALL 按完整边身份断开单一连接。

#### Scenario: 断开已存在边

- **WHEN** 调用方以匹配修订提供完整的源节点、源端口、目标节点和目标端口
- **THEN** 服务只移除该边、草稿修订加一并发布变更

#### Scenario: 边不存在

- **WHEN** 请求的精确边不存在
- **THEN** 服务返回 false 且草稿保持不变

### Requirement: 读模型编辑入口

机器域算法读模型 SHALL 将创建、连接和断开命令转发至实例服务。

#### Scenario: 机器域

- **WHEN** 已选择算法实例且调用图编辑命令
- **THEN** 读模型读取当前草稿修订并转发服务命令

#### Scenario: 模板域或不可用域

- **WHEN** 模板域或不可用域接收图编辑命令
- **THEN** 返回 false 或零节点 Id，且不修改任何数据
