## 问题、证据与影响

1. 四图实际1672×941，未达1920×1080。不能报原生1920；保留原图后若用户允许，仅等比缩放加极少边界填充可标准化，不裁UI、不拉伸、不提升原生细节。此为交付尺寸，不宜反复重绘整套只为分辨率。
2. 编辑/绑定图把导航描述成可选“导航组件A-01”，还把机械臂作为不兼容导航组件列出。既有规则导航属于载体能力，不是可安装效应器/组件。建议导航节点明确绑定本机载体；集中绑定示例改为确有可选传感器的输入节点，避免向后续制作传递不存在的硬件。
3. 问题定位图称S-01组件已移除，同时旧生效R11仍有效。若旧版使用同一必要S-01，则不能保证旧版绿灯。建议示例明确“仅草稿引用S-02已失效，旧版仍使用有效S-01”，或改成仅草稿缺绑定，不以草稿隔离掩盖硬件移除对旧版的真实影响。
4. 左库把导航请求置于输入组；后续应按固定目录任务/载体能力职责放置。历史页等待安全点金色外观类似操作按钮，建议用明确非交互状态条。此两项无需重设计外框。
