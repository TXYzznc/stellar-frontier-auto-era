# GF UI 项目接入模板

本文件是 AutoEra（星际拓荒：自动纪元）的实际接入值。**项目差异记录**节之外的偏差视为违规。

## 项目基础

| 项目 | 填写内容 |
|---|---|
| Unity / GF 版本 | Unity `2022.3.62f3c1`；GF_X（UnityGameFramework） |
| UGUI 参考分辨率与 CanvasScaler | `1920×1080`；`Scale With Screen Size`、`MatchWidthOrHeight`、match `0.5`。值来自 `AppSettings.DesignResolution`，由 `GFBuiltin.UpdateCanvasScaler()` 下发到**场景根 Canvas** |
| UI 根目录、资源目录、资源加载方式 | 页面 Prefab：`Assets/Game/Prefabs/UI/Operations/`；路径由项目资源系统提供，Prefab 不硬编码磁盘路径 |
| UIGroup、排序、覆盖/暂停策略 | 由 GF 配置（`AppConfigs` / `UITable`）统一管理，不在子节点硬编码 |
| Form 基类、命名空间、脚本模板 | 基类 `AutoEraUiFormBase`（`: UIFormBase`）；命名空间 `AutoEra.UI`；脚本目录 `Assets/Game/Scripts/AutoEra/UI/` |
| 输入服务与 UI 输入映射 | 框架 InputModule；UI 意图经 `AutoEraUiIntentRouter` / `AutoEraUiIntentInputAdapter`，不得直接读 `Input` 或设备 |
| 字体、TMP Font Asset、本地化方案 | TMP Font Asset：`Assets/Game/Fonts/UI/SIMHEI SDF.asset`；可翻译文本由项目语言表输出，不烘焙进图片 |
| 支持分辨率、最小安全边距、目标平台 | AI 强制验收 **1920×1080**；16:10 / 21:9 由用户后续手动处理；目标平台 Windows 桌面 |

## 页面创建约定（本项目对 GF 默认流程的偏离）

| 项 | GF 默认 | 本项目要求 |
|---|---|---|
| 创建入口 | 右键 → GF Tools → 创建 → UIForm Prefab And Script | 同左，但模板与落点必须替换为项目版 |
| 脚本模板 | `UIScriptFileTemplate.txt` → `public partial class _CLASS_NAME_ : UIFormBase`（无命名空间） | `namespace AutoEra.UI` + `: AutoEraUiFormBase` + **必须实现其 abstract 成员** `OnOperationPresentationChanged` |
| 脚本落点 | `Assets/Game/Scripts/UI` | `Assets/Game/Scripts/AutoEra/UI` |
| 变量文件落点 | `Assets/Game/Scripts/UI/UIVariables`（当前不存在） | 需建目录或改指向 AutoEra 目录 |
| 类修饰符 | 模板已带 `partial` | **必须保持 `partial`**，否则 GF 的「生成变量代码」会直接失败并弹窗 |
| 根节点组件 | 模板带 Canvas + GraphicRaycaster + CanvasGroup | **不得带 Canvas / GraphicRaycaster / CanvasScaler**（页面动态挂到场景根 Canvas 下） |

## 项目差异记录

| 差异 | 原因 | 影响范围 | 替代做法 | 回滚条件 | 批准人 |
|---|---|---|---|---|---|
| UIForm Prefab 根节点**不带** Canvas / GraphicRaycaster / CanvasScaler | 页面由 GF 动态实例化到场景根 Canvas 下；每页自带 Canvas 等于每页私设渲染与缩放策略 | 全部 UIForm | 缩放由场景根 Canvas 承担，参考分辨率来自 `AppSettings.DesignResolution` | 若出现 Form 被独立实例化到无 Canvas 父级的场景 | 用户（2026-09-18） |
| 不用「先有效果图再拼 Prefab」，改为「先出原型再出效果图」 | 结构正确性可机器判定，外观依赖人工；顺序反转后结构不再被视觉稿绑死 | 全部 UI 页面 | 两阶段验收门见 07 | 用户明确要求恢复视觉稿先行 | 用户（2026-09-18） |
| 允许修改 `Assets/Game/ScriptsBuiltin/`（原「框架层禁改」解除） | 框架已有备份，项目按正式业务管理 | 框架核心与 Editor 工具链 | 修改需留痕（OpenSpec / 决策记录）；仍不得依赖 `AutoEra` 业务类型 | 回到纯框架基线分发 | 用户（2026-09-18） |
