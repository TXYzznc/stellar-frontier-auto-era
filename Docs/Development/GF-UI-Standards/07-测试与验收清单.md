# UI 测试与验收清单

本项目的界面分**两个独立的验收门**，责任方与判定方式完全不同，不得互相取代：

| 门 | 责任方 | 判定内容 | 是否 AI 完成门 |
|---|---|---|---|
| 门 1 原型验收 | AI | 结构、命名、布局、绑定、交互与生命周期正确 | **是** |
| 门 2 效果图验收 | 用户手动 | 外观是否达到效果图水准 | 否 |

两阶段定义见 [03-Prefab与RectTransform规范.md](./03-Prefab与RectTransform规范.md) 的「原型阶段与效果图阶段」。
效果图**不是**原型阶段的输入，也不构成 AI 任务的完成条件。

---

## 门 1：原型验收（AI 完成门）

门 1 的每一条都必须**可机器判定**——不允许"看起来对"这类只能人工判断的措辞。四层全部通过才算完成。

### L1 静态卫生

- [ ] 节点名 100% 落在 03 的前缀词表内；不存在表外前缀（如历史遗留的 `Art_`）。
- [ ] **前缀与组件匹配**：`Grp_` 无任何 Graphic；`Txt_` 不挂 Button；`Btn_` 必有 Button 且
      targetGraphic 指向自身 Image；`Deco_` 的 raycastTarget 为 false 且不承载文本。
- [ ] 同一 Form 内节点名唯一；无本地化文字、路径分隔符、无意义序号（`_01`/`_02`）。
- [ ] 不存在具名预览行或假数据节点；占位文案只表达功能提示（`—`、`--`），不含业务数值。
- [ ] 装饰性 Graphic（`Img_`/`Icon_`/`Deco_` 与非交互 `Txt_`）raycastTarget 为 false；
      可交互 Graphic 与遮罩为 true。
- [ ] 根节点为全屏 Stretch（anchorMin `(0,0)`、anchorMax `(1,1)`、offsets `0`），
      且**不含** Canvas、GraphicRaycaster、CanvasScaler。
- [ ] 无 Legacy `Text`、无默认字体、无 Missing Script、无悬空引用。

### L2 契约一致（结构 / 布局）

- [ ] prefab 的实际节点集合与层级**逐项等于**该页面的 `prefab-layout.md` 契约；
      **缺失项与多余项都算失败**（契约双向一致，不接受"多了也无害"）。
- [ ] 每个节点的 anchor / pivot / sizeDelta / anchoredPosition 与契约声明一致。
- [ ] 每个 `List_` 具备 `ScrollRect` + `Viewport_`（RectMask2D）+ `Content_`
      （LayoutGroup）三件套，且滚动方向与内容锚点一致。
- [ ] 每个列表有且仅有一个 `Item_*Template`，默认 inactive，其结构与契约声明的行结构一致。
- [ ] 不存在 LayoutGroup 与手写绝对坐标争夺同一子节点的情况；契约中标记为
      `layout: group` 的节点由布局组管理，标记为 `absolute` 的节点不被布局组约束。

### L3 绑定语义

- [ ] Form 脚本的每个 `SerializeField` 引用**非空**。
- [ ] 每个 `SerializeField` 的目标节点**路径等于契约声明**——只断言"非空"不足以通过。
      跨页错绑、绑到同名近似节点、绑到语义无关节点都算失败。
- [ ] 契约声明为可视通道的字段（如激活指示物）不得为 null。
- [ ] 绑定到 Button 的持久监听器指向存在的公开方法，且与契约声明的意图一致。

### L4 运行

- [ ] Unity 普通编译 0 error。
- [ ] 打开、切页、覆盖、恢复、Esc、返回主菜单与异常结束均无残留 overlay 或输入穿透。
- [ ] 默认焦点存在且落在契约声明的首个可选中节点上；关闭后焦点恢复。
- [ ] 加载、空、错误、禁用、超时、重复点击与取消都有可见且可恢复的行为。
- [ ] 关闭后无晚到回调、重复订阅、对象池 Item 泄漏或数据串写。

### L5 布局组尺寸与字体资产

- [ ] 父级 Horizontal/VerticalLayoutGroup 勾了 Control Child Size 的孩子都带 `LayoutElement`
      且 `preferredWidth/Height`（或 `minWidth/Height`）已填——缺了会被组算成 0 尺寸。
      由门 1 契约自检的 L5 项判定；契约侧由 `tools/ui_spec_to_contract.py` 自动补齐。
- [ ] 字体资产单图集（`m_IsMultiAtlasTexturesEnabled = 0`、`m_AtlasTextures` 只有一张）
      且界面与数据文本用到的字符已全部预烘。
- [ ] 33 个界面预制体强制生成网格后不出现 `TMP_SubMeshUI` 子对象；所有 TMP 文本引用同一个字体资产。
      由 `AutoEraUiFontGateEditModeTests`（资产态 + 生成态）判定。

### 门 1 的证据

- [ ] 上述各层的可复跑检查结果（EditMode 测试或审计脚本输出）。
- [ ] `python tools/run_project_checks.py` 全绿。
- [ ] 1920×1080 下的页面截图（**只作为结构/遮挡证据，不作为外观达标依据**）。

## 门 2：效果图验收（用户门）

由用户手动完成，**不阻塞也不构成 AI 任务完成条件**：

- [ ] 用户以原型为基准制作效果图。
- [ ] 用户手动把原型微调为效果图外观——只改颜色、Sprite、字号与位置微调；
      **不改结构、命名与绑定**。
- [ ] 微调后仍能通过门 1（结构未被破坏）。

---

## 不构成 AI 完成门的事项

以下项目历史上曾被当作验收条件，现已明确排除，不得再用来阻塞 AI 任务：

- 与效果图/视觉稿的外观一致度。
- 16:10、21:9 及其他比例的适配、截图与取证（由用户后续手动处理；AI 仍须使用合理锚点与
  CanvasScaler，但不出具额外比例证据）。
- 正式美术资源是否齐备（缺失项保留命名明确的占位 Image 即可）。

---

## 自动化对应关系

| 门 1 层级 | 对应手段 |
|---|---|
| L1 静态卫生 | EditMode 结构检查（命名词表、前缀↔组件、raycast、根节点） |
| L2 契约一致 | 契约文件 ↔ prefab 双向比对 |
| L3 绑定语义 | EditMode 绑定检查（目标路径比对） |
| L4 运行 | PlayMode smoke + `tools/run_project_checks.py`（编译、悬空引用、配置、资源表、两项审计） |

任何一层缺失机器判定手段时，先补齐手段再声称该层通过；不得以人工目视替代。
