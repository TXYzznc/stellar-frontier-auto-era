# 第一版资源点设施拆分草案

状态：用户已同意先拆分共用模块与专用设施；以下具体部件为待审核建议，尚未派发原画或建模。

依据：《第一版3D与复合表现实现方案讨论表》及《04-第一版/06-灰盒对象与交互规格》。功能锚点是不可渲染接口，不默认对应一件实体模型。尺寸、部件数量和摆位在用户审核后通过技术设计确定。

## 共用模块候选

- C01 边界立柱：用于端部、转角及少量边界提示；不要求整圈封闭。
- C02 围栏直段：按需组合；农田灌溉、机械臂伸入、树木倒落及钻探净空必须保留，不能以围栏封死作业面。
- C03 低矮边缘条：田地、暂存区、平台边缘可选；不规则地块可由短段或程序布置适配。
- C04 地面平台／承载板：用于设备与货物暂存，仅在功能需要时铺设。
- C05 高差衔接件：平台边缘、短坡或基础脚候选；按实际地形选择，不统一给所有资源点安装。
- C06 缓存底座／托盘：共用承载结构，木材、矿石、作物产物保留各自可见内容；与清单18、28、34–42合并设计，避免重复资产。
- C07 状态灯座／标识支架：有实体支撑，发光区独立控制；不自带操作台玩法。
- C08 地面标线：入口、物流、等待区域的可选视觉标记；可采用贴花，不为每个逻辑锚点制作网格。

以上均以静态模块为初步建议。若增加活动门、升降台或输送机构，先验证动作及参数，再按既有原画与建模流程生产。

## 农田

- 必需表现：可配置轮廓的土地区域、两种作物及其阶段、边缘产物暂存区。
- 共用模块候选：C01/C02少量边界、C03边缘、C06暂存承载、C07状态座、C08区域标记。
- 专用内容：土壤表面与湿度表现；作物种植表现位组织。土地区域不冻结为固定尺寸整块模型，不创建逐湿度格对象。
- 布局约束：照料与综合作业各1点、物流1点、等待2点；照料与综合作业可并行，需保留灌溉落点及机械臂作业空间。
- 不默认新增：固定灌溉管网、温室、农田自带机械臂或独立生产机器。

## 人工林

- 必需表现：树木生长与可切割区域、倒落空间、木材暂存区。
- 共用模块候选：C01边界提示、C06木材堆承载区、C07状态座、C08标记；围栏仅放在不影响切割和倒落的位置。
- 专用内容：用户选定的树木资源及任意位置切割工具适配；木材堆小/中/大，与货物清单共用。
- 布局约束：主要作业、物流、等待各1点；树木切割与再生要求等待工具选型后细化。
- 不默认新增：锯木厂、固定伐木机、自动种树机构。

## 矿山

- 必需表现：随总储量变化的山体块与矿石簇、可接触钻探面、矿石输出与暂存区。
- 共用模块候选：C01边界提示、C04必要承载板、C06矿石暂存区、C07状态座、C08标记。
- 专用内容：普通山体块族、矿石簇族、钻探面的空间组织；工业采掘设备作为结构与安全布置参考，不据此新增固定采矿设备。
- 布局约束：主要作业、物流、等待各1点；开采期间保持固定作业边界和导航阻挡。
- 生命周期：采空后山体消失，下次游戏换日解除矿山占地与导航限制。实体货物保留；外围设施是否保留或撤除需后续统一规则，不能自动删除货物。
- 不默认新增：地下矿井、轨道矿车、固定钻机、破碎机或选矿生产线。
