# 游戏设计名词表

> 状态：持续维护

| 名词 | 当前定义 |
|---|---|
| 机器 | 所有可由玩家下达指令控制、可以装配组件并运行算法的物理载体 |
| 星际拓荒者 | 玩家在世界观中的身份；亲自降临当前星球、以工程和自动化能力建立基地并逐步改造世界的人类工程师 |
| 独立星际拓荒计划 | 向合格拓荒者授予候选星球开发权并提供标准设备、协议和基础支持的计划；玩家主动加入并保留实际发展自主权 |
| 星际拓荒者联合体 | 运行独立星际拓荒计划的松散跨星系协作网络，由拓荒者、科研机构、设备制造商和星际商人共同组成；正式全称暂定 |
| 星拓联 | “星际拓荒者联合体”的暂定简称，用于中枢协议、任务、市场、物流和候选星球目录等系统表现 |
| 玩家实体 | 不存在的玩法概念；游戏不创建或模拟玩家角色的位置、身体、移动、生命值或现场到达过程 |
| 现场交互 | 镜头进入目标附近、目标出现在画面中并被选中后进行的对象操作；不要求玩家角色实际到达 |
| 建筑物 | 与机器、资源点互斥的友方可交互对象；提供固定加工、储存、供能、防护、连接或区域功能，不装配传感器、计算核心和效应器 |
| 传感器 | 获取一种或多种固定类型世界信息的机器组件 |
| 计算核心 | 为机器提供逻辑容量与运行算力的实体组件 |
| 效应器 | 通过一个或多个基础行为实际改变世界的机器组件 |
| 效应器安装位 | 机器载体上与效应器槽位对应的外观挂接位置；安装或替换组件只改变该位置的组件模型，不改变载体本体或其他安装位 |
| 模块化拓荒工业科技 | 人类标准设备的基础造型语言，强调标准化、耐用、可维修、接口清晰和功能可读性；高科技感主要由精密组件与界面承担 |
| 标准作业周期 | 跨系统使用的内部时间基准，固定为4分钟现实时间；用于校准生产、制造、任务和恢复节奏，不作为玩家可见的新计时单位 |
| 内部价值点 | 经济数值设计的隐藏换算单位；一级基础生产每个标准周期产生1000价值点，1金币对应1价值点，但不会成为玩家可见的新资源 |
| 算法 | 由节点和连线组成，将信息与事件转换为判断、状态和行为的规则结构 |
| 节点配置 | 会改变算法结构或执行关系的节点、连线、端口绑定和组件引用等配置；应用后需要重启机器 |
| 运行参数 | 从算法节点公开到机器或中枢面板的常量或阈值；点击应用后等待当前行为安全结束，再无重启生效 |
| 本地算法 | 安装在单台机器中，使用该机器资源并控制其组件的算法实例 |
| 中枢算法 | 在中枢中运行，接收远程信息并调度已连接机器的算法 |
| 算法库 | 保存结构有效算法模板的集合；模板应用时需要重新绑定具体组件 |
| 算力 | 传感器、节点和效应器在运行时占用的计算资源 |
| 逻辑容量 | 计算核心允许机器保存或启用的算法复杂度上限 |
| 算力策略 | 决定任务获得算力的顺序、优先级、排队和抢占方式的配置 |
| 运行 | 机器当前是否执行已应用的软件配置和算法 |
| 连接 | 机器与中枢之间的系统状态，由激活、损坏、区域信号或通信组件自动决定 |
| 区域 | 星球探索、拓荒、连接与经营权限的基本空间单位 |
| 勒米拉 | 当前星球的星拓联通用名称，英文为Lemyra；游戏早期与中期的主要舞台，由多个区域组成，长期可以从这里走向其他星球 |
| XTL-061 b | 勒米拉的星拓联目录编号；主要用于星图、科研资料与正式档案，普通界面优先显示“勒米拉” |
| 来源标签 | 标记作物、生物或其他内容来源与表现主题的非机制标签，例如“外星”；只用于图鉴、文本、美术和筛选，不自动改变属性或兼容规则 |
| 探索 | 消除未知区域灰雾，使玩家能够进入和建设前线设施的过程 |
| 拓荒 | 在已探索区域中维持信号塔、处理环境和生物冲突，最终使区域接入基地的过程 |
| 信号塔 | 开始并维持区域拓荒、连接区域与中枢的固定功能建筑 |
| 资源点 | 与机器、建筑物互斥，按生产模型保存或产生原料并提出通用作业需求的友方可交互对象；可以天然存在或由玩家建造 |
| 资源点缓存 | 资源点保存已产出但尚未运走资源的有限临时空间；主动采集受其容量限制，被动产出可能发生溢出损失 |
| 有限资源点 | 具有剩余储量，储量归零后进入枯竭状态并停止产出的资源点 |
| 可持续资源点 | 没有固定总储量，但需要满足维护、环境、输入或供能条件才能持续产出的资源点 |
| 生产模型 | 资源点运行方式的配置字段，当前包括储量开采、生长收获和连续生产 |
| 作业需求 | 资源点为了生产、维护、采集或转移资源而提出的通用工作要求 |
| 作业能力 | 机器通过传感器、效应器、移动结构和算法提供的可执行工作能力 |
| 基础运输能力 | 由移动能力和货舱容量共同构成，使机器能够在实体位置之间携带资源的能力集合 |
| 资源转移能力 | 由机械臂等效应器提供，在两个作用范围内的库存容器之间搬运资源的能力 |
| 自主装卸运输能力 | 基础运输能力与资源转移能力的组合，使一台机器能够独立完成装载、移动和卸载循环 |
| 转移资源 | 统一表达装载、卸载、取货和供料的效应器行为，根据来源、目标、资源类型和数量移动资源 |
| 货舱 | 机器用于实际携带资源的有限储存空间 |
| 仓库 | 固定功能建筑；负责把送达的木材、矿石、水和生物质结算为全局余额，并以独立容量储存其他实体物品 |
| 基地库存视图 | 同时显示不带地区位置的五种通用资源余额，以及中枢当前可远程观测的各仓库实体物品；后者不代表全局背包 |
| 对象状态传感器 | 由玩家绑定有限目标，在物理范围内读取建筑物、资源点或其他对象公开状态的通用传感器 |
| 基础土壤传感器 | 读取农田附近土壤湿度等环境数据的传感器；用于区分环境信息与资源点主动公开的对象状态 |
| 通信接收器 | 占用传感器槽位，使机器接收本地通信范围内请求的组件 |
| 通信发射器 | 占用效应器槽位，使机器发布请求及其更新或关闭状态的组件 |
| 通信请求 | 发送机器持续维护并向范围内接收器公开的需求；不指定接收者，由兼容机器自主加入任务队列 |
| 能力标签 | 由机器载体、结构、货舱、传感器或效应器提供，用于判断机器能否完成请求的通用能力描述 |
| 有效贡献 | 请求规定的实际工作结果；只有有效贡献发生时才减少请求的剩余需求量 |
| 后续责任 | 机器产生有效贡献后，因已经取得对象或改变状态而必须继续完成的独立收尾任务 |
| 原子动作 | 已开始后不能安全中断的最小执行单元；请求关闭时只允许完成当前原子动作，不保护整个任务 |
| 农田容量 | 一座农田在单个生产批次中最多能够种植的作物单位数 |
| 种植比例 | 当前作物批次的实际种植单位数除以农田容量，用于缩放数量型耗材和作业量 |
| 作物批次 | 在一座农田中以同一种作物和一次播种投入开始，共享生长进度与聚合环境状态的生产周期 |
| 播种作业 | 机器取得并消耗种子、向农田建立作物批次的生产作业；玩家不能直接对农田执行播种 |
| 平均单位产出 | 一个作物批次的有效收获产量除以实际种植单位数，用于比较不同种植规模的生产结果 |
| 完美生产 | 有效批次达到规定的平均单位产出且没有严重生产或收获损失的结果；首次达成可解锁对应资源点资料 |
| 资源点资料 | 完美生产后解锁的相关状态、最佳区间和作业类型信息，不包含完整机器配置或算法答案 |
| 通用资源 | 当前为金币、木材、矿石、水和生物质；以全局余额存在并直接扣除，最多六种的第六个位置暂时留空 |
| 全局资源余额 | 五种通用资源的全局数量；金币直接增加，木材、矿石、水和生物质只有完成仓库入库结算后才增加 |
| 入库结算 | 机器将木材、矿石、水或生物质送入仓库后，将实体数量原子转换为全局资源余额的过程；转换后不能反向取出 |
| 实体物品 | 保留具体所在容器与区域、需要实际装载和运输的物品，如种子、农产品、燃料、专有原料、高级材料与战利品 |
| 金币 | 不能直接开采、通过生产、任务、拓荒、战斗和交易等多种玩法获得的通用基础收益与离散操作成本 |
| 木材 | 完成入库结算后进入全局余额，主要用于基础建筑、机器结构、制造与加工的通用资源 |
| 矿石 | 完成入库结算后进入全局余额，主要用于机器、组件、建筑和高级材料制造的通用资源 |
| 水 | 完成入库结算后进入全局余额，用于农业、生产、环境处理和部分加工的通用资源 |
| 生物质 | 主要由作物收获后的机器清理作业获得，入库后用于生物发电、肥料、有机材料和生态补给的通用资源 |
| 银穗麦 | 第一版教学作物；生长较快、湿度要求宽松，收获银穗麦粒，清理后产生中等生物质 |
| 银穗麦种 | 种植一单位银穗麦时消耗的一单位种子 |
| 银穗麦粒 | 银穗麦成熟后由机器收获的农产品，偏向稳定商品与金币收益 |
| 赤芯芒 | 第一版中枢2级开放的能源作物；湿度要求较严格，清理后提供较多生物质 |
| 赤芯芒种 | 种植一单位赤芯芒时消耗的一单位种子 |
| 赤芯芒纤维 | 赤芯芒成熟后由机器收获的农产品，与清理阶段产生的生物质相互独立 |
| 应急生物质包 | 商店常驻的高价恢复商品；第一版每包提供10生物质、售价1200金币且不限购，用于玩家仍有金币时快速解除燃料短缺 |
| 物品价值 | 可出售物品的固定定价基准，不等同于商人的实际购买或回收价格 |
| 中枢等级 | 与经验绑定的玩家等级表现，限制区域数量、系统算力和机器组件等级上限 |
| 中枢经验 | 推动中枢等级提升的成长数值；主要由主线任务和有意义的日常游戏事件提供，不按高频原子动作发放 |
| 玩家任务 | 面向玩家的发展目标与功能引导；描述要达成的世界结果，不直接控制机器，也不进入机器任务队列 |
| 机器任务 | 由本地算法、中枢算法或通信请求产生，驱动机器完成一组效应器动作的运行时工作单元 |
| 日常游戏事件 | 正常生产经营中能够证明玩家完成一次有意义成果的事件，可提供少量经验，但不是每日任务系统 |
| 探索准备 | 第一版最后一个发展阶段，要求玩家制造并安装探索与远程通信组件，使已部署机器通过探索能力检查 |
| 探索能力检查 | 根据机器当前载体、组件、槽位、计算核心、部署、激活和损坏状态判断其是否具备探索资格的验证 |
| 图纸 | 永久解锁某类成品自主制造或建筑建造的进度内容；不限制玩家购买、持有或使用已获得成品 |
| 制造工坊 | 只提供固定制造功能的普通建筑物；不负责升级，自动供料、启动和收货由外部机器完成 |
| 组件库 | 无场景实体的玩家级管理界面，保存并出售未安装组件，同时索引、比较和升级已安装组件；已安装组件必须现场拆下后才能出售 |
| 机器库 | 无场景实体的玩家级管理界面，保存和出售未部署的完好机器载体并索引已部署机器；部署后仍需现场激活，出售载体前必须卸下组件 |
| 仓库自动分类 | 实体进入仓库后，按类型结算至金币余额、全局资源、组件库、机器库或当地实体库存的统一入库规则 |
| 封装组件 | 制造完成但尚未入库的组件实体，需要由机器搬运；进入仓库后自动归入组件库 |
| 封装载体 | 制造完成但尚未入库的机器载体实体，需要由机器搬运；进入仓库后自动归入机器库 |
| 作业礼包 | 商店中限购一次的机器载体与组件组合；购买后内容直接送入主基地仓库并自动分类，可以按普通规则出售，但不自动组装，也不包含算法模板 |
| 引导阶段 | 具有开始条件、目标、完成条件、图文说明和一次性解锁的教学单元；通过事件及世界状态共同判定进度 |
| 基础引导 | 从初始农田缺水开始，到第二台机器使人工林或矿山完成一次采集入库为止的首段强制教学 |
| 持续世界 | 世界进程与现实时间关联且不能由玩家暂停或减速；界面打开时仍继续运行的时间原则 |
| 区域专有原料 | 只在符合分布条件的部分资源点出现，但可以存在于多个区域的稀有原料 |
| 高级加工材料 | 由一种或多种原料经过加工设施制造出来的高级资源 |
| 资源重构厂 | 后期将大量通用原料和能源低效转换为少量已发现、可合成专有原料的设施 |
| 发电功率 | 区域电网当前单位时间内能够提供的能源能力 |
| 储能 | 储能设施中已经保存、能够在发电不足时释放的能源 |
| 区域电网 | 在一个区域内统一结算发电、用电和储能的简化供电系统 |
| 初始太阳能发电器 | 初始基地自带的低功率恢复设施；不消耗燃料，只在白天发电，用于避免金币与生物质同时耗尽造成永久能源死锁 |
| 待机能耗 | 设备已经获得供电、但未执行主要工作时使用的能耗数据 |
| 稳定能耗 | 设备以正常模式执行工作时使用的能耗数据 |
| 超载能耗 | 设备在玩家主动开启的超载模式下执行工作时使用的预留能耗数据 |
| 激活 | 机器已经完成现场初始化和注册、具有投入使用资格的持久状态；与是否通电相互独立 |
| 结构完整度 | 机器和可受损建筑的结构状态数值，作用类似HP；归零时触发完全损坏或被摧毁 |
| 完全损坏 | 机器结构完整度归零后的状态，会导致断电、断开中枢和激活失效，但机器实体与配置原则上保留 |
| 被摧毁 | 建筑结构完整度归零后的状态，固定功能停止，必须通过重新建造恢复 |
| 整机休眠 | 机器保持通电、激活和最低通信能力，但停止算法与组件工作，并保留原配置 |
| 组件休眠 | 传感器或效应器保持供电并消耗待机能耗，但被玩家禁止响应算法或执行工作 |
| 当前空闲 | 组件处于正常模式且暂未工作，使用待机能耗，但仍能响应后续算法请求 |
| 整机断电 | 只能在现场执行的物理断电操作；机器能耗归零并断开中枢，但不取消激活 |
| 模组 | 已取消的玩家层概念；设计文档不再使用它指代机器可安装能力 |
