# 开发执行约束

生效日期：2026-08-13

## 第一版开发任务表所有权

- `第一版开发任务表.xlsx` 是第一版任务顺序、依赖、里程碑、工时区间和状态的用户维护来源。
- 该工作簿仅允许用户修改。AI、Agent、SKILL、脚本和自动化工具对其只有只读权限。
- 禁止 AI 直接或间接编辑、覆盖、另存后替换、重算后回写该工作簿，也不得修改其中的状态、实际工时和备注。
- 若开发过程产生状态、工时、依赖或备注调整建议，AI 只能在对话、OpenSpec artifact 或独立报告中列出建议，由用户决定是否手动更新工作簿。

## 与 OpenSpec 的职责边界

- 开发任务表决定任务顺序、前置依赖和阶段验收门。
- `Docs/GameDesign/` 提供产品与系统设计依据。
- OpenSpec 负责单个或一组相关开发任务的需求、方案、可测试场景和实现任务分解。
- 代码、数据、资源与测试负责实现和验证；不得反向覆盖开发任务表。
