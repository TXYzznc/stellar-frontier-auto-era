## 共用原则

统一游戏美术语言、材质质感、精细程度、字体和色彩关系，不统一所有界面的实体外壳。基地中枢保持已验收的象牙白终端；其他家族按功能与使用场景设计轮廓、层次和控件。不能把“不复用中枢外壳”理解为只做细线、透明底或简陋布局草图。

同组主要复用外观母版，通过调整内部布局与显示内容复用；共用外观不合并业务权限。复杂工作台保留专用结构。组内小弹层可复用其他组的通用组件，不因此增加重复界面。

## 已确认分组

| 组 | 界面家族 | 内容与复用边界 |
|---|---|---|
| 01 | 主菜单与存档 | 主菜单、三个进度槽、新建/继续、进度详情；启动外观共用，损坏恢复调用通用恢复说明。 |
| 02 | 游戏内系统与设置 | 系统菜单、声音、操作/只读按键、显示与性能；设置内容供主菜单与游戏内复用，游戏内不暂停世界。 |
| 03 | 世界HUD | 资源/等级经验/算力/能源/时间摘要、任务追踪、引导与功能入口、警报和保存状态；一套模块化HUD。 |
| 04 | 基地中枢 | 总览、待处理任务、对象与系统、规则自动化、统计；共用已验收终端壳。能源、远程摘要和记录内嵌对应内容，不新增一级导航。 |
| 05 | 机器管理 | 概况、硬件、算法实例与参数、任务/效应器队列、算力、诊断历史、未部署整备；型号通过配置变化，现场/远程/整备权限分离。 |
| 06 | 资源点观察 | 农田、人工林、地表矿脉、水域；共用观察面板，替换生产/储量/缓存等模块。湿度为逐土地单元的有效传感数据，不改为整田单值；水域与水泵分离。 |
| 07 | 建筑设备与施工状态 | 建筑概况、水泵、生物质发电机、太阳能、蓄电池、施工进度与取消；按类型组合电力/燃料/储电/产出/施工模块，无机器激活和组件槽位。 |
| 08 | 制造工坊 | 配方详情、当前制造、等待队列、输出缓存、阻塞；专用三分区工作台，不压缩成普通建筑信息侧栏。 |
| 09 | 资产与模板目录 | 组件库未安装/已安装与比较、机器库未部署/已部署、仓库分类库存与详情/记录、算法库系统/玩家模板；共用分类筛选+列表/卡片+详情母版。机器独立实例、物品堆叠和模板语义保持区别。 |
| 10 | 商店与建造目录 | 购买、出售、商品/礼包详情、建筑图纸；共用项目选择+条件成本+操作结构，交易与进入放置模式的行为不同。 |
| 11 | 升级与改装 | 载体/组件升级、属性对比、原价/实价/扶持折扣、硬件影响；共用比较成本面板。超限改装开放内容仍需业务合同核对，不因分组新增槽位玩法。 |
| 12 | 选择与绑定 | 安装/替换组件选择、模板集中待绑定、节点组件/世界对象选择、兼容性与无可用项；复用选择器部件，集中绑定不是一次单选。 |
| 13 | 算法工作台 | 节点编辑、节点库、检查器、验证问题、诊断历史路径与当时数值、公开参数；编辑/诊断共用画布切换模式，不另造两套编辑器。 |
| 14 | 世界放置与定位辅助 | 建造、机器部署、朝向占地、合法性、确认取消、绑定对象选择提示；共用世界操作框架，具体条件与事务分离。 |
| 15 | 任务与记录阅读 | 主线任务进行中/可领取/已完成与奖励、警报列表详情、机器任务历史、能源停机记录；共用列表详情组件，不混淆玩家主线和机器执行任务；中枢内嵌时保留中枢壳。 |
| 16 | 教学、规则与知识阅读 | 基础引导、新功能说明、帮助、规则说明、作物图鉴详情；共用图文家族，分别添加进度或解锁字段。规则弹窗不扩张目录/搜索/收藏。 |
| 17 | 操作确认与输入 | 重命名、交易、升级/建造/部署、装卸影响、施工/制造取消退款、机器回收、算法应用/重置、模板/存档删除覆盖、强退、显示模式保留恢复；少量输入/普通/影响成本/强确认模板。 |
| 18 | 进度、结果与报告 | 加载/离线结算、回归报告、备份恢复、保存、安全停止等待、成功拒绝、合并交付、成长解锁、日常补给领取、第一版完成；轻量通知与完整报告分体量，复用部件，不为每次成功弹大窗。 |

## 入口与范围边界

- 仓库建筑信息头可复用07，完整库存使用09；组件安装抽屉使用12，不将组件库与选择器视为同一业务。
- 图鉴知识与日常补给需要承载内容，但独立入口/窗口形式尚未冻结；可用16/18部件，不擅自新增完整图鉴系统或签到界面。
- 探索准备能力清单可置于中枢/任务详情；第一版不实际探索，不制作出征/星球地图/探索结算。
- 空/加载/锁定/无权限/失效/断连/缺电、Hover/Pressed/Selected/Focus/Disabled、等待/成功/拒绝等属于状态，不各增一套外观。状态部件仍需完整美术设计。
- 施工围栏、装饰、虚影属于场景表现；开发测试面板和MotionGraph工具不计入正式玩家UI。
- 第一版只按1920×1080与PC键鼠。旧多比例、暂停/时间加速条款不作为本批新增需求；维修、战斗、实际探索、动态通信等范围外界面不生产。

现有正式美术主要覆盖03世界HUD（含对象轻量侧栏）、04中枢五页及部分通用确认/反馈组件；不意味着这些系统全部业务已接入。其余组不可由文档存在或开发菜单存在推定完成。
