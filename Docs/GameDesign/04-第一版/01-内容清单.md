# 第一版内容清单

> 状态：第一版设计内容与任务基线已冻结，进入OpenSpec分批开发
> 使用方式：只有在对应系统完成第一版细化后，才把条目从“待定”转为正式范围。

## 场景与区域

- [x] 第一版只制作一个可经营的初始区域；相邻未知区域只用于探索解锁表现。
- [x] 初始基地包含一座基础仓库。
- [x] 初始区域包含农田、人工林、矿山和浅层水源；只赠送农田基础机器。
- [x] 第一版结束于探索机器准备完成并解锁探索，不实现实际探索和拓荒。

## 生产内容

- [x] 五种通用资源：金币、木材、矿石、水、生物质；电能单独作为能源。
- [x] 两种作物：教学用银穗麦，以及中枢2级开放、偏向生物质产出的赤芯芒。
- [x] 初始农田已经种满银穗麦，初始仓库额外提供一批能够再次种满农田的银穗麦种。
- [x] 商店按整包出售种子：银穗麦种子包包含10个种子、售价600金币；赤芯芒种子包包含10个种子、售价900金币并在中枢2级开放。
- [x] 第一版商人支持直接出售全局通用资源，以及主基地基础仓库中的实体物品；确认后即时结算，不实现商队和交付等待。
- [x] 第一版实体经营物品只包含两种种子、两种农产品，以及尚未入库的封装组件或封装载体。
- [x] 第一版不加入区域专有原料、高级材料、合成材料、建筑材料和中间加工材料。
- [x] 最小宏观链：农业与基础采集→生物质能源→制造工坊→探索组件→探索机器准备。
- [x] 一座基础制造工坊，只有制造功能、单一队列和最小阻塞反馈。
- [x] 蓄电池、制造工坊、第二台发电机自动施工时间分别为2、3、4分钟；施工不要求机器或电能，可以并行并参与离线推进。
- [x] 四种第一版制造组件均耗时1分钟；队首开工时扣费，取消按剩余进度返还，离线制造不能越过实际阻塞。
- [x] 蓄电池、制造工坊和三种探索组件图纸由主线任务确定性奖励；其他基础内容按等级和初始配置开放。
- [x] 基础商店使用固定目录；购买物按仓库、组件库或机器库分类交付。

## 机器与自动化

- [x] 一种通用轮式载体：2个传感器槽位、2个效应器槽位、1个计算核心槽位，自带移动和基础货舱。
- [x] 四种传感器：对象状态、基础土壤、基础探索扫描器、远程通信接收器。
- [x] 一种基础计算核心；实际支持1～2级，数据允许3级上限。
- [x] 五种效应器：机械臂、水枪、切割、钻探、远程通信发射器。
- [x] 一级基础商店售价：轮式载体900、计算核心700、对象状态传感器400、土壤传感器500、机械臂700、水枪600、切割700、钻探800金币；探索与通信组件不在基础商店出售。
- [x] 两种作业礼包各限购一次；购买后内容直接经主基地仓库自动分类至机器库和组件库，可以按普通规则出售并允许有限倒卖收益。
- [x] 制造工坊的第一轮教学配方为基础计算核心×1，消耗200金币和2矿石；完成入库后用于探索机器准备。
- [x] 探索扫描器配方为300金币＋2矿石，通信接收器和发射器各为200金币＋2木材＋1矿石；三种组件均制造1分钟。
- [x] 第一版通用节点类别、八种强数据类型、组件端点、任务与队列基础规则和五个正式模板已经确认；面向编码的逐节点字段表在开发规格阶段整理。
- [x] 第一版只实现“带保护的优先级＋同级FIFO”默认算力策略，不开放策略切换。
- [x] 最小组件库和机器库：管理未安装组件、已安装组件索引、未部署载体及已部署机器索引。
- [x] 未安装组件和未部署完好载体可以出售；已安装组件必须现场拆下，已部署机器必须现场回收，损坏机器必须先修复；出售载体不连带出售组件。
- [x] 第一版不实现唯一主线能力出售保护或教学组件动态禁售；误售通过商店、永久图纸、每日金币和矿石补给恢复，后续依据试玩决定是否增加保护。
- [x] 一级升二级只强化原有属性并提高约20%能耗；中枢1～3级时金币和通用资源升级成本减半，首次升级任意对象到2级奖励500金币。
- [x] 玩家手动完成升级、改装、组件管理和配方选择；机器负责重复生产与世界作业。
- [x] 初始基地已有一台基础生物质发电机和一台低功率太阳能发电器；第一版包含基础蓄电池和第二台生物质发电机建设。
- [x] 蓄电基础任务先解锁制造工坊；工坊启动产生实际负载缺口后，才派发第二台生物质发电机的供电扩张任务。
- [x] 第一版能源基准：太阳能白天15功率，生物质发电机额定60功率且1生物质提供60电量，基础蓄电池容量240电量。
- [x] 资源发电站在固定额定功率内按电网需求自动调节输出，不提供玩家或算法可配置的功率上限；外部机器算法在通信能力解锁后可以修改启停、充电许可和储能目标等能源策略。
- [x] 第一版固定按免费环境能源、燃料发电、蓄电池和负载停机的顺序供电；免费盈余自动充电，燃料充电必须显式允许并设置目标比例。
- [x] 第一版机器、组件、仓库和制造工坊具有待机／稳定功率表；待机功率约为稳定功率的10%，具体字段独立配置。
- [x] 初始太阳能发电器不能拆除、出售或损坏，可以在无电状态下手动重新开启。
- [x] 第一版建筑、探索组件、商店成品、种子、礼包和应急商品的成本与数量已经冻结。

## 挑战

- [x] 第一版环境挑战为农田湿度与昼夜太阳能，不增加天气、生态灾害或其他环境变量。
- [x] 第一版系统约束为资源产出与库存、缓存和货舱、固定路线运输、能源供需、算力队列、制造成本与时间。
- [x] 第一版不实现生物或其他外部威胁，不产生正常流程中的结构损伤。
- [x] 第一版失败与恢复集中于缺电、资源不足、缓存／实体仓库容量不足、算法异常、算力等待、任务阻塞和目标失效；不实现战损维修。

## 界面与基础功能

- [x] 轻叙事框架：短开局图文、中枢登记与星球档案、任务和内容简述、星拓联协议通知。
- [x] 第一版不制作过场动画、具名NPC持续对话、分支剧情、对话选择和大量日志。
- [x] 基础引导核心框架、HUD常驻入口、图文说明弹窗和分阶段完成判定。
- [x] 基础引导结束后继续提供一段自由经营，不以第二资源点首次入库作为版本终点。
- [x] 基础引导结束后自动派发可并行主线任务；不实现支线、每日任务、随机任务和限时任务。
- [x] 中枢从1级成长到3级；累计经验阈值为0／500／1500，主线合计1550经验，经营事件提供补充经验且不设置每日上限或递减。
- [x] HUD与中枢界面最低信息集：HUD顶部状态、任务警报和底部入口，以及中枢总览／机器／能源／记录四页已确认。
- [x] 通用规则说明按钮：单个按钮通过描述ID绑定配置表中的一条完整说明，并使用统一弹窗显示；不制作规则知识库与多条拼接。
- [x] 机器现场交互界面：概况、硬件、算法、任务与诊断四页及现场管理边界已确认。
- [x] 资源点与建筑现场界面：共同信息、各第一版对象专属状态和禁止玩家直接作业边界已确认。
- [x] 节点算法编辑器：草稿与运行实例分离、强类型端口交互、容量／问题显示、应用验证、诊断模式和算法库集中绑定流程已确认。
- [x] 日志、警报和诊断信息：三级警报、同源合并、已读／活跃分离、定位、任务与算法历史、离线报告和中枢记录入口已确认。
- [x] 组件库、机器库、商店、建造、任务、能源、工坊、仓库、系统菜单和存档恢复等第一版主要界面流程已确认。
- [x] 第一版以PC键鼠操作，支持WASD镜头移动、右键拖动旋转、滚轮缩放、左键选择、F聚焦和Esc分层返回；所有输入统一经过InputModule。
- [x] 第一版UI只以1920×1080作为设计、开发和验收分辨率，不承担低分辨率、超宽屏、移动端和其他宽高比适配。
- [x] UI语义颜色、节点／端口／连线视觉区分与诊断高亮规则已确认；颜色不能作为唯一信息载体。
- [x] 第一版灰盒覆盖范围、锚点／碰撞／作业点要求及逻辑根与视觉子对象分离的替换边界已确认。
- [x] 第一版灰盒使用1单位＝1米、0.5米位置吸附和15度旋转吸附；轮式载体尺寸、导航半径及全部资源点／建筑初始占地已确认。
- [x] 第一版货舱、资源缓存、仓库、工坊输出缓存、移动速度、机械臂、水枪、切割、钻探和阻塞阈值已形成统一规格。
- [x] 第一版逐对象灰盒结构、安装位类别、状态、作业动作和锚点数量已形成统一规格。
- [x] 基础引导、主线摘要、规则描述ID、核心警报、对象短描述和离线报告文本已形成统一文案规格。
- [x] 设置页最小范围已确认：声音、镜头操作、只读InputModule按键表、显示模式、垂直同步、帧率和基础画质；不做改键、分辨率列表和UI缩放。
- [x] 存档与读取：安全快照、异步原子写入、校验备份恢复、永久ID引用和中断后继续均已确认。
- [x] 第一版存档框架采用3个独立进度槽，每槽1份正式存档和3份内部滚动备份；不提供任意手动回档。
- [x] 离线使用确定性事件跳跃结算和固定同刻事件顺序，不截断实际离线时间，不逐帧重播无意义过程。
- [x] 第一版离线白名单、阻塞原则和回归报告已经确认；离线只执行既有决定，不替玩家产生新决策。

## 明确排除

- [x] 程序灰盒阶段不等待正式美术，但第一版最终验收`G8`必须等待正式美术集成验收`ART-G2`通过。
- [x] 完整科技树和长期终局不进入第一版。
- [x] 第一版实现事件驱动离线结算，不设置离线收益时长上限；只推进第一版已经实现的确定性系统，未实现系统不参与结算。
- [x] 大量区域、敌人、机器和部件不进入第一版。
- [x] 完整科技树、图纸掉落池、图纸商人、重复图纸循环和商店轮换不进入第一版。
- [x] 工坊自动升级、复杂并行产线和通用资源反向取出不进入第一版。
- [x] 世界暂停和减速不进入游戏；第一版所有界面打开时世界继续运行。
- [x] 不实现实际探索、灰雾推进、探索战斗、前线建设、信号塔和正式拓荒。
- [x] 不实现其他载体、武器、完整通信协作、除初始应急太阳能发电器之外的其他发电方式和高级能源策略。
- [x] 通信组件第一版只支持制造、管理、安装、状态显示和探索机器能力检查；不运行请求广播、动态运输、中枢远程调度和通信范围模拟。
- [x] 第一版只保留结构完整度字段、状态接口、存档和开发测试入口；不实现玩家可经历的损坏、维修、重建与伤害来源。
