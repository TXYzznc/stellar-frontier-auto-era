# 第一版验收与测试计划

> 状态：验收目标已确认；可执行测试场景随各批OpenSpec建立并持续汇总

## 核心体验验收

- 玩家能否在没有长篇说明的情况下建立第一条有效算法。
- 玩家能否从画面和界面判断算法是否生效。
- 算法失败时，玩家能否定位原因并主动修改。
- 同一个生产问题是否至少存在两种有意义的解决方法。
- 系统稳定后，玩家是否愿意继续优化或扩展。

## 功能验收范围

- 机器硬件安装、停止、激活和运行。
- 节点创建、连接、验证、应用和重启。
- 传感器信息传入算法并驱动效应器行为。
- 算力占用、任务排队和状态显示。
- 生产对象状态变化及资源结算。
- 警报、错误、日志和恢复流程。
- 保存、退出、重新载入后状态一致。

## 按OpenSpec逐步完成

- 各功能的可执行测试步骤由对应OpenSpec覆盖并在实现前确定。
- 性能预算、稳定运行时长、边界条件和破坏性测试随对应系统OpenSpec收敛。
- 首轮试玩人数、观察方法和通过标准在G8前建立专门验收批次。
- 第一版构建与交付验收标准在阶段8和G8对应OpenSpec中完成。
