# 第一版流程与主线任务

> 状态：版本起止边界、主线阶段、最小内容与第一版数值已确认

## 版本终点

第一版完成第一次拓荒之前的内容，结束在：

> 玩家达到中枢3级，组装、部署并现场激活一台通过能力检查的探索机器，区域容量提高到2并解锁区域探索；第一版不实际派出探索机器。

第一版不实现灰雾探索、探索值、未知区域远程运行、探索攻击、前线建设、信号塔和正式拓荒。

## 总体流程

```text
基础引导
→ 基础供应
→ 中枢2级
→ 蓄电基础
→ 建立制造能力
→ 供电扩张（与制造任务并行）
→ 探索准备
→ 中枢3级
→ 探索机器能力检查
→ 解锁区域探索
→ 第一版结束
```

第一版从开始到解锁探索的正常流程暂定约90～120分钟。各阶段的资源成本、任务要求和等待时间必须以该总时长为约束，避免玩家通过无意义等待推进。

联合数值校验要求第一版不能只依赖固定奖励完成全部发展。按最低第一批产量计算，购买两份作业礼包、完成基础供应并进入中枢2级后仍可正常推进；后续固定发展保留约2640金币经营缺口，预期通过约2个正常银穗麦批次补足。蓄电池之后的固定材料需求约为39木材与24矿石，对应人工林4周期、矿山5周期，并应与农业、施工和任务并行而非形成纯等待。

## 阶段一：基础引导

基础引导按[新手引导与复杂度释放](../03-玩家体验/03-新手引导与复杂度释放.md)执行，结束条件为第二台机器使人工林或矿山完成一次有效采集与入库。

完成基础引导自动获得200经验。

新存档初始拥有3000金币、40水、10生物质，木材和矿石均为0。人工林与矿山作业礼包均售价2500金币；完成基础引导奖励1200金币。

初始矿山具有100矿石总储量且不再生。中枢2级后，商店开放5矿石／1500金币且不限购的基础矿石补给包，作为矿山耗尽或误消费后的高成本恢复渠道。

每个存档每个现实自然日首次登录后可以领取一次800金币的星拓联日常补给，首日同样可以领取。补给未领取不累积，不提供经验或任务进度，主要用于避免玩家因错误消费进入永久经济死锁；金额允许在原型测试中调整。

## 阶段二：基础供应任务组

基础引导结束后自动并行派发：

- 木材供应：人工林木材完成有效入库。
- 矿石供应：矿山矿石完成有效入库。
- 持续水源：浅层水源的水完成有效入库。
- 农业循环：完成新的农田批次并获得生物质。

玩家在引导中已经完成的目标通过世界状态复查计入。完成任务组并积累足够经验后升到中枢2级，开放组件升级和能源阶段。

四项子任务各奖励300金币和50经验；全部完成后额外奖励1000金币和100经验。基础引导与任务组累计正好提供500经验，使正常流程在此达到中枢2级。

中枢2级同时派发首次升级任务：将任意机器载体、传感器、计算核心或效应器升级到2级，界面推荐初始农田机器的基础计算核心。任务完成奖励500金币和100经验，不作为蓄电基础任务的前置条件。

## 阶段三：蓄电基础任务组

初始基地已经建有一台基础生物质发电机、一台低功率太阳能发电器，并拥有10生物质，对应600电量。太阳能发电器只在白天工作，负责提供能源死锁时的最低恢复功率，不作为正常扩张的主要电源。引导期间只被动显示能源结果，不要求玩家处理供电。

初始太阳能发电器在第一版中不能拆除、出售或损坏，可以在无电状态下手动重新开启。初始农田已经种满银穗麦，初始仓库额外提供一批足以再次种满该农田的银穗麦种。

第一版昼夜周期为24分钟，其中16分钟具有有效日照、8分钟无日照；新存档从白天早期开始。

中枢2级后派发：

- 获得基础蓄电池图纸并完成建造。
- 任务派发后累计向蓄电池充入至少30电量，并累计放出至少30电量；任务前历史不计入。
- 当前全局生物质与发电机尚未消耗完的燃料折算量合计不少于10生物质，且能源系统没有严重异常。

第一版能源只实现生物质发电机、作为恢复保障的初始太阳能发电器、基础蓄电池、区域发电／用电／储能、默认供电优先级、缺电停机恢复、警报和最小历史记录。商店常驻应急生物质包，每包提供10生物质、售价1200金币且不限购；除初始设施外，不开放太阳能建造与扩张。

默认供电顺序为太阳能、已开启的生物质发电机、蓄电池和负载停机。免费太阳能盈余自动充电；生物质发电只有在玩家明确允许并设置目标储能比例后才主动为蓄电池充电。

完成蓄电基础任务后，获得1000金币和200经验，并确定性获得基础制造工坊图纸与基础计算核心制造图纸。

基础蓄电池施工时间为2分钟。玩家确认位置后自动施工，不需要机器或电能；施工期间可以继续处理其他任务。

## 阶段四：制造能力任务组

- 建造基础制造工坊。
- 制造工坊稳定运行且区域当前真实负载首次超过单台基础生物质发电机60额定功率时，派发供电扩张任务；太阳能或蓄电池暂时覆盖缺口不影响派发。
- 供电扩张要求第二台基础生物质发电机建成并开启，在制造工坊或其他有效负载实际运行的条件下，区域连续2分钟没有对象因缺电停机。发生缺电停机后计时归零；关闭全部负载不能完成。
- 使用200金币和2矿石制造一个基础计算核心。
- 由机器把工坊输出缓存中的封装组件搬运到仓库。
- 仓库自动分类后，确认组件进入组件库。
- 将制造完成的基础计算核心用于后续探索机器准备。

完成制造能力任务组获得250经验；完成并行的供电扩张任务获得200经验。

制造能力任务与供电扩张任务均完成后，确定性获得：

- 基础探索扫描器图纸。
- 远程通信接收器图纸。
- 远程通信发射器图纸。

工坊只有单一队列，同一时间制造一个物品。断电、资源不足或输出缓存已满时暂停并显示原因；断电不清空进度。第一版不实现品质、随机属性、副产物、批量制造和多队列。

基础制造工坊建造消耗1500金币、15木材和8矿石，总内部价值4600。

制造工坊施工时间为3分钟；首次基础计算核心制造时间为1分钟。第二台生物质发电机施工时间为4分钟。三种探索组件各制造1分钟。

## 仓库自动分类

所有实体进入仓库后按类别处理：

```text
金币 → 全局金币余额
木材／矿石／水／生物质 → 全局资源余额
组件 → 组件库
未部署机器载体 → 机器库
其他物资 → 保留在当地仓库实体库存
```

制造组件在工坊输出缓存和运输途中属于封装实体，入库后进入组件库。机器载体采用同一规则进入机器库。

## 阶段五：探索准备任务组

- 制造基础探索扫描器、远程通信接收器和远程通信发射器：扫描器消耗300金币和2矿石，两个通信组件各消耗200金币、2木材和1矿石，三者制造时间各1分钟。
- 准备满足槽位要求的移动机器载体与基础计算核心。
- 安装组件并完成合法配置。
- 把机器部署到场景并现场激活。
- 通过中枢探索能力检查。

探索机器最低能力条件：

```text
移动能力
+ 探索能力
+ 远程通信接收能力
+ 远程通信发送能力
+ 足够的计算核心与槽位
+ 已部署、已激活、未损坏
= 探索准备完成
```

系统按能力检查，不绑定固定载体或礼包。探索准备任务组完成时获得300经验；该任务本身不要求先达到中枢3级。经验结算后，系统重新检查“中枢3级＋任务完成＋机器能力通过”，满足全部条件后区域容量提高到2并解锁区域探索入口；不执行实际探索算法。

三种探索组件合计消耗700金币、4木材和4矿石，单队列制造时间合计3分钟。若使用此前制造的基础计算核心并新购轮式载体，探索机器新增准备成本合计为1600金币、4木材和4矿石；允许改装已有机器降低成本。

取得探索组件图纸后，供电扩张的稳定验证、探索组件制造、组件运输和探索机器整备允许并行。组件可以逐件入库和安装，不要求三件全部完成后才开始整备。

## 第一版机器与组件清单

### 机器载体

- 通用轮式载体：2个传感器槽位、2个效应器槽位、1个计算核心槽位，自带移动能力和基础货舱。

### 传感器

- 对象状态传感器。
- 基础土壤传感器。
- 基础探索扫描器。
- 远程通信接收器。

### 效应器

- 机械臂：播种、收获、清理及统一资源转移。
- 水枪。
- 切割效应器。
- 钻探效应器。
- 远程通信发射器。

### 计算核心

- 一种基础计算核心；1级为50算力／40逻辑容量，2级为75算力／50逻辑容量。数据允许3级上限，第一版不强制制作完整3级属性。

浅层水源按连续生产型资源点运行，水进入缓存后由机械臂按照统一资源转移规则运入仓库，不增加水泵、管道或专用液体物流系统。

## 明确排除

- 其他机器载体、武器和战斗组件。
- 完整本地通信请求实战。
- 超载模式、随机属性、品质和稀有度。
- 除初始应急太阳能发电器外的其他发电方式、跨区域输电、电线、损耗和高级供电策略。
- 探索和拓荒的实际运行内容。
