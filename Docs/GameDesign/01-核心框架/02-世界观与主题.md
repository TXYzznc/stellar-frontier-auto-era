# 世界观与主题：星际拓荒

> 状态：玩家身份与长期空间尺度已确认，降临原因、星球设定与叙事表现待设计

## 当前共识

- 整体世界观采用星际拓荒。
- 玩家是一名亲自降临当前星球的星际拓荒者，职业背景可以设定为工程师；不是基地AI、远程公司的操作员或抽象殖民组织。
- 玩家因为尚未确定的原因降临这颗星球，从初始落脚点开始建设基地、理解环境并逐步把星球塑造成属于自己的世界。
- 当前初步设定为：玩家主动参加“独立星际拓荒计划”，取得一颗候选星球的个人开发权，携带标准拓荒设备降临并开始建设。
- 中枢协议、初始设施、基础机器、商店、图纸和发展任务可以由拓荒计划的标准支持体系提供；这些内容用于解释游戏系统，不代表组织持续替玩家决定发展方向。
- 玩家拥有实际发展自主权，可以选择机器配置、经营方式以及未来对星球的改造路线。任务系统主要承担学习、阶段目标和支持奖励，不是强制剧情命令链。
- 独立星际拓荒计划由一个松散的跨星系协作网络运行，当前暂称“星际拓荒者联合体”，简称“星拓联”。
- 星拓联由拓荒者、科研机构、设备制造商和星际商人共同组成，不是政府，也不是玩家的雇主。科研机构负责候选星球测绘与资料，制造商和商人提供标准设备、图纸、物流与回收服务。
- 星拓联提供拓荒资格、标准中枢协议和阶段支持，但玩家取得资格后保留经营与改造自主权。
- 外星环境能够自然承载农业、资源、能源、自动化、防御与生态挑战。
- 拓荒主题应为长期扩张提供从“存活”到“改变世界”的目标尺度。
- 当前星球是游戏早期和中期的主要舞台；长期成长可以让玩家离开当前星球并探索更多星球，但不进入第一版范围。

## 与玩法的结合

| 原始玩法概念 | 星际拓荒表达 |
|---|---|
| 农田与作物 | 外星土壤、生态穹顶、适应性作物 |
| 浇水与施肥 | 水循环、营养液、土壤成分调节 |
| 天气限制 | 双日灼烧、极夜、辐射、孢子季、地质活动 |
| 野怪袭击 | 本土生物的觅食、迁徙、领地或生态反应 |
| 建筑升级 | 拓荒科技、机器与设备蓝图、能源与材料突破 |
| 家园扩张 | 前哨扩建、区域改造、生态稳定化 |

## 人类设备科技风格

- 人类设备采用“模块化拓荒工业科技”作为基础风格，强调标准化、耐用、可维修和功能可读性。
- 机器载体使用清晰的结构、接口、转轴、装甲分区和工程材料；效应器按照DEC-052只在对应安装位局部挂接，不改变载体其他部分。
- 高科技感主要由传感器、计算核心、精密材料、中枢界面和状态反馈承担；不使用纳米变形等表现掩盖组件结构。
- 设备不采用所有功能都包裹在纯白光滑外壳中的统一未来盒子造型，也不以废土拼装或生物机械作为人类标准设备的主基调。
- 该方向只确定总体造型语言。不同载体的效应器安装位、尺寸、朝向、材质比例与具体轮廓在对应内容和美术规格阶段设计。

## 候选长期主题

- **征服型**：逐步压制环境，将星球改造成人类适居地。
- **共生型**：理解本土生态，建立能够共同存在的生产体系。
- **选择型**：玩家最终在改造、共生和撤离之间作出方向选择。

当前已经确认长期可以形成“持续改造、生态共生或混合路线”的选择；路线如何通过系统行为形成、是否存在撤离结局，仍未定案。

## 情感锚点候选

- 具备名称、状态、行为习惯和成长痕迹的机器人。
- 从简陋设施逐渐成长的基地本身。
- 总部通讯、拓荒者记录、遗迹日志或远端殖民者。
- 本土生物从“野怪”逐步变为可理解的生态成员。

## 当前叙事边界

- 第一版只需要交代玩家身份、降临结果、初始处境以及为什么必须建立自动化生产，不展开跨星球内容。
- 第一版采用轻叙事框架：以一段短文本或3～5张图文卡片介绍星拓联、勒米拉和玩家的拓荒资格；中枢首次启动显示简短登记信息与星球档案。
- 主线任务、系统解锁、机器、组件、作物和建筑可以使用少量世界观说明文字；星拓联协议通知只包装既有功能与奖励，不建立额外剧情任务系统。
- 第一版不制作过场动画、持续对话的具名NPC、分支剧情、对话选择或大量日志。世界观说明不能阻塞玩家进入基础引导。
- 世界观需要解释中枢、商店交付、机器现场激活、初始设施和任务来源，但不能要求增加第一版核心玩法之外的大量剧情系统。
- 星际拓荒者是玩家的叙事身份，不是世界模拟中的实体对象。游戏不追踪玩家身体、位置、移动、生命维持或受伤状态，也不会要求玩家角色出现在画面中。
- “现场交互”是玩法层的空间操作边界：镜头进入对象附近、使对象出现在画面中并选中对象后，即可进行现场操作；它不表示玩家角色亲自移动到目标旁边。
- 当前星球需要一个具有科学命名感的正式名称。名称可以向经典科幻作品致敬，但不能直接照搬著名星球名称。
- 当前星球采用两段式命名：星拓联目录编号为“XTL-061 b”，星拓联通用名称为“勒米拉（Lemyra）”。不增加本土名称、发现者名称或其他平行称呼。
- 普通任务、HUD和叙事主要使用“勒米拉”；星图、科研资料和正式档案显示“勒米拉（XTL-061 b）”或分别列出目录编号与通用名称。
- “061”和“Lemyra”以较隐蔽的方式向斯坦尼斯瓦夫·莱姆及1961年出版的《索拉里斯》致敬，但不继承《索拉里斯》的海洋行星或智慧海洋设定。
- 勒米拉是一颗允许露天工程、拥有液态水和复杂生态，但整体环境明显区别于地球的基本宜居星球。不同区域可以具有不同地貌、资源和生态特征。
- 勒米拉存在复杂的植物与动物；游戏初期没有发现智慧文明。是否在长期内容中存在智慧文明暂不作结论，第一版不以此建立剧情或系统。
- 地球来源与勒米拉本土来源只属于内容背景或可选标签，不形成两套生物、作物、资源点或生态机制。所有内容继续使用统一属性、状态、传感器、作业、算法和伤害规则。
- “外星”标签最多用于图鉴筛选、描述、美术表现和配置已有属性；标签本身不能自动附带抗性、兼容性、专用传感器、专属效应器或额外作业需求。
- 作物是否容易生长、需要哪些环境条件，直接由各作物配置决定，不能仅根据“地球／外星”来源推导。
