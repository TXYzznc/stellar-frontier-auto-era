# 长期经营与核心循环

> 状态：宏观循环、经济方向与持续时间原则已确认；具体节奏待设计

## 宏观循环

```text
开辟区域
→ 建设生产与生存设施
→ 配置自动化
→ 获取作物、材料及击退生物的收益
→ 购买或解锁机器、传感器、计算核心、效应器与建筑
→ 强化生产、防御和维护能力
→ 扩张到更高风险、更高收益的区域
→ 遭遇新约束并重新设计系统
```

## 时间尺度

世界进程与现实时间关联。玩家不能暂停或减速整个世界；打开中枢、算法编辑器、引导或其他界面时世界继续运行。玩家可以休眠机器、停止建筑或关闭局部组件，但这些是局部管理行为，不是暂停世界。

### 短循环：几十秒至数分钟

- 发现问题。
- 调整一条规则或部署一个设施。
- 观察结果并获得即时反馈。

### 单次在线 Session

- 收取并分析离线结果。
- 选择本次发展方向。
- 建设、优化、探索或处理事件。
- 为下一段离线运行做好准备。

### 长期循环

- 解锁区域与能力。
- 建立更大、更复杂的基地网络。
- 改善星球环境或推进拓荒目标。
- 形成具有个人风格的自动化方案。

## 经济来源候选

- 农作物与生态产品。
- 矿物、能源和加工材料。
- 击退或研究本土生物获得的资源。
- 探索获得的蓝图与稀有材料。
- 贸易、委托或阶段性拓荒奖励。

## 循环健康性要求

- 扩张应增加新决策，而不只是把同一生产线复制更多次。
- 新设备应增加组合可能或改变旧规则，不只提供百分比增益。
- 玩家上线后应先获得信息与选择权，而不是立刻被维护杂务淹没。
- 早期设计不能被后期完全作废；升级可增加复用、模板化和分层管理能力。

## 开放问题

- 现实时间与游戏时间的比例及离线结算上限是多少？
- 作物无人照料时是减产、停长，还是死亡？离线惩罚多重才公平？
- 在已确认的“探索—信号塔拓荒—区域接入”流程之外，扩张还需要哪些资源、科技或风险条件？
