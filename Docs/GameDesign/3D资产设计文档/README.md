# 3D 资产设计文档

这里单独维护已经基本完成的世界 3D 资产设计：共享模块、机器/建筑/资源点、3D 技术锚点和组合效果图。

这些文档不属于 `11-美术规范/世界资产设计文档` 的当前非 3D 生产范围，也不会被美术批量导入工具扫描。后续如果修改 3D 内容，只在这里处理。

## 文档分区

- `01-基础规则`：3D 共用模块、锚点、材质和验收合同。
- `02-共享组件`：材质、接口、地表、状态灯、包装等可复用模块。
- `03-可放置对象`：机器、传感器、建筑和资源点。
- `05-效果演示`：3D 对象的区域、工作和施工组合验证图。
- `样例试制`：早期 3D 样例，不作为当前批次导入任务。
