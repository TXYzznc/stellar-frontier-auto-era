# 战斗、原生生物与生态系统

> 状态：暂未完成

> 第一版边界：不实现生物威胁、战斗、伤害、防御、维修和重建。第一版挑战只来自农业环境条件、能源供需、资源缓存与运输阻塞、算法配置、算力队列以及制造安排。本系统从实际探索与拓荒版本开始进入开发范围。

## 已确认方向

- 拓荒主要解决玩家与环境、原生生物之间的冲突。
- 机器没有“战斗型”职业；攻击能力来自安装的传感器、效应器和算法。
- 探索机器可能遭受攻击，需要其他配置了防御能力的机器保护。
- 信号塔运行会使附近生物狂化，压力分阶段增强，并在完成前出现有预警的高峰。
- 拓荒成功后区域不会变成绝对安全区。
- 长期可能存在改造、共存或混合处理生态的路线。

## 暂未完成

- 原生生物的类别、行为动机和生态关系。
- 敌对状态、目标识别、仇恨与攻击选择。
- 射击、弹药、命中、伤害、装甲和死亡规则。
- 生物生成、迁移、聚集与袭击的运行模型。
- 环境挑战与战斗挑战的区别和组合方式。
- 首个实际探索／拓荒版本的最小威胁、最小防御方案和验收场景。
