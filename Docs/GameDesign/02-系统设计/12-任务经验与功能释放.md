# 任务、经验与功能释放系统

> 状态：第一版任务结构、1～3级经验、奖励、界面与核心文案已完成

## 系统目的

基础引导结束后，任务系统向玩家提供阶段目标，让玩家在自由经营中逐步接触能源、制造和探索准备。中枢等级通过经验逐步释放学习内容，而不是制造需要重复刷取的等级门槛。

## 三种任务概念

- **玩家任务**：面向玩家的发展目标，提供经验、资源、图纸或系统解锁。
- **机器任务**：机器准备执行的完整世界作业，由算法或通信请求产生。
- **通信请求**：机器在本地通信范围内广播的工作需求。

三者使用独立状态与数据。玩家任务不能直接插入机器任务队列，也不能替玩家生成机器算法。

## 第一版玩家任务边界

- 基础引导结束后自动派发主线发展任务，不需要任务板手动接取。
- 可以同时存在多个任务，玩家自由安排完成顺序。
- 第一版不实现支线、每日任务、随机任务、限时任务和任务分支选择。
- 任务只描述结果，不指定唯一机器、组件或算法方案。
- 任务没有失败、超时或惩罚。
- 系统解锁在满足条件时自动生效；金币、资源等普通奖励可以手动领取。

任务状态为：

```text
未派发 → 进行中 → 可领取 → 已完成
```

## 目标判定与时序

- 目标同时监听运行事件并检查实际世界状态，不能只依赖一次性事件。
- 任务派发、读取存档和相关对象状态变化时，重新检查已经满足的条件。
- 提前完成的行为可以计入后续任务，但必须满足任务定义的来源和有效性要求。
- 奖励、经验和系统解锁只能结算一次。
- 多目标任务只有在全部必要目标满足后完成；并列任务互不强制阻塞。

## 任务、图纸与等级职责

```text
玩家任务
→ 提供目标、经验与确定性图纸

中枢等级
→ 控制学习阶段、系统能力与区域上限

图纸
→ 控制具体建筑或组件能否建造、制造
```

第一版的基础蓄电池、制造工坊、基础探索扫描器、远程通信接收器和远程通信发射器图纸，均由对应主线任务确定性获得。

## 第一版等级阈值

| 中枢等级 | 累计经验 |
|---|---:|
| 1级 | 0 |
| 2级 | 500 |
| 3级 | 1500 |

- 第一版经验上限为1500，达到上限后不继续储存通往4级的经验。
- 经验达到阈值时自动升级，溢出经验正常保留；经验与功能解锁均不需要玩家手动领取。
- 等级是学习进度，不是难度门槛。玩家通过经营事件提前达到3级是允许的。

## 经验来源

经验来自两类内容：

### 主线任务经验

| 任务或阶段 | 经验 |
|---|---:|
| 完成基础引导 | 200 |
| 木材供应 | 50 |
| 矿石供应 | 50 |
| 持续水源 | 50 |
| 农业循环 | 50 |
| 基础供应任务组全部完成 | 100 |
| 首次升级 | 100 |
| 蓄电基础任务组 | 200 |
| 制造能力任务组 | 250 |
| 供电扩张任务 | 200 |
| 探索准备任务组 | 300 |

- 主线经验合计1550。正常流程会在探索准备完成时达到第一版1500经验上限，无须额外刷取。
- 基础引导与基础供应任务组累计正好提供500经验，使正常流程在该阶段达到中枢2级。

### 日常游戏事件经验

| 有效事件 | 经验 |
|---|---:|
| 完成一个农田批次 | 20 |
| 一个资源点完成一次有效生产并入库 | 10 |
| 制造一个组件 | 20 |
| 升级一个载体或组件 | 20 |
| 解决一次真实断电 | 30 |
| 基地连续稳定运行20分钟 | 30 |
| 某作物首次达成完美生产 | 100 |
| 该作物后续再次达成完美生产 | 20 |

- 第一版不设置每日经验上限或同类事件递减。即使玩家通过大量有效生产提前达到3级，也不影响任务、图纸与能力检查的职责。
- 每单位资源、每次浇水、单次检测、单次机械臂动作、打开界面、修改参数以及反复启停机器不提供经验。
- 同一个结果只能触发一次对应经验；首次完美生产与同批次的后续完美生产奖励不叠加。

## 等级设计原则

- 等级用于逐步释放学习内容，不作为需要长期刷取的难度门槛。
- 玩家可以通过日常事件提前升级，但不能绕过任务、图纸和机器能力要求。
- 不出售经验，不设置体力，不扣除经验。
- 中枢等级仍限制机器与组件等级上限，以及可接入区域数量。

## 第一版1～3级结构

### 中枢1级

- 基础引导。
- 农田自动化和基础算法库。
- 初始商店与作业礼包。
- 机器库、组件库的基础功能。

### 中枢2级

- 机器和组件等级上限提高到2级。
- 开放载体与组件升级功能，并派发一次将任意载体、传感器、计算核心或效应器升级到2级的主线任务。任务推荐升级初始农田机器的基础计算核心，完成奖励500金币和100经验。
- 开放完整能源界面、蓄电池和蓄电基础任务；完成后解锁制造工坊图纸。
- 推进制造工坊相关发展任务并增加基础商店商品；制造工坊首次启动并形成真实负载缺口后，再触发供电扩张任务。
- 区域容量仍为1。

### 中枢3级

- 机器和组件等级上限提高到3级；第一版不强制制作完整3级升级内容。
- 区域容量由1提高到2。
- 探索组件图纸与探索准备任务由主线进度释放，不由等级单独开放。
- 中枢达到3级、探索准备主线完成且探索机器能力检查通过后，解锁区域探索入口。探索准备任务本身不含“达到3级”子目标；任务结算经验后系统立即重新检查入口条件。

## 结算规则

- 经验在任务或事件成立时自动结算；金币、资源等普通任务奖励仍可手动领取。
- 任务事件与实际世界状态共同复核，经验和一次性奖励只能发放一次。

第一版蓄电任务的正式状态条件为：任务派发后累计充入与放出各30电量，当前生物质与发电机剩余燃料折算量不少于10，且能源系统无严重异常。供电扩张在工坊运行使真实负载超过60时派发；第二台发电机开启后需要在有效负载下连续稳定2分钟，缺电停机使计时归零。

## 第一版任务界面与追踪

- 第一版任务列表只划分进行中、可领取和已完成，不实现日常任务、随机委托或复杂分类。尚未派发的后续任务不显示。
- 任务组显示目标说明、完整验收目标、实时进度、金币与资源奖励，以及自动结算的经验和功能解锁。HUD只显示一个主动追踪任务组和最多三条当前目标。
- 玩家只能主动追踪一个任务组。没有追踪目标时，新派发任务自动成为追踪目标；已有追踪目标时只提示新任务，不强制替换；当前任务完成后自动追踪下一个已派发主线任务组。
- 目标可以提供定位对象或打开已解锁相关界面的快捷操作，但不能替玩家完成购买、配置、部署或其他决策。
- 经验与系统解锁在条件成立时自动结算；金币和资源通过领取按钮结算。未领取奖励只在任务入口显示提示，不反复弹窗打断玩家。
- 达到1500经验后，第一版继续发生的经验事件不再累积经验，也不预存4级进度。

## 第一版不实现

- 中枢4级及以上内容。
- 完整长期经验曲线和所有经验来源。
- 每日任务、周常、通行证或活跃度系统。
- 经验道具、经验加成、经验惩罚或付费经验。
- 可失败、可超时或相互排斥的任务。

任务名称、目标摘要和完成说明见[第一版玩家可见文案规格](../04-第一版/07-玩家可见文案规格.md)。任务HUD、列表、领取和升级反馈的界面边界已经记录在[视角、交互与信息呈现](../03-玩家体验/01-视角交互与信息呈现.md)。任务状态、经验和一次性奖励必须进入存档，正式可执行验收用例等待用户授权后生成。
