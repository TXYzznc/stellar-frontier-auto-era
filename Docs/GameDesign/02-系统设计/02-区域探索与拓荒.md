# 区域探索与拓荒

> 状态：核心流程已形成，挑战内容与数值待设计

## 空间结构

- 游戏主要发生在同一颗星球。
- 玩家初始拥有一小块已拓荒区域。
- 其他区域分为“未探索”和“已探索但未拓荒”等状态。
- 玩家从现有基地边界逐步探索并拓荒相邻区域。

## 区域状态

```text
未探索
→ 探索中
→ 已探索、未拓荒
→ 信号塔启动、拓荒中
→ 拓荒成功、接入基地
```

### 未探索与探索中

- 区域被灰雾覆盖，不能建设和经营。
- 玩家派遣具备探索能力和远程通讯能力的机器进入。
- 探索值增长速度受到有效探索机器数量、机器状态和探索能力影响。
- 探索机器可能遭受土著生物与环境攻击，需要配置防御能力的机器保护。
- 探索机器可以获得完整中枢连接，中枢能够查看状态、修改配置，并由中枢算法直接调用其效应器。
- 完整远程连接需要机器同时安装通讯接收设备与通讯发送设备，分别占用一个传感器槽位和一个效应器槽位。
- 远程通讯不是机器职业限制；任何兼容机器承担相同槽位和运行成本后都可以获得完整连接。

### 已探索、未拓荒

- 探索值满后灰雾消失，玩家可以进入区域并进行现场交互。
- 允许部署机器，并建设信号塔、墙体、供能、补给、维修等拓荒所需的前线基础设施。
- 不允许种植、采集、长期生产等经营操作。
- 普通机器不能连接中枢，只能运行本地算法；具备探索远程通讯能力的机器除外。
- 该阶段主要解决玩家与环境、土著生物之间的冲突。

### 拓荒中

- 玩家建设并启动固定功能建筑“信号塔”，开始累计拓荒时间。
- 信号塔属于建筑，不具有机器激活状态，不安装传感器、计算核心和效应器，也不运行本地节点算法。
- 信号塔具有结构完整度并需要区域电网持续供电。
- 信号塔已启动、正常供电且结构完整度大于0时，拓荒值随有效运行时间持续增长。
- 信号塔受损但尚未被摧毁时，拓荒速度和当前拓荒值不直接受结构完整度比例影响，只产生受损与维修警告。
- 信号塔持续发出特殊电波，使附近土著生物狂化，提高袭击频率、数量和强度。
- 狂化压力随信号塔持续运行分阶段增强，并在拓荒完成前出现一次具有明确预警的高峰挑战。
- 挑战的具体内容、组合方式和强度节奏需要作为独立主题细化，当前不提前锁定。
- 普通机器仍然不能连接中枢，必须依靠本地算法自治。
- 前线建筑可以受损并被摧毁；完全损毁后需要重建。重建成本比例暂不锁定，通过后续经济测试确定。

### 拓荒进度与存档点

- 拓荒进度条设置4个进度存档点，具体位置与是否对应挑战阶段以后续节奏设计为准。
- 信号塔正常运行时，拓荒进度持续增加。
- 信号塔被摧毁时，进度立即回退到上一个已保存的进度点。
- 信号塔被玩家主动停止或因断电停止时，进度以极慢速度回退，直到到达上一个已保存的进度点后停止。
- 存档点用于保护已完成的阶段成果，拓荒失败不会让全部进度清零。
- 信号塔恢复并重新启动后，从当前保留进度继续推进。
- 信号塔结构完整度归零即视为被摧毁，需要重新建造；重建并启动后从保留进度继续。

### 拓荒成功、接入基地

- 狂化期结束，区域恢复常态环境与生态压力，但不会变成绝对安全区。
- 区域正式计入玩家基地，解锁种植、采集、生产等长期经营操作。
- 区域内已激活且未损坏的普通机器自动连接中枢，本地算法继续保留和运行。
- 区域资源、算力与生产数据纳入中枢全局统计。
- 该区域可以作为探索相邻区域的新起点。
- 信号塔需要持续存在和运行以维持区域网络；之后信号塔被摧毁不会取消区域归属，但区域内普通机器会断开中枢并继续运行本地算法，重建后自动恢复连接。

## 机器连接规则

```text
普通机器连接中枢
= 已激活 + 未损坏 + 位于已拓荒且信号塔正常的区域

远程通讯机器连接中枢
= 已激活 + 未损坏 + 同时安装并运行通讯接收传感器与通讯发送效应器
```

## 拓荒阶段允许与禁止的内容

| 内容 | 未探索 | 已探索、未拓荒 | 已拓荒 |
|---|---:|---:|---:|
| 探索机器进入 | 允许 | 允许 | 允许 |
| 普通机器部署 | 禁止 | 允许 | 允许 |
| 前线防御与墙体 | 禁止 | 允许 | 允许 |
| 信号塔 | 禁止 | 允许 | 允许且需维护 |
| 能源、补给与维修设施 | 禁止 | 允许 | 允许 |
| 种植、采集和长期生产 | 禁止 | 禁止 | 允许 |
| 普通机器中枢控制 | 禁止 | 禁止 | 信号塔正常时允许 |

## 开放问题

- 探索机器数量的边际递减、探索值公式和不同探索能力如何计算？
- 拓荒期间的环境、生态、后勤和系统挑战分别有哪些具体内容？
- 四个进度存档点分别位于何处，是否与狂化压力阶段和关键挑战一一对应？
- 区域挑战采用固定区域目标、动态压力，还是两者结合？挑战强度如何形成完整节奏？
- 前线允许建设的能源、补给和维修设施边界如何定义，避免提前形成经营系统？
- 拓荒成功后，不同改造/共生路线如何改变区域长期状态？
