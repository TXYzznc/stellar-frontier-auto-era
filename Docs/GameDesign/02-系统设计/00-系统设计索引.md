# 系统设计索引

> 状态：持续维护

本目录用于记录单个游戏系统的正式规则。核心框架回答“为什么存在”，系统文档回答“如何运行”，第一版文档回答“本版本具体实现哪些内容”。

| 系统 | 当前状态 | 第一版是否需要 | 说明 |
|---|---|---:|---|
| 机器、自动化与算法 | 第一版已完成 | 是 | 核心结构、正式模板、算力、队列、冲突和异常规则已定 |
| 区域探索与拓荒 | 部分完成 | 仅准备 | 第一版结束于探索机器准备完成并解锁探索，不实际运行探索与拓荒 |
| 资源、种植与生产 | 第一版已完成 | 是 | 资源流、作物、资源点、产量、缓存与生产反馈已定 |
| 建筑与建造 | 第一版已完成 | 部分 | 固定功能边界、第一版建筑、施工、工坊与制造已定 |
| 战斗、原生生物与生态 | 暂未完成 | 否 | 第一版不实现生物威胁、战斗与防御 |
| 能源、储存与物流 | 第一版已完成 | 是 | 发电、蓄电、默认供电、容量、固定运输与统一仓库分类已定 |
| 损坏、故障与维修 | 部分完成 | 仅字段 | 第一版保留完整度、状态、存档与测试入口，不提供玩家损坏维修流程 |

| 存档与状态持久化 | 第一版已完成 | 是 | 安全快照、备份恢复、离线结算与状态保存边界已定 |

| 任务、经验与功能释放 | 第一版已完成 | 是 | 自动派发主线、任务状态、事件经验和1～3级释放已定 |
| 统一数值模型 | 第一版已完成 | 是 | 多轴基准、核心数值、容量、动作和纸面联合审计已完成 |
| 第一版行为、容量与结算 | 第一版已完成 | 是 | 统一移动、缓存、货舱、效应器行为、安全中断和结果结构 |
