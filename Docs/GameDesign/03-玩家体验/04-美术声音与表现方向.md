# 美术、声音与表现方向

> 状态：第一版总体视觉、声音与灰盒规格已确认；正式资源生产留到后续制作阶段  
> 当前阶段：只保留设计接口，不进入正式资源生产

## 已确认表现需求

- 游戏为俯视角 3D。
- 不通过玩家角色承担情感代入，需要依靠机器状态、基地变化和环境反馈建立联系。
- 机器采用“固定载体外观＋效应器安装位局部挂接”的表现方式。安装、替换或移除效应器时，只改变对应安装位上的组件模型；载体本体和其他安装位完全不变。
- 不为每一种组件组合制作独立整机模型。机器载体后续会配置效应器安装位，但当前总体美术方向阶段不要求确定各载体安装位的具体位置与朝向。
- 人类机器与建筑采用模块化拓荒工业科技：强调标准化、耐用、可维修和功能可读性，以工业结构、工程材料和清晰接口为主。
- 高科技感集中在传感器、计算核心、精密材料、中枢UI和状态反馈；不以纯白无接口未来盒子、废土拼装或生物机械作为标准设备主风格。
- 激活状态使用呼吸灯区分：未激活灰白、已激活绿色、需要重新激活黄色、已损坏红色。
- 状态反馈必须清楚表达动作、因果、警报和长期成长。
- 整体气质为安静、孤独但不压抑的工程拓荒科幻；正常经营舒缓克制，系统异常阶段性增强紧张感，不使用持续高压生存表现。
- 第一版机器只通过命名、轮廓、运动、姿态、状态灯和机械动作体现轻度个性，不制作性格系统和自主对话。娱乐性个性动作保留为后续想法。

## 第一版视觉语言

- 星球自然环境以偏冷、低饱和色为主；土地使用灰褐、暗红或冷灰，本土植物可以使用蓝绿、暗紫和少量荧光色，水体偏青。夜晚必须保持机器与作业状态可读。
- 人类工业设施使用深灰金属、工程塑料和磨砂复合材料，辅以暖灰白外壳、低饱和橙色安全结构和青蓝色精密设备微光，形成“冷色陌生环境＋偏暖工程设施”的对比。
- 绿色、黄色、红色和灰白优先服务激活、警告、损坏和未激活状态；普通装饰不得大面积使用高饱和状态色。
- 机器载体采用稳定、低重心、可维护的工业轮廓。水枪喷口、机械臂关节、钻头、传感器方向、槽位和安装接口必须具有功能可读性。
- 外壳使用适量倒角，避免纯方盒、过度流线化洁白科幻和无接口黑箱。组件升级以细节、材质和少量发光变化体现，不彻底改变功能轮廓。

## 第一版声音层级

- 环境层包含风、远处生物、植物、水体和昼夜变化，保持安静与空间感，不能用高频生物叫声制造不存在的威胁暗示。
- 机器与生产层覆盖移动、机械臂、水枪、切割、钻探、发电、制造、入库和装卸。循环声必须与实际状态同步；休眠、停止和阻塞不能继续播放正常工作声。
- 大量同类机器不能无限叠加相同声源。优先限制近距离同类声源数量，再以低密度基地环境声补充规模感。
- UI与警报按照普通确认、完成、提醒、警告和严重逐级增强。同源警报合并后不能叠加播放；管理界面只降低部分世界声，不切断世界仍在运行的听觉反馈。
- 音乐采用平稳经营、阻塞张力和严重异常／关键成长三层简单动态结构。第一版不为每个系统单独作曲，不加入角色语音和机器对话。

## 第一版UI视觉语言

- UI采用工程终端与工业控制台风格：深色不透明或低透明面板、明确边框分区、暖灰白正文和少量青蓝高科技光效，避免装饰性扫描线、持续闪烁和大面积全息效果。
- 第一版只以1920×1080作为唯一设计、开发和验收分辨率，不适配1280×720、超宽屏、移动端或其他宽高比；后续版本需要适配时另行重构布局规则。
- 青蓝表示普通信息与可交互，绿色表示正常／有效／完成，黄色表示等待／警告，红色表示错误／严重异常，灰白表示未激活／中性，深灰表示禁用与背景。颜色必须配合文字、图标或形状。
- 节点图中持续数据使用实线，瞬时事件使用带方向标记的虚线或其他明显不同的线型。节点类别使用固定标题栏与图标，端口除颜色外还使用形状或内部符号区分数据类型。
- 诊断视图高亮实际路径、灰显未走分支，等待节点黄色、失败节点红色、当前选择青蓝；动画只在查看诊断记录时短暂使用，不让整张图持续闪烁。

## 第一版灰盒资源标准

- 灰盒用于验证对象识别、组件功能、安装位遮挡、作业动作、状态灯、选择碰撞、建筑占地、机器路径和昼夜可读性，不以正式美术质量为验收目标。
- 灰盒至少覆盖第一版载体与组件、四类资源点、第一版建筑、两种作物主要阶段、全部核心作业动作，以及施工、运行、休眠、断电、阻塞和警报状态。
- 每个灰盒对象必须具有正确比例／占地、模型原点／朝向、独立选择碰撞体、效应器安装锚点、状态灯、作业目标／装卸点及导航与物理碰撞范围。
- 逻辑根对象与视觉子对象分离。正式资源替换只替换视觉子对象，不改变对象ID、根节点、组件槽位、安装锚点、导航参数、交互范围、作业点和存档数据。
- 正式资源替换后重新检查轮廓、遮挡、碰撞和安装位，但不重写玩法逻辑。第一版功能完成以灰盒能够完整表达玩法为准。

### 世界与载体尺度

- 世界统一使用1 Unity单位＝1米。建筑自由放置，但第一版位置按照0.5米吸附、旋转按照15度吸附，兼顾整齐与非网格化表现。
- 通用轮式载体本体初始尺寸为2.4×1.6×1.2米，交互占地约2.6×1.8米，导航半径约0.9米。采用低重心四轮或六轮底盘，具有明确前向、中央核心区、前／上部传感位、左右效应器位、后部货舱与顶部状态灯。
- 两个效应器安装位初始采用左右对称布局，替换组件只改变对应安装位模型。第一版不模拟组件重量、平衡与载体重心变化。

### 第一版对象灰盒占地

| 对象 | 初始占地 |
|---|---:|
| 基础农田 | 8×8米 |
| 人工林 | 8×8米 |
| 矿山 | 10×8米，不规则轮廓 |
| 浅层水源 | 8×6米，不规则轮廓 |
| 基础仓库 | 8×6米 |
| 制造工坊 | 8×6米 |

| 初始太阳能发电器 | 4×4米 |

- 每个对象配置作业、装货、卸货、等待、选择碰撞和名称／状态标识锚点。第一版默认一个主要作业点和一个物流点；农田可以提供两个互不阻挡的作业点，以支持机械臂与水枪同时工作。
- 上述尺寸是灰盒初始值，原型可以调整，但必须维持载体通行、作业可读和对象间相对尺度的一致性。

### 第一版组件灰盒包络

- 传感器统一使用约0.35×0.35米安装底座，视觉包络不超过0.5×0.5×0.5米。不同传感器通过扫描头、探地头、阵列或天线区分；模型朝向不改变第一版圆形读取范围。
- 效应器统一使用约0.45×0.45米安装底座，待机收纳包络约0.9×0.5×0.5米。动作时允许临时伸出，但待机不能长期遮挡另一安装位、状态灯或机器前向。
- 计算核心约0.8×0.6×0.35米，安装于中央核心舱；正常视角只需显示舱盖、散热结构与状态光。

逐对象灰盒结构、锚点、状态和动作要求见[第一版灰盒对象与交互规格](../04-第一版/06-灰盒对象与交互规格.md)。

## 后续制作问题

- 第一版环境、机器、建筑的最终模型、材质、图标、字体与音频资源生产规格。
- 第一版只存在一种载体；更多载体加入后再设计尺寸等级、安装布局和遮挡规则。
- 本土生物与实际探索环境不进入第一版，造型原则在探索版本开始前确定。
