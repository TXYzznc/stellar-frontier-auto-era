# 新手引导与复杂度释放

> 状态：第一版基础引导、完成判定与核心文案已完成；配图随UI灰盒制作

## 引导目标

基础引导让玩家亲手完成第一次自动化扩张，理解机器激活、传感信息、算法模板、运行参数、资源生产、设备管理和入库结算。引导不是完整系统教程；能源、制造、通信和拓荒在后续满足条件时分别触发阶段引导。

基础引导的最终结果为：

> 玩家让初始农田完成生产，并购买、组装和部署第二台机器，使人工林或矿山完成一次有效采集与入库。

## 引导系统核心框架

```text
触发条件
→ 引导阶段
→ 一个或多个目标
→ 监听行为事件并检查实际世界状态
→ 阶段完成
→ 发放一次性奖励或解锁
→ 保存进度
```

每个引导阶段至少配置：

- 开始条件与完成条件。
- 教学标题、文字、图片和当前目标。
- HUD入口及需要高亮或定位的对象。
- 卡住时的补充说明与恢复保护。
- 一次性奖励或系统解锁。

完成判定必须同时支持事件监听与实际状态检查。读取存档、重新进入界面或遗漏一次性事件时，系统重新检查世界状态；已经满足的目标直接完成，但奖励和解锁不得重复发放。

## 通用交互规则

- 基础引导不能跳过；关闭说明弹窗不代表跳过目标。
- 不提供引导重置，也不回滚世界、机器或资源。
- 世界始终继续运行，引导弹窗和其他界面均不暂停或减速世界。
- 当前存在未完成引导阶段时，HUD常驻显示引导图标。
- 新阶段开始时自动打开一次图文说明；关闭后可以随时点击HUD图标重新查看。
- 教学弹窗显示阶段说明、操作图片、当前进度、常见问题及相关界面的快捷定位入口。
- 教学面板还提供规则按钮；可以关闭后再次从HUD图标打开，但当前基础引导不能跳过或重置。
- 引导步骤以真实游戏状态验收，不以单纯点击“下一步”完成。购买、安装、部署、激活和资源入库分别检查对应记录、实例状态与来源关系。
- 步骤完成后自动切换下一步并显示简短反馈。读取存档、重新打开界面或遗漏事件时重新检查实际状态，奖励与解锁仍只能结算一次。
- 只在当前教学明确涉及的界面使用局部高亮与箭头；第一版不使用锁死其他操作的全屏强制遮罩。快捷入口只能定位或打开界面，不能替玩家执行决策。
- 基础引导完成后图标消失；后续阶段引导触发时重新出现。

第一版只需要静态界面截图、节点示意图和操作位置标注，不制作视频或复杂交互演示。

## 初始状态与保护

- 初始农田已经播种，作物处于生长阶段并逐渐受到缺水影响。
- 玩家拥有少量已经完成入库结算的全局水资源，足以完成第一轮灌溉并容许少量错误。
- 初始基地具有基础仓库、农田、人工林、矿山和浅层水源。
- 初始农田机器尚未激活，预装通用轮式载体、基础货舱、基础计算核心、对象状态传感器、基础土壤传感器、水枪和机械臂。
- 对象状态传感器读取农田公开的作物阶段、成熟、待清理和缓存等状态；土壤湿度必须由基础土壤传感器读取。
- 机械臂在第一版支持播种、收获、农田清理和资源转移。
- 第一批作物不会因玩家阅读或试错而死亡或永久停止；极差照料下仍保留基础生长速度的10%，但完成时间与最终产量会明显变差。
- 第一版不因教学或未完成主线动态禁止组件出售，也不实现“唯一主线能力”保护。误售后的恢复依靠基础商店、永久制造图纸、星拓联日常金币和矿石补给包；是否需要额外保护根据实际试玩迭代。

## 初始算法库

算法库开局至少具有以下结构有效的基础模板。模板不绑定具体对象、传感器或效应器，应用后仍由玩家完成实际绑定。

| 模板 | 作用 | 玩家需要完成 |
|---|---|---|
| 基础灌溉 | 根据湿度区间控制浇水 | 绑定农田、土壤湿度输出和水枪，调整阈值 |
| 农田基础作业 | 处理播种、成熟收获、清理和产物搬运 | 绑定农田、机械臂、种子来源和仓库 |
| 生长资源采集 | 资源成熟后采集并送入仓库 | 绑定人工林、采集效应器、机械臂和仓库 |
| 储量资源开采 | 有储量且缓存允许时开采并送入仓库 | 绑定矿山、钻探效应器、机械臂和仓库 |

第一条灌溉算法使用完整模板，不在算法库保存缺线或结构无效的教学草稿。教学重点是模板应用、端点绑定、参数调整和观察反馈。

## 基础引导流程

### 阶段一：观察问题与激活机器

1. 玩家观察农田缺水、生长速度下降及自然语言提示。
2. 玩家移动视角到初始机器附近并打开现场交互界面。
3. 玩家现场激活机器，认识激活、开机和中枢连接的区别。

### 阶段二：完成第一次算法配置

1. 从算法库应用“基础灌溉”模板。
2. 绑定目标农田、基础土壤传感器的湿度输出与水枪行为。
3. 设置开始和停止浇水阈值并点击应用。
4. 观察算法触发路径、机器行为、湿度和生长速度变化。
5. 修改一次公开运行参数；参数在当前行为安全结束后生效，不重启机器。

### 阶段三：完成第一批农田生产

农田基础作业可以使用系统提供的完整模板，玩家主要观察：

```text
成熟 → 机器收获 → 产物进入缓存
→ 搬运到仓库 → 清理农田 → 生物质入库结算
```

第一批农产品通过教学操作出售并获得金币，随后开放商店、机器库和组件库的相关教学入口。

### 阶段四：购买并组装第二台机器

商店提供两种作业礼包：

| 礼包 | 内容 |
|---|---|
| 人工林作业礼包 | 通用轮式载体、基础计算核心、对象状态传感器、切割效应器、机械臂；2500金币，限购一次 |
| 矿山作业礼包 | 通用轮式载体、基础计算核心、对象状态传感器、钻探效应器、机械臂；2500金币，限购一次 |

- 礼包只简化购买，不包含算法模板，也不自动组装机器。
- 购买完成后，载体与组件直接送入主基地仓库并自动分类至机器库和组件库，不要求玩家执行运输或拆包操作。
- 礼包内对象可以按普通规则出售；两种礼包各限购一次，因此允许玩家取得有限的一次性倒卖收益。
- 机器载体进入机器库，组件进入组件库。
- 两个礼包都可购买，教学只要求选择一个。两种礼包均已确定为各限购一次，内容按普通回收规则出售；允许由一次性优惠形成有限倒卖收益，但不能无限循环购买。
- 玩家安装组件、部署机器、前往现场激活，再从算法库选择兼容模板并完成绑定。

### 阶段五：完成第二资源点收益

基础引导在以下条件全部满足后结束：

- 第二台机器已经现场激活。
- 机器应用的算法结构有效且必要绑定完整。
- 第二台机器对人工林或矿山产生至少一次有效采集贡献。
- 本次产物进入机器货舱并被运入仓库。
- 入库结算使木材或矿石的全局余额实际增加。

判定必须追踪本次产出来源和入库结果，不能用初始库存绕过。引导不要求第二资源点连续运行多个周期或达到最优效率。

## 后续引导边界

基础引导结束后不再继续强制逐步操作，改由自动派发的玩家主线任务引导自由经营、能源、制造与探索准备。新系统首次开放时可以显示简短图文说明，但目标、经验、图纸和系统解锁均由[任务、经验与功能释放](../02-系统设计/12-任务经验与功能释放.md)管理。第一版不设计通信协作、实际探索和拓荒的后续引导。
