# 反馈与情感曲线

> 状态：整体气质、第一版情感曲线与机器拟人化边界已确认

## 目标情绪

- 建设时的专注与创造欲。
- 系统稳定运行时的秩序感和满足感。
- 异常出现时的警觉与推理欲。
- 危机期间的紧张与掌控感。
- 找到漏洞并优化后的顿悟和成就感。
- 基地长期成长带来的归属感。

## 整体气质

第一版采用“安静、孤独但不压抑的工程拓荒科幻”。星球应当陌生、辽阔，星拓联提供有限远程支持；正常经营保持舒缓和清晰，异常只产生阶段性紧张，不营造持续生存恐惧。

压力来源是系统出现可理解、可诊断和可优化的问题，而不是玩家角色面临死亡。基地从稀疏设备逐渐形成稳定自动化系统，是第一版最主要的情感成长。

## 候选情感曲线

```text
规划与建设（舒缓）
→ 系统开始运转（期待）
→ 发现异常信号（警觉）
→ 多系统连锁危机（紧张）
→ 干预、诊断和修复（专注）
→ 恢复稳定并获得收益（释放与满足）
```

## 多层反馈

### 即时反馈

- 放置、连接、命令接收和动作执行的视听确认。

### 状态反馈

- 作物、设施、机器人、能源和防区的当前状态。

### 因果反馈

- 为什么触发、为什么拒绝、为何改变任务以及产生何种后果。

### 长期反馈

- 离线报告、生产趋势、故障记录、区域变化和基地成长。

## 反馈原则

- 普通运行时克制，异常时逐级加强，避免持续报警造成疲劳。
- 先告诉玩家“哪里有问题”，再帮助回答“为什么”和“如何修复”。
- 重要后果应同时通过世界表现和界面信息传达。
- 日志应支持回看，但不能成为理解系统的唯一方式。

## 第一版机器拟人化边界

- 机器通过玩家命名、型号轮廓、运动方式、工作姿态、状态灯、机械动作和运行记录建立轻度个性与陪伴感。
- 普通运行使用克制的状态灯与机械声；完成节点使用短促局部反馈；阻塞使用黄色反馈和原因说明；严重异常使用红色反馈、强化声音与合并HUD警报。
- 中枢升级、首次稳定自动循环、首次完美生产和探索准备完成可以使用更明显的音乐、镜头与界面演出。
- 第一版不实现性格数值、心情／忠诚、随机对话、性格拒绝任务和大模型自主交流。
- 与生产无关的个性化设计、待机娱乐动作和趣味互动进入想法库，不属于第一版范围。
