# 算法诊断模式

状态：2026-09-19设计候选，供18项完成后统一验收。页面ID：`AlgorithmDiagnosis`；家族：13-算法工作台。

## 目的、入口与归属

玩家任务：算法诊断模式。入口：算法记录→诊断或编辑器模式切换。

所属 `AlgorithmEditorForm`，页面根 `Panel_PageAlgorithmEditor`。只切换显示模式和写权限，不创建第二份编辑器结构。
完整节点树、组件与逐节点RectTransform见本家族[prefab-layout](prefab-layout.md)的AlgorithmEditor节；外壳、导航、关闭节点见[共享外壳](../00-共享外壳-prefab-layout.md)。

## 结构与布局

内容范围 1728×830。顶工具区，左节点库、中画布、右检查器、底问题栏；编辑与诊断共享同一画布。

| 分区 | 展示字段 | 区域职责 |
|---|---|---|
| 历史运行选择 | 机器和算法；最近运行时间；结果；合并次数 | Nodes |
| 历史执行路径 | 同一画布显示实际经过节点／端口；选中历史步骤；失效节点提示 | Canvas |
| 当时数值 | 历史输入输出；判断结果；绑定当时状态；因果ID | Inspector |
| 异常定位 | 错误、警告、拒绝或等待原因；关联任务与对象 | Problems |
| 诊断状态 | 运行记录时间；只读标识；当前世界仍运行；记录版本与现版本差异 | Toolbar |

分区复用AlgorithmEditor对应节点；节点库切成运行记录，检查器显示当时数值，操作由模式合同映射。
文本独立排版，不烘焙入图片。暂无数值使用“—”；说明与历史记录不伪装成实时测量。

## 继承规则与本页边界

不把当前值覆盖历史值；已过保留窗口的记录说明不可用。编辑和诊断共用一套画布结构，模式切换禁用写操作。

业务来源：[01-机器自动化与算法](../../../02-系统设计/01-机器自动化与算法.md)；所有页面继承[通用合同](../00-通用合同.md)及[页面关系与复用](../00-页面关系与复用.md)。已有规则直接复用，具体排版及新增入口是本次候选设计。

## 数据、权限、返回与状态

- 数据为相关领域服务提供的只读快照：历史运行选择、历史执行路径、当时数值、异常定位、诊断状态；打开首次取数，领域事件增量更新。历史阅读锁定对应记录与版本。
- 参数保留来源与返回上下文，传稳定对象／槽位／算法／记录ID；失效或无权限时禁用写操作并说明，不自动按名字替换对象。
- 返回先关闭选择或确认，再退详情／子页，最后回入口；恢复分页、选择、筛选、滚动与焦点。已提交等待继续按业务请求状态运行。
- 首焦点优先取消／返回，否则首个可用安全动作；公共关闭按钮在导航末尾；纯展示内容不抢焦点。
- default、focused、pressed使用Selectable过渡；disabled解释具体原因；loading反映真实读取；empty给无对象／无记录说明；error保留上下文及恢复路径；success只由权威结果触发。只读文本不适用pressed，未发提交不伪造success。
- 特殊边界：不把当前值覆盖历史值；已过保留窗口的记录说明不可用。
- 失败恢复：修正缺失条件再提交；业务请求结果不确定时继续等待，不允许UI自行超时重发。成功后仅刷新该对象与受影响摘要，不重置无关页面状态。

## 接入、素材与验收

Form使用AutoEra.UI命名空间及项目基类。每个按钮序列化字段采用camelCase并绑定本文布局内同名完整路径；输入、Button和快捷键汇入同一意图。OnClose释放页面读取和监听；已接受事务不随UI销毁而取消。时间、单位、价格和本地化由显示层格式化服务提供。
所需素材：容器底板、按钮正常／焦点／按下／禁用表现、类型图标、状态图标；图文页另需可选示意图。结构期用通用token和明确占位Image，中枢外壳复用已验收资源。字体及射线约定见通用合同。
文档自验：分区、数据、控件、返回、权限、状态均有说明；不得把页面文件数量当Form数量。未来原型需GF标准07的L1—L4检查、项目检查及1920×1080结构截图，本次只交设计文档。
