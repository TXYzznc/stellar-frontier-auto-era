# 算法编辑模式

状态：2026-09-19设计候选，供18项完成后统一验收。页面ID：`AlgorithmEditor`；家族：13-算法工作台。

## 目的、入口与归属

玩家任务：算法编辑模式。入口：机器算法编辑、中枢规则编辑、模板绑定完成。

所属 `AlgorithmEditorForm`，页面根 `Panel_PageAlgorithmEditor`。本页为该Form内预制内容区；同Form普通页互斥，HUD模块除外。
完整节点树、组件与逐节点RectTransform见本家族[prefab-layout](prefab-layout.md)的AlgorithmEditor节；外壳、导航、关闭节点见[共享外壳](../00-共享外壳-prefab-layout.md)。

## 结构与布局

内容范围 1728×830。顶工具区，左节点库、中画布、右检查器、底问题栏；编辑与诊断共享同一画布。

| 分区 | 展示字段 | 区域职责 |
|---|---|---|
| 节点库 | 输入、判断与运算、状态、流程、行为分类；搜索；解锁状态；端口能力 | Nodes |
| 节点画布 | 节点；有向连线；端口；选中项；草稿版本；可用逻辑容量 | Canvas |
| 节点检查器 | 绑定；节点参数；默认值；优先级；端口类型／单位；公开参数定义 | Inspector |
| 验证问题 | 错误与警告列表；节点／端口定位；逻辑容量与算力构成 | Problems |
| 算法状态 | 算法与机器名称；启用状态；草稿修改；应用中；当前版本 | Toolbar |

分区根为Panel_AlgorithmEditor加区域英文Key；每区声明标题、滚动正文和默认inactive的真实条目模板。
文本独立排版，不烘焙入图片。暂无数值使用“—”；说明与历史记录不伪装成实时测量。

## 可交互对象与效果

| 控件／意图 | 标签 | 条件、操作与效果 |
|---|---|---|
| Btn_AlgorithmEditorAdd | 添加或连接节点 | 从节点库加入；拖线仅兼容端口高亮；错误说明到类型／单位／能力 |
| Btn_AlgorithmEditorEdit | 修改节点和参数 | 只修改草稿；移动、删除、连线操作可撤销／重做属于本次编辑交互建议 |
| Btn_AlgorithmEditorBind | 选择绑定 | 进入12对应选择器 |
| Btn_AlgorithmEditorValidate | 验证 | 更新问题栏并可点击定位 |
| Btn_AlgorithmEditorApply | 应用草稿 | 完整验证；错误阻止，警告可确认；17应用确认后安全点生效 |
| Btn_AlgorithmEditorDiagnose | 切换诊断模式 | 13-诊断模式，保留草稿 |
| Btn_AlgorithmEditorTemplate | 保存为模板 | 清除实例绑定后保存玩家模板，重名覆盖走强确认 |

独立输入控件：`Panel_AlgorithmEditorNodeSearch`（搜索节点）。值变化或编辑结束汇入同一用户意图；字段控制与确认按钮职责分离。

## 数据、权限、返回与状态

- 数据为相关领域服务提供的只读快照：节点库、节点画布、节点检查器、验证问题、算法状态；打开首次取数，领域事件增量更新。历史阅读锁定对应记录与版本。
- 参数保留来源与返回上下文，传稳定对象／槽位／算法／记录ID；失效或无权限时禁用写操作并说明，不自动按名字替换对象。
- 返回先关闭选择或确认，再退详情／子页，最后回入口；恢复分页、选择、筛选、滚动与焦点。已提交等待继续按业务请求状态运行。
- 首焦点优先取消／返回，否则首个可用安全动作；公共关闭按钮在导航末尾；纯展示内容不抢焦点。
- default、focused、pressed使用Selectable过渡；disabled解释具体原因；loading反映真实读取；empty给无对象／无记录说明；error保留上下文及恢复路径；success只由权威结果触发。只读文本不适用pressed，未发提交不伪造success。
- 特殊边界：机器继续运行旧版本；不暂停世界。
- 失败恢复：修正缺失条件再提交；业务请求结果不确定时继续等待，不允许UI自行超时重发。成功后仅刷新该对象与受影响摘要，不重置无关页面状态。

## 接入、素材与验收

Form使用AutoEra.UI命名空间及项目基类。每个按钮序列化字段采用camelCase并绑定本文布局内同名完整路径；输入、Button和快捷键汇入同一意图。OnClose释放页面读取和监听；已接受事务不随UI销毁而取消。时间、单位、价格和本地化由显示层格式化服务提供。
所需素材：容器底板、按钮正常／焦点／按下／禁用表现、类型图标、状态图标；图文页另需可选示意图。结构期用通用token和明确占位Image，中枢外壳复用已验收资源。字体及射线约定见通用合同。
文档自验：分区、数据、控件、返回、权限、状态均有说明；不得把页面文件数量当Form数量。未来原型需GF标准07的L1—L4检查、项目检查及1920×1080结构截图，本次只交设计文档。
