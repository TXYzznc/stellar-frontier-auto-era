# 显示与性能设置

状态：2026-09-19设计候选，供18项完成后统一验收。页面ID：`DisplaySettings`；家族：02-系统与设置。

## 目的、入口与归属

玩家任务：显示与性能设置。入口：设置→显示与性能分页。

所属 `SettingsForm`，页面根 `Panel_PageDisplaySettings`。本页为该Form内预制内容区；同Form普通页互斥，HUD模块除外。
完整节点树、组件与逐节点RectTransform见本家族[prefab-layout](prefab-layout.md)的DisplaySettings节；外壳、导航、关闭节点见[共享外壳](../00-共享外壳-prefab-layout.md)。

## 结构与布局

内容范围 1488×730。内容区按下列分区自左向右排列，底部固定操作区；各区长内容独立滚动。

| 分区 | 展示字段 | 区域职责 |
|---|---|---|
| 显示模式 | 全屏／无边框全屏；垂直同步；30／60／不限帧率 | Display |
| 质量设置 | 低／中／高画质；阴影档位；抗锯齿档位；当前生效项与持久化状态 | Quality |

分区根为Panel_DisplaySettings加区域英文Key；每区声明标题、滚动正文和默认inactive的真实条目模板。
文本独立排版，不烘焙入图片。暂无数值使用“—”；说明与历史记录不伪装成实时测量。

## 可交互对象与效果

| 控件／意图 | 标签 | 条件、操作与效果 |
|---|---|---|
| Btn_DisplaySettingsMode | 切换显示模式 | 选择模式后临时应用并打开17-显示保留恢复；超时回滚 |
| Btn_DisplaySettingsQuality | 修改质量 | 使用档位按钮和Toggle即时应用，相关受限项显示原因 |
| Btn_DisplaySettingsReset | 恢复本页默认 | 只恢复显示与性能；若模式变化仍需保留／恢复确认 |
| Btn_DisplaySettingsTabs | 切换设置分页 | 切至声音或操作 |


## 继承规则与本页边界

固定1920×1080，不增加分辨率列表、UI缩放、语言、色盲滤镜。垂直同步控制帧率时说明帧率上限的实际作用，不显示互相矛盾的已生效状态。

业务来源：[10-存档与状态持久化](../../../02-系统设计/10-存档与状态持久化.md)；所有页面继承[通用合同](../00-通用合同.md)及[页面关系与复用](../00-页面关系与复用.md)。已有规则直接复用，具体排版及新增入口是本次候选设计。

## 数据、权限、返回与状态

- 数据为相关领域服务提供的只读快照：显示模式、质量设置；打开首次取数，领域事件增量更新。历史阅读锁定对应记录与版本。
- 参数保留来源与返回上下文，传稳定对象／槽位／算法／记录ID；失效或无权限时禁用写操作并说明，不自动按名字替换对象。
- 返回先关闭选择或确认，再退详情／子页，最后回入口；恢复分页、选择、筛选、滚动与焦点。已提交等待继续按业务请求状态运行。
- 首焦点优先取消／返回，否则首个可用安全动作；公共关闭按钮在导航末尾；纯展示内容不抢焦点。
- default、focused、pressed使用Selectable过渡；disabled解释具体原因；loading反映真实读取；empty给无对象／无记录说明；error保留上下文及恢复路径；success只由权威结果触发。只读文本不适用pressed，未发提交不伪造success。
- 特殊边界：固定1920×1080，不增加分辨率列表、UI缩放、语言、色盲滤镜。
- 失败恢复：修正缺失条件再提交；业务请求结果不确定时继续等待，不允许UI自行超时重发。成功后仅刷新该对象与受影响摘要，不重置无关页面状态。

## 接入、素材与验收

Form使用AutoEra.UI命名空间及项目基类。每个按钮序列化字段采用camelCase并绑定本文布局内同名完整路径；输入、Button和快捷键汇入同一意图。OnClose释放页面读取和监听；已接受事务不随UI销毁而取消。时间、单位、价格和本地化由显示层格式化服务提供。
所需素材：容器底板、按钮正常／焦点／按下／禁用表现、类型图标、状态图标；图文页另需可选示意图。结构期用通用token和明确占位Image，中枢外壳复用已验收资源。字体及射线约定见通用合同。
文档自验：分区、数据、控件、返回、权限、状态均有说明；不得把页面文件数量当Form数量。未来原型需GF标准07的L1—L4检查、项目检查及1920×1080结构截图，本次只交设计文档。
