# 规则自动化

状态：2026-09-19设计候选，供18项完成后统一验收。页面ID：`HubRules`；家族：04-基地中枢。

## 目的、入口与归属

玩家任务：规则自动化。入口：中枢规则自动化分页。

所属 `BaseCommandHubForm`，页面根 `Panel_PageHubRules`。本页为该Form内预制内容区；同Form普通页互斥，HUD模块除外。
完整节点树、组件与逐节点RectTransform见本家族[prefab-layout](prefab-layout.md)的HubRules节；外壳、导航、关闭节点见[共享外壳](../00-共享外壳-prefab-layout.md)。

## 结构与布局

内容范围 1488×730。内容区按下列分区自左向右排列，底部固定操作区；各区长内容独立滚动。

| 分区 | 展示字段 | 区域职责 |
|---|---|---|
| 自动化实例索引 | 机器／算法名称；启用与有效状态；成本；最近运行；异常与能力缺失 | Instances |
| 选中实例配置 | 公开参数及合法区间；实际绑定；旧版本与草稿区别；权限 | Configuration |
| 影响预览 | 受影响机器／组件／对象；校验错误与警告；应用安全点；状态重置影响 | Impact |

分区根为Panel_HubRules加区域英文Key；每区声明标题、滚动正文和默认inactive的真实条目模板。
文本独立排版，不烘焙入图片。暂无数值使用“—”；说明与历史记录不伪装成实时测量。

## 可交互对象与效果

| 控件／意图 | 标签 | 条件、操作与效果 |
|---|---|---|
| Btn_HubRulesSelect | 选择自动化实例 | 更新配置和影响，实例不等同算法模板 |
| Btn_HubRulesEdit | 打开算法工作台 | 进入13-编辑模式，关闭／覆盖中枢后保存返回上下文 |

## 数据、权限、返回与状态

- 数据为相关领域服务提供的只读快照：自动化实例索引、选中实例配置、影响预览；打开首次取数，领域事件增量更新。历史阅读锁定对应记录与版本。
- 参数保留来源与返回上下文，传稳定对象／槽位／算法／记录ID；失效或无权限时禁用写操作并说明，不自动按名字替换对象。
- 返回先关闭选择或确认，再退详情／子页，最后回入口；恢复分页、选择、筛选、滚动与焦点。已提交等待继续按业务请求状态运行。
- 首焦点优先取消／返回，否则首个可用安全动作；公共关闭按钮在导航末尾；纯展示内容不抢焦点。
- default、focused、pressed使用Selectable过渡；disabled解释具体原因；loading反映真实读取；empty给无对象／无记录说明；error保留上下文及恢复路径；success只由权威结果触发。只读文本不适用pressed，未发提交不伪造success。
- 特殊边界：本次建议把旧触发条件→提高供电优先级／创建维护任务样例替换为现有算法实例管理；不另建全局规则语言，不开放第一版禁止的供电优先级修改或维修调度。
- 失败恢复：修正缺失条件再提交；业务请求结果不确定时继续等待，不允许UI自行超时重发。成功后仅刷新该对象与受影响摘要，不重置无关页面状态。

## 接入、素材与验收

Form使用AutoEra.UI命名空间及项目基类。每个按钮序列化字段采用camelCase并绑定本文布局内同名完整路径；输入、Button和快捷键汇入同一意图。OnClose释放页面读取和监听；已接受事务不随UI销毁而取消。时间、单位、价格和本地化由显示层格式化服务提供。
所需素材：容器底板、按钮正常／焦点／按下／禁用表现、类型图标、状态图标；图文页另需可选示意图。结构期用通用token和明确占位Image，中枢外壳复用已验收资源。字体及射线约定见通用合同。
文档自验：分区、数据、控件、返回、权限、状态均有说明；不得把页面文件数量当Form数量。未来原型需GF标准07的L1—L4检查、项目检查及1920×1080结构截图，本次只交设计文档。
