# 全局提示词与交付规范

```text

```

## 3. 六段式提示词骨架

1. **主体与职责**：对象是什么、在玩法中做什么、玩家第一眼识别点。
2. **构图与视图**：正面、正交、三分之一轴测、爆炸图、状态板；画布和留白。
3. **形体与结构**：轮廓、比例、支撑、接口、锚点、可动件、作业点。
4. **色彩与光影**：深灰蓝基础、浅色信息卡、橙色焦点；硬边阴影和少量高光线。
5. **技术输出**：透明背景、九宫格 border、无文字、动态文字留白、命名和源格式。
6. **状态与验收**：状态差异、不可出现的内容、用户视觉检查项。

## 4. UI/3D/效果图三类产物

| 产物 | 画布 | 必须输出 | 禁止替代 |
|---|---|---|---|
| UI 切图 | 透明源图，按条目尺寸 | PNG、原始生成图、状态版本、border | 不得把整屏效果图切成控件 |
| 3D 设计图 | 1920×1080，正交/轴测 | 主视、背视、结构标注、材质分区 | 不得以效果图推导工程尺寸 |
| 页面效果图 | 1920×1080 正面 | 页面层级、示例文案、状态差异 | 不得当作可导入运行时资源 |

## 5. 命名与追踪

```text
NEW_<assetId>_<state>_<view>@<size>.<ext>
NEW_MOCK-UI-08_normal_front@1920x1080.png
NEW-IND-MCH-001_working_isometric@1920x1080.png
```

每个输出记录：assetId、版本、提示词、负面提示、工具/模型、种子或等价记录、源文件指纹、后处理、视觉裁决。

## 6. 禁止项

- 不上传旧素材作为图生图参考；可使用空白构图网格和本批新生成素材。
- 不让模型生成中文 UI 文本、数字、Logo 或状态文案；文字由 TMP 运行时绘制。
- 不用颜色单独传递状态；必须加入图标、形状、位置、姿态或文字。
- 不让效果图决定碰撞、导航、安装、KeepOut、功率、容量或采样参数。
