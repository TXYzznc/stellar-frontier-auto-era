# SMP-UI-002 · 水资源图标

## 1. 目的与使用位置

用于资源摘要、仓库列表和资源点详情中的水资源识别。水是第一版的通用资源，图标必须在 64×64 的列表尺寸下仍能与电能、木材和矿石区分。

## 2. 生成规格

| 项目 | 要求 |
|---|---|
| 输出 | NEW_smp_ui_002_resource_water_normal@512x512.png |
| 画布 | 512×512，sRGB，透明背景，主体占画布 70%～82% |
| 视图 | 正面图标，不要场景、容器或文字 |
| 结构 | 单一水滴主体、内部一道几何高光切面、底部小型异星测量刻线；刻线不得形成文字 |
| 变体 | 后续可派生 selected（橙色外框）和 disabled（降饱和），本次只生成 normal |
| 依赖 | 界面设计文档/共用素材/07-资源与类别图标.md |

## 3. 可复制中文提示词

制作一枚原创工业二次元资源图标：水资源。512×512 正方形透明背景，单个居中的水滴轮廓，轮廓略带机械切面而不是自然写实水滴；主体为清澈的低饱和异星蓝，内部只有两块平整色面和一条硬边高光切线，底部嵌入一个极简的深灰蓝测量刻线结构，不形成任何文字。图标外轮廓清晰、重心稳定、适合缩小到64×64，清线赛璐璐，平整色块，硬边阴影，少量高光线，原创拓荒测量符号。不要玻璃拟真、液体飞溅、复杂纹理、容器、背景、文字、数字、Logo、旧图标、参考游戏图标、均匀黑描边、霓虹、粒子光效。

## 4. 可复制 English prompt

Create one original anime industrial resource icon for water. Square 512x512 transparent canvas, one centered droplet silhouette with subtle mechanical facets rather than a natural photorealistic drop. Use a clear low-saturation alien blue, only two flat interior color planes and one hard-edged highlight cut. Add a minimal deep blue-gray measurement mark at the bottom that must not form letters or numbers. Strong silhouette, stable center of mass, readable when reduced to 64x64. Clean cel-shaded digital art, flat color masses, hard shadows, sparse highlight lines, original frontier measurement symbol. No glass realism, splash, complex texture, container, background, text, numbers, logo, old icon, copied game icon, uniform black outline, neon or particle glow.

## 5. 评审与通过

- 64×64 时轮廓仍像水资源，而不是宝石或气泡。
- 透明边缘无白边、无半透明脏边，缩放后没有锯齿性黑圈。
- 图标不依赖颜色才能识别：水滴轮廓与底部测量刻线必须同时有效。
- selected 与 disabled 只改变边框／对比度，不改变主体轮廓。
- 通过后标记 PROMPT-READY，并记录 512、128、64 三种缩放检查结果。
