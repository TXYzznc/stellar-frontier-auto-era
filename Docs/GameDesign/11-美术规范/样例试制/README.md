# 样例试制包

> 目的：提供第一轮风格试制用的 5 个独立需求。本文档只写新资源的设计、提示词、规格与验收；不生成图像，也不把样例当成已经接入 Unity 的正式资源。

## 使用顺序

1. 先生成 SMP-UI-001，确认深灰蓝底、浅色信息卡、锐角切角和橙色焦点是否合适。
2. 再生成 SMP-UI-002，确认透明背景图标在小尺寸下仍有清线赛璐璐的识别度。
3. 生成 SMP-WORLD-001 与 SMP-WORLD-002，确认机器和建筑是否属于同一原创工业二次元世界。
4. 最后生成 SMP-COMP-001，确认素材组合、世界可见面积和 FieldHudDetailForm 的上层关系。

## 样例目录

| 编号 | 样例 | 目的 | 输出类型 |
|---|---|---|---|
| SMP-UI-001 | 世界详情浅色信息卡 | 验证 UI 外壳、信息留白、切角和焦点边 | 透明 PNG，九宫格母版 |
| SMP-UI-002 | 水资源图标 | 验证小尺寸图标轮廓、资源语义和双色状态表达 | 透明 PNG，图标母版 |
| SMP-WORLD-001 | 通用轮式载体 | 验证机器比例、接口、轮组和工业色块 | 概念板 PNG，三视辅助 |
| SMP-WORLD-002 | 岸边水泵 | 验证建筑与异星浅层水域的组合关系 | 轴测概念图 PNG |
| SMP-COMP-001 | 世界 HUD 详情叠加 | 验证素材组合、运行层级和页面构图 | 1920×1080 效果图 |

## 统一试制门禁

- 全部资源必须从零生成；不得以旧项目截图、旧模型、旧贴图、旧图标或参考游戏截图做图像输入。
- 保留每次生成使用的完整提示词、模型、种子、生成时间和原始文件；未通过评审的样例标记 REJECTED，不得作为后续参考图。
- 禁止生成可读文字、Logo、品牌标识和伪造数值；动态文字由 SIMHEI 与程序绘制。
- 统一使用原创工业二次元、清线赛璐璐、平整色块、硬边阴影、少量高光线；不使用照片写实、厚重锈蚀、霓虹赛博或均匀黑描边。
- 样例通过后只冻结方向，不直接冻结最终材质、最终模型面数或运行时切图。
