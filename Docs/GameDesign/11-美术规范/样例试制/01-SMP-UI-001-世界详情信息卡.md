# SMP-UI-001 · 世界详情浅色信息卡

## 1. 目的与使用位置

用于 FieldHudDetailForm 的对象详情卡，承载名称、类别、状态、位置等动态字段的空白信息区域。它是第一项试制，因为可以直接检验新的 UI 明暗关系，并能在最终组合图里验证详情层覆盖常驻 HUD 的关系。

## 2. 生成规格

| 项目 | 要求 |
|---|---|
| 输出 | NEW_smp_ui_001_detail_card_normal@1024x512.png |
| 画布 | 1024×512，sRGB，透明背景 |
| 视图 | 正面、无透视、单个空白卡片，不带页面截图 |
| 切图 | 保留四角、四边和中心内容区的九宫格安全线；安全线由制作人员在后处理中标注 |
| 内容 | 中心留白至少 72%，不得烘焙文字、数字、图标或 Logo |
| 依赖 | 美术风格和规范/03-UI视觉规范.md、界面设计文档/共用素材/01-九宫格与容器.md |

## 3. 可复制中文提示词

为原创工业二次元科幻游戏制作一张 UI 详情信息卡素材，单个正面平视的横向矩形卡片，透明背景，1024×512。卡片主体是偏浅的冷灰蓝信息面，外轮廓使用不对称锐角切角：左上和右下各有一次短切角，四边有极细的深蓝灰结构边，不要圆角胶囊。内部保留大面积干净空白，只有左侧一条细窄的橙色焦点标记和右上角一个小型原创异星拓荒几何徽记；徽记不可包含文字。色彩使用深灰蓝底关系中的浅色卡片、少量橙色焦点、低饱和蓝灰阴影。清线赛璐璐，平整色块，硬边阴影，少量高光线，边缘干净，功能性强，模块化网格感，适合九宫格拉伸。不要生成文字、数字、Logo、品牌、按钮、人物、背景场景、旧项目素材、参考游戏版式、照片质感、金属噪点、锈蚀、霓虹、厚重黑描边、渐变玻璃、投影光晕。

## 4. 可复制 English prompt

Create one original anime industrial science-fiction UI detail card asset, front-facing orthographic view, transparent background, 1024x512. Use a light cool gray-blue information surface with asymmetric sharp corner cuts: one short cut on the upper left and one on the lower right, thin deep blue-gray structural edges, no rounded capsule shape. Leave at least 72 percent of the center empty for runtime text. Add only a narrow restrained orange focus marker on the left and a tiny original alien-expedition geometric emblem in the upper right; the emblem must contain no letters. Clean cel-shaded digital art, flat color masses, hard-edged shadows, sparse highlight lines, precise edges, modular grid logic, suitable for a nine-slice panel. No readable text, numbers, logo, brand, button, character, scene background, old asset, copied game layout, photorealism, noisy metal, rust, neon glow, thick black outline, glass gradient or bloom.

## 5. 评审与通过

- 缩到 320×160 后，外轮廓仍能读出详情卡而不是普通矩形。
- 浅色卡片与 UI/Background #111923、UI/Surface #1B2633 有清楚层级差。
- 橙色焦点只占很小区域，不抢过动态标题。
- 拉伸中心区后边缘结构连续，没有被拉长的装饰或断裂线。
- 透明边缘干净、中心留白足够、无伪文字后标记 PROMPT-READY，才允许派生 hover、selected、disabled 状态。
