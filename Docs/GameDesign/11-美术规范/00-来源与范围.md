## 3. 全量重做政策

本批所有图片、模型、贴图、材质、VFX、动画和音频从零设计。历史资源不可作为生产输入，也不能用旧资源文件标记为本批 `DELIVERED`。B52/ART006 只提供页面层级、语义 Token、状态含义和技术接口。外部植物、树木和施工装饰也必须依据新提示词重新制作或重新授权。

## 4. 明确排除

人物、动物、战斗、实际探索地图、通信调度、维修破损资源、天气、复杂流体、动态通信光束、角色语音、棋盘和移动端 UI 不属于本批生产对象。

## 5. 状态词

`DESIGN` 设计完成；`PROMPT-READY` 提示词可直接使用；`VISUAL-REVIEW` 用户正在审图；`ACCEPTED` 用户通过新生成版本；`EXTERNAL` 用户外部制作但必须走本规范；`TODO-TECH` 等待工程合同；`DELIVERED` 已交付并完成导入验收。
