# 03 · UI 视觉规范

## 1. UI 基调

深灰蓝底承载工程工作区，浅色信息卡承载文本和列表，橙色只标记当前焦点、主操作和确认。页面不是象牙白大面，也不是全黑透明 HUD。

## 2. 色板

| Token | 色值 | 用途 |
|---|---|---|
| `UI/Background` | `#111923` | 页面底和遮罩后的基底 |
| `UI/Surface` | `#1B2633` | 主面板 |
| `UI/Card` | `#2B3745` | 浅色信息卡与列表 |
| `UI/CardRaised` | `#364657` | hover/重点卡片 |
| `UI/TextPrimary` | `#E9EEF2` | 主文字 |
| `UI/TextSecondary` | `#AEBCC7` | 辅助文字 |
| `UI/Action` | `#E68A37` | 主按钮、焦点、确认 |
| `UI/Focus` | `#F0A24B` | 选中锐角、键盘焦点 |
| `UI/Success` | `#67C28A` | 正常/完成 |
| `UI/Warning` | `#D8B15A` | 等待/注意 |
| `UI/Danger` | `#D75E63` | 故障/危险 |
| `UI/Alien` | `#79A9C7` | 异星资源或精密微光 |

## 3. 控件

控件使用小圆角或锐角切角，不使用大圆角胶囊。按钮状态变化保持尺寸和外轮廓一致；pressed 通过内阴影和下移表达；disabled 通过降饱和、低对比和禁用图形表达。

## 4. 字体与布局

唯一正式字体为 `SIMHEI`。1920×1080：H1 32、H2 26、H3 22、正文 18、辅助 14、数字 20。动态文字不烘焙进切图。`FieldHudDetailForm` 永远高于 `FieldHudResidentForm`，效果图和实现验收都必须体现。

## 5. UI 验收

- [ ] 小图可读分区和焦点。
- [ ] 浅色卡片与深灰蓝底有足够明度差。
- [ ] 橙色只占焦点区域，不铺满页面。
- [ ] 状态至少同时使用颜色＋图标/形状/文字中的两种。
- [ ] 无伪造文字、Logo、旧版截图痕迹。

## AI 单文档生成合同（可独立投喂）

### 这份规范必须直接执行

本文件同时是视觉方向和 AI 生成约束，不需要读取其它规范才能执行。所有新画面统一采用原创工业二次元清线赛璐璐：平整色块、硬边阴影、2–4px 结构线、少量冷白高光，避免照片、柔焦、均匀黑描边和参考游戏复制。

### 内容、构图与技术要求

- 主体先保证轮廓、接地、层级和功能，再添加装饰；画面必须留出运行时文字、数值和 UI 叠加空间。
- UI 默认 1920×1080 或表格指定透明切图尺寸；世界默认三分之一轴测/正交约 35°；效果图必须有前景、中景、远景。
- Logo 只接受用户上传的 PNG 参考，不自行绘制、改字、加副标题或改变比例。
- 输出透明 PNG 或 1920×1080 效果图，sRGB，边缘干净；禁止可读乱码、旧资产、旧截图、人物、动物、战斗和复制其它游戏。
