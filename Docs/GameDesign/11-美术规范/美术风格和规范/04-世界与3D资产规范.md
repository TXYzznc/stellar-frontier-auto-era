# 04 · 世界与 3D 资产规范

## 1. 尺度与视图

1 Unity 单位＝1 米；设计图采用正交或三分之一轴测。每个对象必须有主视图、背视图、顶部/工作视图，复杂对象追加爆炸图。

## 2. 结构合同

任何机器/建筑必须标出接地点、逻辑根、安装面、作业点、可动 Pivot、KeepOut 和维护侧。效果图不能替代技术合同。

## 3. 材质合同

主材质使用 BaseColor、Normal、Mask/AO、Emission Mask 的简化 PBR；视觉上保持清线赛璐璐的明暗分组。透明只用于水面、施工虚影和明确的显示窗。

## 4. LOD 与组合

远景保留轮廓、状态灯和作业方向；中景保留接口和模块；近景增加维护件。模块化边界按 0.5m 网格拼接，不生成无法落地或穿插的装饰。

## 5. 验收

- [ ] 轴测图能读出用途、方向、接口和支撑。
- [ ] 落地点、作业口、碰撞包络与技术合同一致。
- [ ] 状态灯不替代 UI 状态摘要。
- [ ] 资源点不会用外观伪造储量。
