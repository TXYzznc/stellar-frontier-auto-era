# 01 · 总体视觉方向

## 1. 核心叙事

“自动化设备在陌生星球上把不可控自然变成可读、可维护、可持续的工作系统。”画面同时表达异星陌生感和工程秩序，不使用灾难废墟或战斗压迫感。

## 2. 视觉关键词

清朗、二次元、工程、模块化、异星、可维护、功能优先、轻量叙事、克制高光。

## 3. 视觉禁忌

照片写实、厚重锈蚀、赛博霓虹、统一黑描边、糖果色、欧美军事写实、无接口悬浮、随机机械堆叠、把背景细节做得比玩法对象更抢眼。

## 4. 视觉层级

1. 当前交互焦点：橙色锐角边、局部高光、最强对比。
2. 当前玩法对象：浅色外壳或深蓝信息窗、清晰轮廓和状态灯。
3. 环境与装饰：中低饱和冷色、低频纹理、不可抢焦点。
4. 背景氛围：大色面和留白，不制造无关事件。

## 5. 参考的正确用法

可学习参考游戏的“信息先后、分区逻辑、装饰节奏和焦点控制”；不得复制角色、图标、字体、具体组件、具体页面、具体颜色组合或构图。
