# 02 · 工业二次元清线赛璐璐规范

## 1. 形体

先做大轮廓，再做结构切面，最后做少量维护件。几何简化必须遵循实际结构和受光方向，不能做随机低模三角拼贴。

## 2. 明暗

使用亮面/中间面/暗面三组大色块，边界以硬边为主；圆柱、软管和玻璃只在必要处使用短软边。阴影贴合结构，禁止长投影和重 AO。

## 3. 线条

用相邻色面的明度差和局部深色结构线建立轮廓，不使用全物体等宽纯黑描边。机械接口、检修缝和作业方向可以使用短线强调。

## 4. 材质

金属靠转折面、窄高光和色相偏移表现；聚合物靠大面色块和边缘磨亮表现；橡胶保持低反射；玻璃只保留深蓝色透窗和一条高光线。

## 5. 细节密度

远景只读大形和状态灯；中景读安装面、作业口和模块关系；近景读刻线、螺钉和材料差异。任何不服务识别的微细节删除。

## 6. 验收

- [ ] 缩略图能读出职责和方向。
- [ ] 轮廓不依赖黑描边。
- [ ] 高光不超过焦点对象面积的 15%。
- [ ] 颜色数量受控，状态色没有变成装饰色。
- [ ] 同族资产的切面比例、边缘节奏和高光宽度一致。
