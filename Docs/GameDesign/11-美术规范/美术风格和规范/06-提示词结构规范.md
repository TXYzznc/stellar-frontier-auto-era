# 06 · 提示词结构规范

每份可交付提示词都必须包含以下八个模块：

1. **对象定位**：ID、职责、目标玩家识别点。
2. **画布/视图**：尺寸、透明/不透明、正面/轴测/爆炸、留白。
3. **大形与结构**：轮廓、组件、接口、支撑和动作轴。
4. **材质与色板**：继承全局 Token，写出主材质和焦点色。
5. **光影与清线赛璐璐**：大色面、硬边阴影、局部高光线。
6. **状态后缀**：每个状态独立编号、文件名和变化句。
7. **技术输出**：PNG/SVG/源稿、border、透明、无文字、命名。
8. **负面提示和验收**：禁止内容、结构和视觉检查。

每个状态必须可单独复制；状态派生可以引用同族母版，但必须写出“保持轮廓、尺寸、Pivot 完全一致，只改变……”的完整句子。
