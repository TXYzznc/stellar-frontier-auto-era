# 05 · VFX、动画与音频规范

## VFX

VFX 必须由真实状态触发、可中断、可回收；选择、合法性、施工、湿度、矿脉稀疏、水面和状态灯采用低频几何效果。禁止持续扫描光束、全屏噪波、无意义闪烁和提前成功。

## 动画

刚性关节优先。机器动作统一为“待机 → 预动作 → 加速 → 工作 → 受控减速 → 安全收回”。取消、断电、目标失效和阻塞必须有安全收束姿态；离线不补播历史动作。

## 音频

环境、机器、UI/警报、音乐四层分开设计。循环音必须有无缝循环点；同类机器限制同时声源数；视觉警报和声音事件都绑定权威状态，不使用角色语音。

- [ ] 音画状态一致，不提前宣告结果。
