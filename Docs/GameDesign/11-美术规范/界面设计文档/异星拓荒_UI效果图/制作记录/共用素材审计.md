# 共用素材审计与处理

## 原始图片尺寸与文件名不一致

27张输入PNG的实际分辨率并非文件名所声明的尺寸：框架与图标为1254×1254，按钮与反馈图为1774×887。完整实际尺寸、文件名声明尺寸和原文件SHA-256见 `输入文件指纹.json`。

本次只输出效果图，没有把这些原文件原样标记为符合Unity切图导入合同的资源。引用前进行了透明通道清理和显示尺寸归一化。

## 母版与状态

根框架复用同一normal母版并按固定边角进行拉伸；状态结构在同一容器合同上增加刻线、边轨、断口、斜线纹理或闭合端点。控件和反馈采用对应共用文档的统一几何合同构造，而不是为每个页面绘制一套不同风格的按钮或进度条。页面专属glyph继续使用统一六边形图标壳。

输出不是原始共用切图修复包。若要直接导入这些输入母版，仍应另行完成其实际分辨率、九宫格border、Pivot与状态轮廓的一致性验收。

## 透明与品牌

本包最终PNG仅有0和255两类alpha值，消除了输入图中极低alpha背景噪点以及接近255但非完全不透明的内部像素。PNG外部透明、面板内部不透明；没有棋盘格背景烘焙。

输入没有Brand/Logo中的冻结PNG。所有界面不添加Logo，不以普通字体重新拼出一个近似字标替代源Logo。
