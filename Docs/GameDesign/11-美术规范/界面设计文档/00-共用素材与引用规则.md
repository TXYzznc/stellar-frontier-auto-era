# 共用素材与引用规则

## 1. 三种复用策略

| 策略 | 条件 | 做法 |
|---|---|---|
| A 完全共用 | 视觉职责和形体完全一致 | 一份素材，多页面引用 |
| B 同族变体 | 轮廓一致，只差状态/语义色/尺寸 | 母版＋逐状态独立文件 |
| C 形似不同 | 改图会改变玩家理解 | 页面专属素材，不能塞进共用族 |

## 2. 编号规则

共用容器/控件使用 `SHR-UI-###-state`；图标使用 `ICO-###-state`；页面专属使用 `SCR-<页面族>-###-state`。每个需要绘制的状态都是一个独立编号、文件名、源图和验收记录。程序绘制项使用 `PROC-UI-###`，不要求生图。

## 3. 引用规则

页面文档只写 ID，不复制共用提示词。新增共用素材必须回写本目录索引、manifest 和引用矩阵。仅仅因为两个素材都是按钮，不代表可以共用；先检查轮廓、职责、尺寸和状态语义。

## 4. 出图优先级

1. 面板/对话框/卡片/按钮/页签。
2. 进度条、滚动条、输入框、遮罩、Toast。
3. 导航/状态/资源/类别/世界交互图标。
4. 18 个页面族专属素材。

## 5. 全局 UI 验收

- [ ] 1920×1080 正文 18px 缩略图可读。
- [ ] 页面焦点不被背景装饰抢走。
- [ ] `FieldHudDetailForm` 位于 `FieldHudResidentForm` 上方。
- [ ] 动态文字、数字和连线不进入切图。
- [ ] 每个状态同时有颜色和非颜色反馈。
