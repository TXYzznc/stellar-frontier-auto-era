# 共用素材与引用规则

## 1. 复用判断

| 判断 | 处理 |
|---|---|
| 轮廓、职责和状态语义完全一致 | 复用同一母版，页面只引用 ID。 |
| 轮廓一致但状态不同 | 使用同一母版的状态文件；状态必须写出结构、纹理或几何差异。 |
| 玩家理解会改变，或主体形状不同 | 另建页面专属素材，不把近似外观塞进共用母版。 |

## 2. 新编号

共用母版使用 `UI-MASTER-###-state`；品牌 Logo 使用 `LOGO-###-*`，页面引用合同使用 `LOGO-REF-001`；页面专属资源继续使用 `SCR-<页面族>-###-state`。运行时绘制项使用 `UI-RUNTIME`，不进入 Sprite 导入清单。

## 3. 母版和状态合同

- `UI-MASTER-001`：页面画框、面板与对话框共用壳；中央必须镂空透明。
- `UI-MASTER-002`：按钮与操作控件；本体必须上下顶满画布。
- `UI-MASTER-003`：六边形图标壳和语义 glyph；语义靠轮廓、数量、方向区分。
- `UI-MASTER-004`：反馈、进度与结果轨道；圆形/六边形/菱形端点独立成 1:1 方形素材。
- `UI-MASTER-005`：列表行、端口行与条目；行本体四边顶满画布。
- `UI-MASTER-006`：状态提示与空态框；七种语义共用同一外框。
- `UI-MASTER-007`：细轨、滑块把手与分段计量；把手独立成 1:1 方形素材。
- `UI-MASTER-008`：输入槽、下拉、复选框与开关行；槽体四边顶满画布。
- `UI-MASTER-009`：页签、挂耳、侧栏项与页签组；平端帽与挂耳两种形态各自内部一致。
- `UI-MASTER-010`：滚动条轨、把手与分隔线；把手独立成 1:1 方形素材。
- `UI-MASTER-011`：卡片、槽位卡与画框外装饰层；卡片四边顶满画布，装饰层中央必须镂空。
- `UI-MASTER-012`：算法工作台的节点卡、连接点、连线与网格底；连接点与拐角为 1:1 方形件。
- `UI-MASTER-013`：功能图标；与 `UI-MASTER-003` 共用同一图标壳，只更换语义 glyph。
- `LOGO-REF-001`：只引用已生成的三种 Logo PNG，不允许模型重新设计。

同一母版下所有状态必须连续出现在同一生产文档中。每个状态要说明具体几何、明度、纹理或装饰变化；只换颜色的状态不通过验收。状态在灰度缩略图中至少保留两种非色彩差异。

## 4. 生图批次上限

每份可直接交给 AI 执行的文档最多 10 个生图需求。当前共用文档分别为 3、6、6、8、10、8、7、8、10、8、6、7、8、10 条，均可直接作为一批导入；导入工具按表格顺序匹配源文件。以后新增文档也必须保持不超过 10 条。

## 5. Logo 引用流程

先执行 [00-Logo设计与引用](./共用素材/00-Logo设计与引用.md)，确认三种分辨率 PNG 已导入 `Assets/Game/Sprites/UI/Brand/Logo/`。页面或效果图批次出现 Logo 时，在提示词中上传对应 PNG 并写 `LOGO-REF-001`；禁止把页面截图、重新绘制的近似标志或带背景的 Logo 当源文件。

## 6. 全局 UI 验收

- [ ] 各元素只引用已登记的母版（`UI-MASTER-001`~`013`），不复制近似外观。
- [ ] 状态的结构差异在灰度缩略图中可见，且状态含义与文档一致。
- [ ] 动态文字、数字、连线、百分比和进度不进入切图。
- [ ] Logo 只来自 `LOGO-REF-001` 的上传参考图，比例、缺口和星核层数未改变。
- [ ] 页面专属素材没有偷换成共用母版的伪变体。

## AI 单文档生成合同（可独立投喂）

### 共同输入与身份控制

本文件本身就是完整生成合同。输入只包括本文件和（画面需要 Logo 时）已经生成的 Logo PNG。Logo 不是重新设计对象：保持徽记缺口方向、星核层数、字标比例、负空间和透明背景完全一致；未明确写“出现 Logo”的画面不得自行添加 Logo。不要引用旧截图、旧模型、参考游戏界面或未登记资源。

### 视觉风格

- 原创工业二次元清线赛璐璐：平整色块、硬边阴影、2–4px 结构线、少量冷白高光线；轮廓清楚，避免照片级材质和柔焦。
- 形体采用 12°/30°/45° 的规整切角和模块化边界；相同母版的外轮廓、透视、锚点和安全区必须保持一致。
- 画面信息层级按“主体轮廓 → 状态装饰 → 留字/留数值槽 → 次要纹理”排列，不能用装饰抢主操作焦点。

### 配色 Token 与使用比例

- `UI/Background #111923`：页面底、遮罩和未激活区域，占画面约 55%–70%。
- `UI/Surface #1B2633`：主面板和导航底，占约 15%–25%。
- `UI/Card #2B3745`、`UI/CardRaised #364657`：卡片、列表、悬停和聚焦层，占约 8%–15%。
- `UI/TextPrimary #E9EEF2`、`UI/TextSecondary #AEBCC7`：只作为留字槽对比参考，图片中不生成可读文字。
- `UI/Action #E68A37`、`UI/Focus #F0A24B`：操作、焦点和确认强调，合计不超过画面 8%。
- `UI/Success #67C28A`、`UI/Warning #D8B15A`、`UI/Danger #D75E63`：状态色只作辅助，必须同时有形状、刻线、缺口、纹理或位置变化。
- `UI/Alien #79A9C7`：异星数据或传感器信息，禁止大面积铺满。

颜色只负责语义辅助；normal、hover、pressed、selected、disabled、warning、danger、empty 等状态必须另外加入位置、轮廓、刻线、断口、斜线纹理、内缩或外伸等非颜色差异。

### 内容与构图要求

- 先按本文件资源表逐条生成，不合并条目，不新增未登记的按钮、图标、文字、数字、徽章或装饰。
- 容器和控件中心保留运行时文字/数值槽；图标使用统一母版壳，语义由几何形状、数量和方向表达。
- 页面类画面采用 1920×1080 安全区，四周留 24px；透明切图按表格尺寸正面输出，九宫格边角不可进入中心拉伸区。
- 需要 Logo 时，直接使用上传的 Logo PNG，保持原始比例，不把 Logo 烘焙进其它切图。

### 技术输出

- 透明 PNG，sRGB，边缘无白边和半透明脏边；不生成可读文字、数字、百分比、连线、动态粒子或程序遮罩。
- 文件名、尺寸和 `Assets/Game/Sprites/` 目标目录严格使用本文件资源表；每个状态独立导出并保持画布、Pivot 和安全区一致。

### 交付验收

- [ ] 每个表格条目都有独立文件，数量和顺序与文档一致。
- [ ] 同一母版所有状态的外轮廓、画布和锚点完全一致。
- [ ] 状态在灰度缩略图中至少有两种非颜色差异。
- [ ] 目标尺寸、透明背景、文件名和路径全部符合表格。

### 风格

原创工业二次元清线赛璐璐；平整色块、硬边阴影、少量结构高光，保持本文件的形体、镜头和色彩合同，不使用照片、柔焦或参考游戏复制。

### 输出

按本文件登记的尺寸、视图、透明度、文件名和目标路径交付；透明切图使用干净 PNG，效果图使用 1920×1080，sRGB，无裁切、白边和背景污染。

### 构图

主体优先，前景/中景/背景或标题区/主体区/反馈区按本文层级排列；四周保留安全区，接口、作业点、状态装饰和运行时留槽必须完整可见，不用空背景或无关装饰填充画面。
