# 界面设计文档

本目录按参考文档的生产级粒度拆分 UI 美术。共用素材采用少量母版和明确状态合同；每份生图文档最多 10 条，导入工具按表格顺序接收外部生成文件。

## 文档层级

- `00-资源覆盖与制作状态.md`：已完成资源、效果图交付范围，以及旧版“90 个”占位需求的撤销说明。
- `00-共用素材与引用规则.md`：母版复用、状态差异、Logo 引用和批次上限。
- `01-提示词规范与输出约定.md`：效果图、透明切图、程序绘制三类产物的固定模板。
- `共用素材/README.md`：新母版索引和路径映射。
- `共用素材/00-Logo设计与引用.md`：Logo 三种分辨率，必须先生成并冻结。
- `共用素材/01-UI框架母版.md`：容器、卡片、对话框、列表和空态。
- `共用素材/02-交互控件母版.md`：按钮、页签、输入槽和开关。
- `共用素材/03-语义图标母版.md`：统一图标壳与可区分语义 glyph。
- `共用素材/04-反馈与进度母版.md`：进度、加载、提示、阻塞和结果反馈。
- `界面/01~18`：页面族布局、页面专属素材、交互状态和母版引用。

## 生成顺序

Logo → UI 框架母版 → 交互控件母版 → 语义图标母版 → 反馈与进度母版 → 页面族效果图 → 结合 Prefab 确认是否需要页面专属切图 → 状态复核。

## 产物边界

效果图是组合验收图；透明切图是可拆分运行时素材；程序绘制项包括 TMP 文字、算法连线、数值、动态进度和纯色遮罩。不能把效果图直接导入 Unity。

## Unity 存放路径

- Logo：`Assets/Game/Sprites/UI/Brand/Logo/`。
- 框架母版：`Assets/Game/Sprites/UI/Common/01-Containers/`。
- 交互控件：`Assets/Game/Sprites/UI/Common/02-ButtonsAndTabs/`。
- 反馈与进度：`Assets/Game/Sprites/UI/Common/03-ProgressAndInputs/`。
- 语义图标：`Assets/Game/Sprites/UI/Common/06-StatusAndEvents/`。
- 页面专属切图：`Assets/Game/Sprites/UI/Pages/<页面编号>-<页面族>/`（仅存放经过实际接入确认的独有透明资源，不预置占位图）。
- 页面效果图：`Assets/Game/Sprites/UI/EffectBoards/`。
- `UI-RUNTIME` 只由程序运行时绘制，不生成或存入 Sprite。

## 批次上限

当前共用文档分别为 3、6、6、8、7 条需求，均不超过 10 条；同一母版的全部状态连续放在同一文档中。以后新增文档仍必须保持不超过 10 条，并在导入工具中刷新目录索引。

## AI 单文档生成合同（可独立投喂）

### 共同输入与身份控制

本文件本身就是完整生成合同。输入只包括本文件和（画面需要 Logo 时）已经生成的 Logo PNG。Logo 不是重新设计对象：保持徽记缺口方向、星核层数、字标比例、负空间和透明背景完全一致；未明确写“出现 Logo”的画面不得自行添加 Logo。不要引用旧截图、旧模型、参考游戏界面或未登记资源。

### 视觉风格

- 原创工业二次元清线赛璐璐：平整色块、硬边阴影、2–4px 结构线、少量冷白高光线；轮廓清楚，避免照片级材质和柔焦。
- 形体采用 12°/30°/45° 的规整切角和模块化边界；相同母版的外轮廓、透视、锚点和安全区必须保持一致。
- 画面信息层级按“主体轮廓 → 状态装饰 → 留字/留数值槽 → 次要纹理”排列，不能用装饰抢主操作焦点。

### 配色 Token 与使用比例

- `UI/Background #111923`：页面底、遮罩和未激活区域，占画面约 55%–70%。
- `UI/Surface #1B2633`：主面板和导航底，占约 15%–25%。
- `UI/Card #2B3745`、`UI/CardRaised #364657`：卡片、列表、悬停和聚焦层，占约 8%–15%。
- `UI/TextPrimary #E9EEF2`、`UI/TextSecondary #AEBCC7`：只作为留字槽对比参考，图片中不生成可读文字。
- `UI/Action #E68A37`、`UI/Focus #F0A24B`：操作、焦点和确认强调，合计不超过画面 8%。
- `UI/Success #67C28A`、`UI/Warning #D8B15A`、`UI/Danger #D75E63`：状态色只作辅助，必须同时有形状、刻线、缺口、纹理或位置变化。
- `UI/Alien #79A9C7`：异星数据或传感器信息，禁止大面积铺满。

颜色只负责语义辅助；normal、hover、pressed、selected、disabled、warning、danger、empty 等状态必须另外加入位置、轮廓、刻线、断口、斜线纹理、内缩或外伸等非颜色差异。

### 内容与构图要求

- 先按本文件资源表逐条生成，不合并条目，不新增未登记的按钮、图标、文字、数字、徽章或装饰。
- 容器和控件中心保留运行时文字/数值槽；图标使用统一母版壳，语义由几何形状、数量和方向表达。
- 页面类画面采用 1920×1080 安全区，四周留 24px；透明切图按表格尺寸正面输出，九宫格边角不可进入中心拉伸区。
- 需要 Logo 时，直接使用上传的 Logo PNG，保持原始比例，不把 Logo 烘焙进其它切图。

### 技术输出

- 透明 PNG，sRGB，边缘无白边和半透明脏边；不生成可读文字、数字、百分比、连线、动态粒子或程序遮罩。
- 文件名、尺寸和 `Assets/Game/Sprites/` 目标目录严格使用本文件资源表；每个状态独立导出并保持画布、Pivot 和安全区一致。
