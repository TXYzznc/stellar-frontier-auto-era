# 界面设计文档

本目录按参考文档的生产级粒度拆分 UI 美术。每个共用素材批次可单独喂给生图 AI；每个页面族文档可单独交付给 UI 设计师和程序。

## 文档层级

- `00-共用素材与引用规则.md`：编号、状态、完全共用/同族变体/形似不同三种策略、引用矩阵和出图优先级。
- `01-提示词规范与输出约定.md`：UI 效果图、透明切图、程序绘制三类产物的固定模板。
- `共用素材/01~09`：每批自包含，含固定视觉模块、技术硬约束、逐状态提示词、文件名、批次建议和验收。
- `界面/01~18`：每个页面族包含概述、真实 Form/contract 来源、布局规格、元素清单、效果图中英文提示词、专属素材、交互状态、共用引用和验收。

## 生成顺序

共用容器 → 控件/页签 → 进度/滚动 → 装饰 → 图标 → 世界 HUD 标记 → 页面族效果图 → 页面专属切图 → 状态复核。

## 产物边界

效果图是组合验收图；透明切图是可拆分运行时素材；程序绘制项包括 TMP 文字、算法连线、数值、动态进度和纯色遮罩。不能把效果图直接导入 Unity。
