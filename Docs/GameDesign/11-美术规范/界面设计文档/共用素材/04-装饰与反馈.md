# 共用素材批次 · 分隔线、分组标题、角标、Toast、空状态、加载标记、焦点框

> 本文件可单独交给 UI 美术或生图 AI。每个状态是一个独立交付条目；程序绘制项明确标记为不生图。

## 1. 固定视觉模块

```text
原创工业二次元科幻 UI，深灰蓝底，浅色信息卡，少量橙色焦点，清线赛璐璐，平整色块，硬边阴影，锐角切角，模块化网格，细窄结构线，原创异星拓荒符号，成熟商业游戏完成度。
```

### 色彩与光影

| Token | 色值 | 用途 |
|---|---|---|
| UI/Background | #111923 | 页面底 |
| UI/Surface | #1B2633 | 主面板 |
| UI/Card | #2B3745 | 浅色信息卡 |
| UI/CardRaised | #364657 | hover/重点卡 |
| UI/Action | #E68A37 | 主操作/焦点 |
| UI/TextPrimary | #E9EEF2 | 主文字 |
| UI/Success | #67C28A | 正常/完成 |
| UI/Warning | #D8B15A | 等待/注意 |
| UI/Danger | #D75E63 | 故障/危险 |

高光只落在结构边缘 1~2px；阴影短而硬；不用统一黑描边、玻璃拟态、霓虹、随机文字、旧游戏 UI 或旧项目截图。

## 2. 本批硬性约束

- 透明切图必须写明源图尺寸、border、Pivot、九宫格拉伸区和不可绘制区域。
- 同族状态保持画布、外轮廓、Pivot、文字槽和锚点一致，只改变语义色、明暗或状态标记。
- 动态文字和数字不画入素材；程序项不生图，只提供样式参数。
- 生图输入不得包含旧资源参考图；每个输出保存 NEW-GEN 记录。

## 4. 出图批次建议

先生成每族 normal/empty 母版，确认外轮廓、色板和留白，再逐状态派生。一次只生成同族 4~12 个状态，完成后检查像素尺寸、透明边缘、切图拉伸和状态一致性。

## 5. 本批验收清单

- [ ] 每个状态有独立 ID、文件名、提示词和源文件指纹。
- [ ] 透明边缘无白边、黑边和被裁切高光。
- [ ] 9 倍拉伸后四角、边缘和中心不出条纹。
- [ ] 状态同时具备颜色与图标/形状/文字槽变化。
- [ ] 没有参考游戏复制、旧素材重绘和伪造 UI 文本。
