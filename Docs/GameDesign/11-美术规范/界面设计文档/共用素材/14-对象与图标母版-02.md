# 对象与图标母版：能源、种子、作物与礼包

本批覆盖对象清单中的 2 类资源对象（水、生物质）、1 类能源对象（电能）、2 类种子对象（银穗麦种、赤芯芒种）、2 类作物对象（银穗麦、赤芯芒）与 3 类礼包对象（银穗麦种子包、赤芯芒种子包、应急生物质包），每个对象交付一枚 128×128 正面图标。这些图标被建造与生产面板、农田与播种界面、库存与产出条目、配方输入输出槽、奖励与补给弹窗等多个页面复用，同一枚文件在多处引用而不重画。十条需求必须同批生成，保证同族外框、线宽与定位槽完全一致。

## 共用几何合同

基准画布 **128×128**，全部为 1:1 方形件。

- 图标壳沿用 `03-语义图标母版` / `13-功能图标母版` 的壳语言：规整切角（12°/30°/45°）、冷白 2px 连续轮廓、中心定位槽；**不同对象类别使用不同外框形状**，本批出现四种外框——资源为「切角菱形」（四角 45° 切角），能源为「圆形带上下引出缺口」，种子与作物为「圆角方」，礼包为「梯形封条」（梯形外框 + 顶部一条通长封条横线）。
- 每个图标是**独立正面件**：`spriteBorder` 全 0，按 32×32 或 64×64 正面使用，**不参与九宫格拉伸**；不得为适应尺寸而改动外框形状、切角方向或定位槽。
- 语义只能靠几何形状、数量、方向和断口表达：同一图标内不得出现可读文字、数字、字母、货币符号或人物头像。
- 层级与线宽：外框为 2px 连续轮廓，内部 glyph 为 4–6px 实心或空心几何，glyph 与外框之间至少留 12px 负空间。
- 同类外框必须逐像素一致：叠加本批任意两枚资源图标（或任意两枚种子 / 作物 / 礼包图标）时，外轮廓、切角与封条线位置必须完全重合。
- 导出 PNG 的实际像素必须等于文件名标注的尺寸（全部 128×128）。
- 不得烘焙发光、渐变、投影光晕或动态粒子。

## AI 单文档生成合同（可独立投喂）

### 共同输入与身份控制

本文件本身就是完整生成合同。输入只包括本文件和（画面需要 Logo 时）已经生成的 Logo PNG。Logo 不是重新设计对象：保持徽记缺口方向、星核层数、字标比例、负空间和透明背景完全一致；未明确写“出现 Logo”的画面不得自行添加 Logo。不要引用旧截图、旧模型、参考游戏界面或未登记资源。

### 视觉风格

- 原创工业二次元清线赛璐璐：平整色块、硬边阴影、2–4px 结构线、少量冷白高光线；轮廓清楚，避免照片级材质和柔焦。
- 形体采用 12°/30°/45° 的规整切角和模块化边界；相同母版的外轮廓、透视、锚点和安全区必须保持一致。
- 画面信息层级按“主体轮廓 → 状态装饰 → 留字/留数值槽 → 次要纹理”排列，不能用装饰抢主操作焦点。

### 配色 Token 与使用比例

- `UI/Background #111923`：页面底、遮罩和未激活区域，占画面约 55%–70%。
- `UI/Surface #1B2633`：主面板和导航底，占约 15%–25%。
- `UI/Card #2B3745`、`UI/CardRaised #364657`：卡片、列表、悬停和聚焦层，占约 8%–15%。
- `UI/TextPrimary #E9EEF2`、`UI/TextSecondary #AEBCC7`：只作为留字槽对比参考，图片中不生成可读文字。
- `UI/Action #E68A37`、`UI/Focus #F0A24B`：操作、焦点和确认强调，合计不超过画面 8%。
- `UI/Success #67C28A`、`UI/Warning #D8B15A`、`UI/Danger #D75E63`：状态色只作辅助，必须同时有形状、刻线、缺口、纹理或位置变化。
- `UI/Alien #79A9C7`：异星数据或传感器信息，禁止大面积铺满。

颜色只负责语义辅助；normal、hover、pressed、selected、disabled、warning、danger、empty 等状态必须另外加入位置、轮廓、刻线、断口、斜线纹理、内缩或外伸等非颜色差异。
