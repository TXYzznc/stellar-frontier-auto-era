# 页签与导航母版：页签、挂耳、侧栏项与页签组

页签、挂耳页签、侧栏导航项和页签组底条共用同一套“斜切端帽 + 留字槽”语言。工程里页签节点为 177×48（8 处），页签组底条为 1320×52，侧栏导航由 `Grp_Navigation` 承载。八条需求同批生成。

## 共用几何合同

基准画布 **512×64**。

- **页签本体必须四边顶满画布**：第 0 行、第 63 行、第 0 列、第 511 列都是本体像素（最外 2px 轮廓线或投影即可），不得出现透明留白，也不得把页签画成一条浮在画面中间的细条。
- 左右各留 **24px 安全区**（画端帽与选中标记位）；上下各留 **8px**（画上下边线与挂耳根部）。
- 中央 `x∈[24,488]`、`y∈[8,56]` 必须**纯平**：无图案、无渐变、无分割线、无装饰，供运行时填充页签文字。横向与纵向拉伸后都不得出现条纹。
- 页签有两种**形态**，同一形态内各状态必须逐像素同轮廓：
  - 平端帽形态：左右端帽为 12° 斜切，顶部边线连续；
  - 挂耳形态：左右端帽改为顶部挂耳（上边线在两端上折 12px 形成挂耳根部），其余几何不变。
- 侧栏导航项在左端 24px 安全区内保留**图标槽**（不放 glyph，运行时引用语义图标）；右侧保持纯平留字槽。
- 九宫格：`spriteBorder = {x:24, y:8, z:24, w:8}`，控件最小尺寸 48×16，可服务 177×48 一类的页签与侧栏项。
- 导出 PNG 的实际像素必须等于文件名标注的尺寸；同一形态内各状态的外轮廓、端帽与安全区必须逐像素一致。
- 不得烘焙页签文字、数字或图标 glyph。

本文件本身就是完整生成合同。输入只包括本文件和（画面需要 Logo 时）已经生成的 Logo PNG。Logo 不是重新设计对象：保持徽记缺口方向、星核层数、字标比例、负空间和透明背景完全一致；未明确写“出现 Logo”的画面不得自行添加 Logo。不要引用旧截图、旧模型、参考游戏界面或未登记资源。

### 视觉风格

- 原创工业二次元清线赛璐璐：平整色块、硬边阴影、2–4px 结构线、少量冷白高光线；轮廓清楚，避免照片级材质和柔焦。

### 配色 Token 与使用比例

- `UI/Background #111923`：页面底、遮罩和未激活区域，占画面约 55%–70%。
