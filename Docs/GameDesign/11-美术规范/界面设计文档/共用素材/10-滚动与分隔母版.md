# 滚动与分隔母版：滚动条轨、把手与分隔线

列表、队列与详情面板都放在滚动视图里（工程里 15 个 `List_*` / `Viewport_*` 容器，当前均未挂滚动条视觉件），分组与区段之间需要通用分隔线。滚动条轨与把手分离，避免把手或端帽被九宫格拉伸。六条需求同批生成。

## 共用几何合同

基准画布：滚动条轨 **512×24**（水平）/ **24×512**（垂直）；把手 **64×64**；分隔线 **512×8**（水平）/ **8×512**（垂直）；虚线分隔 **32×8** 平铺件。

- **轨本体必须贴满画布**：水平轨第 0 行与第 23 行、第 0 列与第 511 列都是轨道像素；垂直轨同理。不得出现透明留白，也不得把轨道画成一条浮在画面中间的细线。
- 水平轨左右各留 **12px 端帽区**（12° 斜切收口），中段 `x∈[12,500]` 必须是可横向无缝重复的平直轨道；垂直轨上下各留 **12px 端帽区**，中段可纵向无缝重复。
- 分隔线本体贴满画布：水平线 `y∈[0,7]` 内为 2px 连续线 + 上下各 3px 留白；中线在视觉上居中，左右各留 **8px 收口区**。
- 虚线分隔线以 **32×8** 为平铺单元：一个单元内包含一段 16px 实线段 + 16px 空隙，首尾必须能无缝相接（单元右边界与左边界拼合后线宽、间距不变）。此件**不做九宫格**，用 `Image.type = Tiled` 平铺。
- 把手单独绘制在 64×64 方形画布上，1:1 正形，`spriteBorder` 全 0，按 24×24 或 32×32 正面使用，**不参与九宫格拉伸**。
- 九宫格：水平轨 `spriteBorder = {x:12, y:0, z:12, w:0}`（控件最小尺寸 24×1）；垂直轨 `{x:0, y:12, z:0, w:12}`（控件最小尺寸 1×24）；分隔线 `{x:8, y:0, z:8, w:0}`（控件最小尺寸 16×1）；虚线件与把手全 0。
- 导出 PNG 的实际像素必须等于文件名标注的尺寸；水平与垂直件必须是同一几何的 90° 旋转关系，端帽收口角一致。
- 不得烘焙滚动位置、百分比或文字。
