# UI 框架母版：容器与信息壳

这一个母版覆盖卡片、面板、对话框、列表、槽位和空态。外观相似的功能不再拆成多个母版，差异通过尺寸、九宫格拉伸区、标题槽和状态装饰表达。六条需求必须同批生成。

## 共用几何合同

基准画布 512×512；外框 32px 切角，四角各有一组 3px 刻线；内框距外框 20px，整圈条带厚度不超过 52px；顶部标题槽高度 64px；九宫格安全区四边均为 96px，即所有边框、切角、刻线和状态装饰都必须落在距画布边缘 96px 以内；中央 `x∈[96,416]`、`y∈[96,416]` 的区域必须完全透明，不得有填充、渐变、阴影、纹理、空槽轮廓或插画，供运行时文字、数值和列表内容填充。容器、卡片和对话框只允许改变宽高比例与标题槽，不得换一套边框。

六态的条带厚度、切角位置和安全区必须逐像素一致，状态差异只能画在安全区内部，不得靠加厚条带或在中央作画来表达状态。导出 PNG 的实际像素必须等于文件名标注的 512×512；不得导出放大后的版本再依赖导入设置缩放——九宫格边界以源像素为单位，尺寸不一致会直接破坏安全区。接入时 `spriteBorder` 四边均取 96，画框最小可用尺寸为 192×192。

## AI 单文档生成合同（可独立投喂）

### 共同输入与身份控制

本文件本身就是完整生成合同。输入只包括本文件和（画面需要 Logo 时）已经生成的 Logo PNG。Logo 不是重新设计对象：保持徽记缺口方向、星核层数、字标比例、负空间和透明背景完全一致；未明确写“出现 Logo”的画面不得自行添加 Logo。不要引用旧截图、旧模型、参考游戏界面或未登记资源。

### 视觉风格

- 原创工业二次元清线赛璐璐：平整色块、硬边阴影、2–4px 结构线、少量冷白高光线；轮廓清楚，避免照片级材质和柔焦。
- 形体采用 12°/30°/45° 的规整切角和模块化边界；相同母版的外轮廓、透视、锚点和安全区必须保持一致。
- 画面信息层级按“主体轮廓 → 状态装饰 → 留字/留数值槽 → 次要纹理”排列，不能用装饰抢主操作焦点。

### 配色 Token 与使用比例

- `UI/Background #111923`：页面底、遮罩和未激活区域，占画面约 55%–70%。
- `UI/Surface #1B2633`：主面板和导航底，占约 15%–25%。
- `UI/Card #2B3745`、`UI/CardRaised #364657`：卡片、列表、悬停和聚焦层，占约 8%–15%。
- `UI/TextPrimary #E9EEF2`、`UI/TextSecondary #AEBCC7`：只作为留字槽对比参考，图片中不生成可读文字。
- `UI/Action #E68A37`、`UI/Focus #F0A24B`：操作、焦点和确认强调，合计不超过画面 8%。
- `UI/Success #67C28A`、`UI/Warning #D8B15A`、`UI/Danger #D75E63`：状态色只作辅助，必须同时有形状、刻线、缺口、纹理或位置变化。
- `UI/Alien #79A9C7`：异星数据或传感器信息，禁止大面积铺满。

颜色只负责语义辅助；normal、hover、pressed、selected、disabled、warning、danger、empty 等状态必须另外加入位置、轮廓、刻线、断口、斜线纹理、内缩或外伸等非颜色差异。

### 内容与构图要求

- 先按本文件资源表逐条生成，不合并条目，不新增未登记的按钮、图标、文字、数字、徽章或装饰。
- 容器和控件中心保留运行时文字/数值槽；图标使用统一母版壳，语义由几何形状、数量和方向表达。
- 页面类画面采用 1920×1080 安全区，四周留 24px；透明切图按表格尺寸正面输出，九宫格边角不可进入中心拉伸区。
- 需要 Logo 时，直接使用上传的 Logo PNG，保持原始比例，不把 Logo 烘焙进其它切图。

### 技术输出

- 透明 PNG，sRGB，边缘无白边和半透明脏边；不生成可读文字、数字、百分比、连线、动态粒子或程序遮罩。
