# 对象与图标母版：礼包、载体、核心与传感器

本批覆盖礼包（3 条）、载体（2 条）、核心（1 条）、传感器（4 条）共四类对象，对应 `FirstVersionObjects.txt` 中的十个具体对象，每条对象需要一枚独立图标。这些对象图标跨仓库、制造、布点选址、机器编组与状态观测等页面复用，同一对象在所有页面必须使用同一枚图标。十条需求同批生成，以保证同类外框形状逐像素一致。

## 共用几何合同

基准画布 **128×128**，全部为 1:1 方形件。

- 沿用 `03-语义图标母版` / `13-功能图标母版` 的图标壳语言：规整切角外壳、冷白 2px 连续轮廓、中心定位槽、四边线宽统一 2px；中心定位槽方向不可变，本文件只更换外框切角方式与壳内对象 glyph。
- 不同类别使用不同外框形状：**礼包=梯形封条、载体=方形带轮位缺口、核心=同心方环、传感器=方形带弧线开口**。同类对象的外框形状、切角与缺口位置逐像素一致，仅中心 glyph 不同；异类之间靠外框形状即可分辨。
- 每个图标是**独立正面件**：`spriteBorder` 全 0，按 32×32 或 64×64 正面使用，**不参与九宫格拉伸**；不得为适应尺寸而改变外框形状、切角、缺口方向或中心定位槽。
- 语义只能靠几何形状、数量、方向和断口表达：同一图标内不得出现可读文字、数字、字母、货币符号或人物头像。
- 外框为 2px 连续轮廓，中心 glyph 为 4–6px 实心或空心几何，glyph 与外框之间至少留 12px 负空间。
- 状态差异只用形状、缺口、层数表达，不靠颜色：selected / disabled / warning 等状态由程序在外框外添加标记，生图只交付对象图标本体。
- 导出 PNG 的实际像素必须等于文件名标注的尺寸（全部 128×128）。
- 不得烘焙发光、渐变、投影光晕或动态粒子。
