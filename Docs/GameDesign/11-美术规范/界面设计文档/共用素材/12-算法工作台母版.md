# 算法工作台母版：节点卡、连接点、连线与网格底

算法工作台由节点卡、连接点、连线段和网格底四种件组成。工程里节点类节点 21 个（202×202 起）、连线段 24 个（32×32 起），**目前完全没有素材**；节点上的端口**行**（136×28）引用 `05-列表与条目母版`，不在本文件重复。八条需求同批生成。

## 共用几何合同

基准画布：节点卡 **512×256**；连接点 **64×64**；连线段 **512×32**；连接拐角 **128×128**；网格底 **256×256** 平铺件。

- **节点卡本体必须四边顶满画布**：第 0 行、第 255 行、第 0 列、第 511 列都是本体像素（最外 2px 轮廓线或投影即可），不得出现透明留白，也不得把节点画成一条浮在画面中间的细条。
- 节点卡左右各留 **24px 安全区**（画端帽与连接位），上下各留 **40px**（顶部 24px 标题带 + 底部 16px 端口带）。
- 节点卡中央 `x∈[24,488]`、`y∈[40,216]` 必须**纯平**：无图案、无渐变、无分割线、无装饰，供运行时填充节点标题、参数与端口名。
- 连线段本体上下贴满画布；左右各留 **16px 端帽区**（12° 收口），中段 `x∈[16,496]` 必须可横向无缝重复；本件不画拐角、不画箭头。
- 连接点是 64×64 的 1:1 方形件，`spriteBorder` 全 0，按 16×16 或 24×24 正面使用，**不参与九宫格拉伸**；左右端口共用同一图形，方向由运行时旋转决定。
- 连接拐角是 128×128 的 1:1 方形件（直角外弧 24px 半径），不在九宫格内拉伸。
- 网格底以 **256×256** 为平铺单元：2px 冷灰网格线、间距 32px、交点 3px×3px 短刻点，除网格线外全部透明；首尾必须无缝相接，此件**不做九宫格**，用 `Image.type = Tiled`。
- 九宫格：节点卡 `spriteBorder = {x:24, y:40, z:24, w:40}`，控件最小尺寸 48×80；连线段 `{x:16, y:0, z:16, w:0}`，控件最小尺寸 32×1；连接点、拐角与网格底全 0。
- 导出 PNG 的实际像素必须等于文件名标注的尺寸；四条节点态的外轮廓、安全区与端口带必须逐像素一致。
- 不得烘焙节点文字、参数数值、箭头或流动粒子。
