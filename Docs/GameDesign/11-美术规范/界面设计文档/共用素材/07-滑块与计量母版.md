# 滑块与计量母版：细轨、填充、把手与分段计量

设置页的音量/速度滑块（680×56，轨道只有 8px 高）、机器与能源的充能条（405×8、440×8、656×8）以及分段计量条共用同一套细轨语言。细轨高度只有 8px，必须由**本体顶满画布**的扁平素材服务；大尺寸反馈条见 `04-反馈与进度母版`。八条需求同批生成。

## 共用几何合同

基准画布：细轨 **512×16**；分段计量底板 **512×32**；把手 **64×64**。

- **细轨本体必须上下顶满画布**：第 0 行与第 15 行都是轨道像素，不得出现透明留白，也不得把轨道画成一条浮在画面中间的细线。轨道高度随控件高度整体拉伸，本母版**不画圆形或六边形端点**。
- 细轨左右各留 **16px 端帽区**（12° 斜切收口）；中段 `x∈[16,496]` 必须是可横向无缝重复的平直段。
- 分段计量底板 512×32：上下顶满；在 `x∈[32,480]` 内以等距刻线划分 8 段；刻线本身是装饰，不得下探到 `y∈[4,28]` 的填充安全区以内。
- 把手单独绘制在 64×64 方形画布上，保持 1:1 正形，按原尺寸正面使用（控件里显示为 24×24 或 32×32），**不参与九宫格拉伸**。
- 九宫格：细轨与分段底板 `spriteBorder = {x:16, y:0, z:16, w:0}`，控件最小尺寸 32×1，可服务 4px 以上的任意高度；把手 `spriteBorder` 全 0。
- 导出 PNG 的实际像素必须等于文件名标注的尺寸；同一几何的填充与轨道必须端点对齐、刻线对齐。
- 不得烘焙百分比、数字、文字或动态粒子。
