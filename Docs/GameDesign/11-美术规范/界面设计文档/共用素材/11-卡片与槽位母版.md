# 卡片与槽位母版：卡片、槽位卡与画框外装饰层

卡片、槽位卡和画框外装饰层共用同一套“切角 + 内框 + 状态刻线”语言。工程里槽位类节点 20 个（窄卡 177 宽）、队列与列表容器 37 个，**画框外装饰层 33 个（1520×840 ~ 1840×980）目前完全没有素材**。七条需求同批生成。

## 共用几何合同

基准画布：卡片与槽位卡 **512×256**；画框外装饰层 **512×512**。

- **卡片本体必须四边顶满画布**：第 0 行、第 255 行、第 0 列、第 511 列都是本体像素（最外 2px 轮廓线或投影即可），不得出现透明留白，也不得把卡片画成一条浮在画面中间的细条。
- 卡片左右各留 **32px 安全区**（画端帽与状态标记位），上下各留 **24px**（画上下边线与标题带）。
- 中央 `x∈[32,480]`、`y∈[24,232]` 必须**纯平**：无图案、无渐变、无分割线、无装饰，供运行时填充标题、摘要与列表内容。横向与纵向拉伸后都不得出现条纹。
- 槽位卡在卡片同一几何上增加两个固定槽位：顶部 24px 安全区内的**图标槽**（空正方形定位刻线）、底部 24px 安全区内的**数值槽边界**（一条 2px 短横线）；中央保持纯平。
- **画框外装饰层是镂空件，作用与 001 相反**：512×512 画布上只画画框**外侧**的装饰——四角 12° 切角、上下装饰带、侧边刻线；中央 `x∈[96,416]`、`y∈[96,416]` 必须**完全镂空透明**，运行时叠在 001 画框下层或上层，不得遮挡面板内容。
- 九宫格：卡片与槽位卡 `spriteBorder = {x:32, y:24, z:32, w:24}`，控件最小尺寸 64×48；画框外装饰层 `spriteBorder = {x:96, y:96, z:96, w:96}`，控件最小尺寸 192×192。
- 导出 PNG 的实际像素必须等于文件名标注的尺寸；同一几何的各状态外轮廓、安全区与槽位必须逐像素一致。
- 不得烘焙标题、数值、图标 glyph 或进度。

## AI 单文档生成合同（可独立投喂）

### 共同输入与身份控制

本文件本身就是完整生成合同。输入只包括本文件和（画面需要 Logo 时）已经生成的 Logo PNG。Logo 不是重新设计对象：保持徽记缺口方向、星核层数、字标比例、负空间和透明背景完全一致；未明确写“出现 Logo”的画面不得自行添加 Logo。不要引用旧截图、旧模型、参考游戏界面或未登记资源。

### 视觉风格

- 原创工业二次元清线赛璐璐：平整色块、硬边阴影、2–4px 结构线、少量冷白高光线；轮廓清楚，避免照片级材质和柔焦。
- 形体采用 12°/30°/45° 的规整切角和模块化边界；相同母版的外轮廓、透视、锚点和安全区必须保持一致。
- 画面信息层级按“主体轮廓 → 状态装饰 → 留字/留数值槽 → 次要纹理”排列，不能用装饰抢主操作焦点。

### 配色 Token 与使用比例

- `UI/Background #111923`：页面底、遮罩和未激活区域，占画面约 55%–70%。
- `UI/Surface #1B2633`：主面板和导航底，占约 15%–25%。
- `UI/Card #2B3745`、`UI/CardRaised #364657`：卡片、列表、悬停和聚焦层，占约 8%–15%。
- `UI/TextPrimary #E9EEF2`、`UI/TextSecondary #AEBCC7`：只作为留字槽对比参考，图片中不生成可读文字。
- `UI/Action #E68A37`、`UI/Focus #F0A24B`：操作、焦点和确认强调，合计不超过画面 8%。
- `UI/Success #67C28A`、`UI/Warning #D8B15A`、`UI/Danger #D75E63`：状态色只作辅助，必须同时有形状、刻线、缺口、纹理或位置变化。
- `UI/Alien #79A9C7`：异星数据或传感器信息，禁止大面积铺满。

颜色只负责语义辅助；normal、hover、pressed、selected、disabled、warning、danger、empty 等状态必须另外加入位置、轮廓、刻线、断口、斜线纹理、内缩或外伸等非颜色差异。
