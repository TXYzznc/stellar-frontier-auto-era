# 提示词规范与输出约定

## UI 效果图提示词模板

```text
【页面族与用途】写页面 ID、Form、玩家进入页面的目标。
【画布与布局】1920×1080，列出区域、锚点、宽高、间距和焦点顺序。
【信息层级】主标题、摘要、列表、详情、操作、警报的视觉权重。
【视觉语言】深灰蓝底、浅色信息卡、橙色焦点、清线赛璐璐锐角模块。
【示例状态】normal/empty/disabled/warning/error 中选择本页代表态。
【技术约束】动态文字用 SIMHEI 示例槽，最终切图不烘焙文字，层级按 B52 contract。
【负面提示】旧图复刻、参考游戏版式复制、乱码、人物、动物、战斗、玻璃拟态。
```

## 透明切图提示词模板

写清源图尺寸、border、透明背景、不可画文字、九宫格可拉伸区域、状态后缀、文件名和验收。四角/边缘被拉伸后不得产生条纹；不同状态外轮廓逐像素一致。

## 程序绘制项

TMP 文字、数字、进度填充、算法连线、选中脉冲、纯色遮罩和动态数据不交给生图 AI；文档只定义样式、颜色、线宽、速度和触发条件。

## 交付记录

每张图都要记录 `assetId / state / prompt / negative / model / seed / sourceHash / visualReview`。未有源文件指纹和用户视觉裁决的条目不能写 `ACCEPTED`。
