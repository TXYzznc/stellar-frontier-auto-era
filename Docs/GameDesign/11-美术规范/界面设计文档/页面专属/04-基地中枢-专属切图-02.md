# 页面专属切图：04-基地中枢（第二批）

基地中枢族在共用母版之外的第二批独有内容：中枢等级徽记三级 / 满级、统计图框、对象摘要素描卡、远程机器条目版式与中枢总览环形仪表框。容器、控件、图标、轨道一律引用 `UI-MASTER-001`~`014`，品牌位置引用 `LOGO-REF-001`，动态文字与数值由程序绘制；对象与物品的小图标（建筑、资源、种子、作物、礼包、载体、核心、传感器、效应器、资源点）归 `共用素材/14-对象与图标母版`（`UI-MASTER-014`），本文件不重复登记。七条需求必须同批生成。

## 共用几何合同

- 页面画布 1920×1080，SafeArea 四周留 24px。
- 插画/版面类（统计图框、对象摘要素描卡、远程机器条目版式）：正面视角，正投影平视构图（对象摘要素描卡为等距正视），主体居中并预留运行时文字覆盖区；主体占画面 60%–75%，四周留白 ≥ 24px，四周 8px 内不得有需要拉伸的细节。
- 角标类（中枢等级徽记 · 三级 / 满级、中枢总览环形仪表框）：同一子族共用同一外框尺寸与锚点（`pivot = 0.5, 0.5`）；状态差异必须含结构、纹理、明度中的至少两种，不得只换颜色。
- 全部条目：透明 PNG、sRGB、无可读文字与数字、无白边；导出 PNG 的实际像素必须等于文件名标注的尺寸。
- 接入：等级徽记与环形仪表框 `spriteBorder` 全 0；统计图框与远程机器条目版式用 `spriteBorder = 32` 九宫格拉伸。
