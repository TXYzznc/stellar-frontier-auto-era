# 页面专属切图：08-制造工坊

制造工坊族在共用母版之外需要的独有画面内容：配方卡专属版面、队首进度标记、阻塞原因角标、输出容量刻度底纹和缓存警报角标。容器、控件、图标、轨道一律引用 `UI-MASTER-001`~`013`，品牌位置引用 `LOGO-REF-001`，动态文字与数值由程序绘制，均不在本文件重复登记。八条需求必须同批生成。

## 共用几何合同

- 页面画布 1920×1080，SafeArea 四周留 24px。
- 插画类：正面视角，正投影平视构图，主体居中并预留运行时文字覆盖区；主体占画面 60%–75%，四周留白 ≥ 24px，四周 8px 内不得有需要拉伸的细节。
- 角标类：各状态共用同一外框尺寸与锚点（`pivot = 0.5, 0.5`）；状态差异必须含结构、纹理、明度中的至少两种，不得只换颜色。
- 底纹类：必须无缝平铺，左右与上下边缘各自首尾相接，不得出现接缝、暗角或有方向性的渐变；刻度格件的格块划分必须逐像素对齐。
- 全部条目：透明 PNG、sRGB、无可读文字与数字、无白边；导出 PNG 的实际像素必须等于文件名标注的尺寸。
- 接入：配方卡版面、队首进度标记与各角标 `spriteBorder` 全 0；输出容量刻度底纹用 `Image.type = Tiled` 平铺，导入时 `wrapMode = Repeat`。
