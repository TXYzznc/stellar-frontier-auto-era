# 页面专属切图：05-机器管理（第二批）

机器管理族在共用母版之外的第二批独有画面内容：通用轮式与固定旋转两种载体型号的缩略图大图、机器等级徽记、诊断路径段与断点、远程机器徽记和机器准备态版式。容器、控件、图标、轨道一律引用 `UI-MASTER-001`~`014`，品牌位置引用 `LOGO-REF-001`，动态文字与数值由程序绘制，均不在本文件重复登记。八条需求必须同批生成。

## 共用几何合同

- 页面画布 1920×1080，SafeArea 四周留 24px。
- 插画类（载体缩略图）：正面视角，2:1 轴测等距构图，主体居中并预留运行时文字覆盖区；主体占画面 60%–75%，四周留白 ≥ 24px，四周 8px 内不得有需要拉伸的细节。
- 版式类（机器准备态版式）：正面正交构图，不含等距透视；四边为 2px 结构线版面边框，内部按标题带／主体台／信息带三段分区，主体台中心预留运行时文字与数值槽，边框四角不得进入拉伸区。
- 角标类（机器等级徽记、诊断路径标记、远程机器徽记）：同一子族共用同一外框尺寸与锚点（`pivot = 0.5, 0.5`）；等级徽记与远程机器徽记子族固定 96×96 并共用同一 12° 切角与 2px 边线，诊断路径标记子族固定 128×128 并共用 32px 高贯穿轨道线；状态差异必须含结构、纹理、明度中的至少两种，不得只换颜色。
- 底纹类（诊断路径 · 正常段）：必须无缝平铺，左右与上下边缘各自首尾相接，不得出现接缝、暗角或有方向性的渐变；贯穿轨道线固定落在垂直 128px 基线（带高 32px、上下各留 112px 透明）。
- 全部条目：透明 PNG、sRGB、无可读文字与数字、无白边；导出 PNG 的实际像素必须等于文件名标注的尺寸；四张载体缩略图（本批两张与第一批两张）共用同一等距机位、画布与主体占位框，外轮廓按各自型号绘制。
- 接入：徽记与诊断路径标记 `spriteBorder` 全 0；诊断路径 · 正常段用 `Image.type = Tiled` 平铺，导入时 `wrapMode = Repeat`；载体缩略图与机器准备态版式 `spriteBorder` 全 0、`Image.type = Simple`。

## AI 单文档生成合同（可独立投喂）

### 共同输入与身份控制

本文件本身就是完整生成合同。输入只包括本文件和（画面需要 Logo 时）已经生成的 Logo PNG。Logo 不是重新设计对象：保持徽记缺口方向、星核层数、字标比例、负空间和透明背景完全一致；未明确写“出现 Logo”的画面不得自行添加 Logo。不要引用旧截图、旧模型、参考游戏界面或未登记资源。

### 视觉风格

- 原创工业二次元清线赛璐璐：平整色块、硬边阴影、2–4px 结构线、少量冷白高光线；轮廓清楚，避免照片级材质和柔焦。
- 形体采用 12°/30°/45° 的规整切角和模块化边界；相同母版的外轮廓、透视、锚点和安全区必须保持一致。
- 画面信息层级按“主体轮廓 → 状态装饰 → 留字/留数值槽 → 次要纹理”排列，不能用装饰抢主操作焦点。

### 配色 Token 与使用比例

- `UI/Background #111923`：页面底、遮罩和未激活区域，占画面约 55%–70%。
- `UI/Surface #1B2633`：主面板和导航底，占约 15%–25%。
- `UI/Card #2B3745`、`UI/CardRaised #364657`：卡片、列表、悬停和聚焦层，占约 8%–15%。
- `UI/TextPrimary #E9EEF2`、`UI/TextSecondary #AEBCC7`：只作为留字槽对比参考，图片中不生成可读文字。
- `UI/Action #E68A37`、`UI/Focus #F0A24B`：操作、焦点和确认强调，合计不超过画面 8%。
- `UI/Success #67C28A`、`UI/Warning #D8B15A`、`UI/Danger #D75E63`：状态色只作辅助，必须同时有形状、刻线、缺口、纹理或位置变化。

颜色只负责语义辅助；normal、hover、pressed、selected、disabled、warning、danger、empty 等状态必须另外加入位置、轮廓、刻线、断口、斜线纹理、内缩或外伸等非颜色差异。
