# 共用 3D 模块与引用规则

## 1. 共享策略

- **完全共用**：工业主材质、状态灯、接口板、接地点、模块化边界、地表通道。
- **同族变体**：相同几何母版，通过材质/尺寸/状态参数派生；每个可见状态仍独立记录。
- **形似不同**：不同玩法职责即使外形相似也独立制作，例如水泵与发电机不能共用外壳。

## 2. 技术锚点

每个 3D 对象必须定义 `LogicalRoot`、`VisualRoot`、`GroundContact`、`Mount_*`、`WorkPoint_*`、`KeepOut_*` 和状态灯位置。效果图须用旁注标出这些锚点，但不把标注烘焙进模型。

## 3. 共享材质

清线赛璐璐视觉使用简化 PBR 通道：BaseColor、Normal、Mask/AO、Emission Mask。金属为暖白/浅灰＋深灰结构，橙色只用于操作件和安全标记，深蓝用于信息窗；普通环境采用冷灰、蓝绿和土色。

## 4. 资产验收

- [ ] 三分之一轴测下轮廓职责清楚。
- [ ] 正视、背视、顶部/工作视图结构一致。
- [ ] 有可信接地点、接口、作业面和维护侧。
- [ ] LOD 只减少细节，不改变轮廓、锚点和状态灯。
- [ ] 新源文件、提示词、尺寸依据和用户裁决完整。
