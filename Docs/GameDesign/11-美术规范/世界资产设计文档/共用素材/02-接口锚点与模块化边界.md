# 共用世界素材 · 安装面、挂点、接地点、作业口、KeepOut、边界套件

> 本文件是新制作母版批次。每个状态/变体单独编号并保存记录；不可用旧模型或旧渲染图作为参考输入。

## 1. 固定视觉模块

```text
原创工业二次元科幻世界资产，清线赛璐璐，平整色块，硬边阴影，少量高光线，明亮中模结构，暖白/浅灰工业外壳，深灰骨架，深蓝信息窗，橙色操作件，冷色异星环境，三分之一轴测，支撑和接口可信，原创异星拓荒符号。
```

负面提示：照片写实、旧模型复刻、随机低模三角拼贴、全物体纯黑描边、锈蚀油污覆盖、霓虹赛博、漂浮、无接地、无接口、伪造文字、参考游戏复制、人物、动物、战斗。

## 2. 本批硬性约束

- 1 Unity 单位＝1 米；图中用中性比例尺，不从透视外观推导工程尺寸。
- 输出主视、背视、顶部/工作视图；可动对象追加待机和安全收回姿态。
- BaseColor/Normal/Mask/AO/Emission Mask 分开设计；透明只用于水面或虚影。
- 状态灯不能替代真实状态；必须同时有姿态、图标或 UI 摘要。
