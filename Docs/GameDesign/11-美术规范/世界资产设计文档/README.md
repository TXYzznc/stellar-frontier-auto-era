# 世界资产设计文档

本目录按参考项目的“通用规则 → 分族生产文档 → 组合效果图”组织世界、机器、建筑、资源点、VFX、动画和音频。每份独立素材文档包含对象职责、尺寸/接口约束、视图要求、中文/英文提示词、状态后缀、命名、技术交付和验收。

## 顺序

1. `共用素材/01` 材质与清线模块 → `02` 接口/锚点 → `03` 地表/散布 → `04` 状态灯/VFX → `05` 包装/装饰。
2. `独立素材/01` 机器载体与核心 → `02` 传感器与效应器 → `03` 建筑与施工 → `04` 资源点与环境 → `05` 外部供给、VFX、动画、音频。
3. `效果图/01~07` 依次生成代表区域、单体、装配、资源点、施工和 UI 叠加图。

## 全部新制作

效果图、轴测设计、模型、贴图、VFX、动画和音频均从零制作。1 Unity 单位＝1 米、碰撞、导航、安装面、作业点、KeepOut、功率和容量来自技术合同，不能由图像推导。
