# 世界资产设计文档（非 3D）

这里现在只维护**非 3D 世界表现**：VFX、动画表现和音频设计。

机器、建筑、资源点、材质、挂点、地表和 3D 组合效果图已经移到 [3D资产设计文档](../../3D资产设计文档/README.md)，不在本目录继续拆分或重复设计。

## 这里保留什么

| 内容 | 用途 | 最终资源根目录 |
|---|---|---|
| VFX | 选择框、合法/非法放置、施工虚影、湿度/矿脉/水面表现、状态灯和结果反馈 | `Assets/Game/VFX/`；设计板暂存 `Assets/Game/Sprites/World/Standalone/05-VfxAnimationAudio/` |
| 动画表现 | 施工、机器工作、状态切换的时序和节奏 | `Assets/Game/Animations/` |
| 音频 | 环境音、机器音、警报音和动态音乐 | `Assets/Game/Audio/` |

## 使用顺序

1. 先确认 3D 对象的名称和状态 ID 已由 3D 文档冻结。
2. 阅读 `01-动态表现/01-VFX动画音频与外部供给.md`，了解总合同。
3. 实际生图/制作时只选择 `01-动态表现/批次/` 下的批次文档；每批最多 10 项。
4. 音频条目是声音设计合同，不要把它们误当成 PNG。

## 批次规则

- 同一表现母版的所有状态在同一批。
- 状态不能只改颜色，必须写清形态、节奏、方向、持续时间或回收方式。
- 设计板只是参考图，VFX、动画和音频的运行时文件分别进入正式资源根目录。
