# 11 · 覆盖、交付与验收

## 1. 文档覆盖

- UI 共用素材批次：9 份自包含生产文档。
- UI 页面族：18 份独立文档；每份包含页面概述、真实 contract 来源、布局骨架、元素槽位、中英文效果图提示词、专属素材、状态、共用引用和验收。
- 世界资产共用模块：5 份；独立资产：5 份；效果图：7 份。
- 清单：`assets-manifest.json`，当前登记 553 个资产/程序项、25 个效果图板；另有 5 个样例资产和 1 份样例索引。

## 2. 文档级验收

- [ ] 参考目录结构已映射到本项目，且本项目排除项未被带入。
- [ ] 每个共用批次均有固定视觉模块、硬性约束、逐项状态、文件名、提示词、批次建议和验收。
- [ ] 每个页面族均有实际 Form/Prefab/contract 来源。
- [ ] 世界对象均有尺寸依据、接口/锚点、状态、提示词和技术边界。
- [ ] 所有效果图只引用 manifest 已登记 ID。

## 3. 状态级素材验收

- [ ] 每个需要绘制的状态有独立编号、文件名和提示词。
- [ ] 同族状态保持外轮廓、画布、Pivot、锚点一致。
- [ ] 程序绘制项（文字、数字、算法连线、动态进度、纯色遮罩）未被错误要求生图。
- [ ] UI 九宫格四角、边缘、中心拉伸后无条纹和断裂。
- [ ] 3D 对象主视/背视/顶部视图一致，接地、接口、作业点和 KeepOut 可读。

## 4. 视觉验收

- [ ] 工业二次元、清线赛璐璐、深灰蓝底、浅色信息卡、少量橙色焦点贯穿全套。
- [ ] 不复制明日方舟、重返未来1999或任何其他游戏的具体图标、字体、角色、版式或素材。
- [ ] 不使用旧图片、模型、贴图、材质、VFX、动画、音频或旧效果图作为生产内容。
- [ ] 状态至少由颜色与图标/形状/姿态/文字槽中的两种表达。
- [ ] 不出现人物、动物、战斗、棋盘、圆形 PCG 边界、悬浮建筑、伪造文字和 Logo。

## 5. 外部生图交付记录

每项必须保存：`assetId`、状态、完整提示词、负面提示、模型/工具、种子或等价记录、原始文件、后处理、源文件指纹、用户视觉裁决。没有这些记录不能标记 `ACCEPTED` 或 `DELIVERED`。

## 7. 不通过条件

把效果图当运行时切图；用图片推导工程尺寸；状态只换颜色；页面层级与 contract 不符；动态文字烘焙；旧素材复用；参考游戏复制；源文件/提示词/指纹缺失，均退回重做。
