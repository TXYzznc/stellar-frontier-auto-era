# 星际拓荒：自动纪元 · 第一版美术规范

> **用途**：本目录是第一版所有新美术资源的生产设计入口，按“总规范 → UI 资源 → 非 3D 世界表现 → 交付验收”执行。3D 资产单独维护在 `Docs/GameDesign/3D资产设计文档/`。所有文档只提供设计、提示词、规格、引用和验收；实际生图由用户负责。
>
> **全量重做门禁**：不得复用旧图片、旧模型、旧贴图、旧材质、旧 VFX、旧动画、旧音频、旧 Prefab 截图或旧效果图。现有 B52、ART006、历史合同和参考项目只提供语义、尺寸、层级与信息结构。

资源批次完成后，可使用 [美术批次导入工具](../../Development/ArtBatchImportTool.md) 从批次文档读取资源 ID、文件名和存放路径，按生成文件顺序预览并一键导入到 `Assets/Game/Sprites`。

## 推荐生产顺序

1. 阅读 `00-来源与范围.md`、`美术风格和规范/01~06`，冻结视觉和生成约束。
2. 先按 `界面设计文档/共用素材/00-Logo设计与引用.md` 生成并冻结三种 Logo；再按 `共用素材/01~14` 生成十四族 UI 母版（共 142 项），同一母版状态一起生成、一起验收。
3. 按 `界面设计文档/界面/01~18` 生成页面效果图；页面专属素材按 `界面设计文档/页面专属/01~18`（24 份，共 204 项）逐族生成，再补控件状态。
4. 3D 机器、建筑、资源点和效果图进入 `Docs/GameDesign/3D资产设计文档/` 单独流程。
5. 按 `世界资产设计文档/01-动态表现/批次` 生成 VFX、动画和音频设计。
6. 使用 `assets-manifest.json` 和 `11-覆盖与验收.md` 做引用、状态、源文件指纹和视觉验收。

## 已冻结方向

- 原创工业二次元主导，学习参考游戏的信息层级与构图节奏，不复制其具体素材。
- 清线赛璐璐：平整色块、硬边阴影、少量高光线；不使用均匀黑描边和照片级微表面。
- UI：深灰蓝底、浅色信息卡、少量橙色焦点；状态色必须配合文字、图标或形状。
- 世界：明亮异星环境与暖白/浅灰工业设施并置；三分之一轴测和正交镜头优先。
- 当前第一版不制作人物、动物、战斗、实际探索、角色语音和棋盘内容。

## 第一轮试制入口

在批量制作前，先使用 样例试制/README.md。其中的 5 个样例按“共享 UI → 小图标 → 机器 → 建筑 → 组合效果图”排列，提示词可以直接交给生图 AI。样例只用于判断方向，不替代正式素材族文档，也不代表 Unity 接入完成。
